# Zotero Neo

Zotero Neo adds keyboard controls to Zotero. Find papers, select PDF text, make
annotations, and keep excerpts in existing notes while continuing to use
Zotero's own library, reader, and note editor.

The public release is [v0.1.0](https://github.com/zhongyangchuwu/Zotero-Neo/releases/tag/v0.1.0).
This documentation describes v0.2 development. Use the latest stable Zotero release.
