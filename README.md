# Zotero Neo

Zotero Neo 是 **Zotero 的模块化增强工具链**，灵感来自 [LazyVim](https://www.lazyvim.org/) 和 [snacks.nvim](https://github.com/folke/snacks.nvim)。它把找论文、读 PDF、做批注和切换工作现场串成键盘优先的日常操作；每项工具也可以单独使用，文献和笔记仍留在原有 Zotero 文库。

- **找文献，不离开键盘**：用统一选择器查找条目、分类和笔记，边浏览边标记，挑完再批量整理。
- **读 PDF，不反复拖选和翻页**：用 Flash 按词句选中文字，在批注、图表和引用之间跳转，随时回到刚才的位置。
- **少找标签页，少重配一遍**：用侧栏分组管理打开的文献，用 Neo 管理已装扩展；借助设置快照备份和携带配置，可选用 Zotero 同步快照。
