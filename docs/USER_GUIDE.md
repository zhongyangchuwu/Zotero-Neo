# User guide

Start with [Install Neo and try it](GETTING_STARTED.md), then choose a workflow below. [How Neo works](CONCEPTS.md) explains focus, modes, Cursor, and Selection. For exact ActionIds, bindings, contexts, counts, and targets, use the [Command Reference](COMMAND_REFERENCE.md); see [Tags](TAGS.md) for tag actions and filters, [Input methods](INPUT_METHODS.md) for native text entry and IME, and [Project terminology](INTERACTION_MODEL.md#terminology) for shared terms. For setting defaults, see the [Settings reference](SETTINGS_REFERENCE.md).

## Read a paper and keep a running note

Use the [Library guide](MAIN_GUIDE.md) to locate and open a paper, then the [Reader guide](READER_GUIDE.md) to move through its PDF. The [Selection guide](SELECTION_GUIDE.md) covers finding and annotating text; [Capture](CAPTURE_GUIDE.md) explains how to append a passage to an existing note. Continue in the [Notes guide](NOTE_GUIDE.md) to edit the note, and use [Tags](TAGS.md) to organize the item.

## Review and organize papers

Use [Search and navigation](SEARCH_GUIDE.md) to narrow the Main view or find a specific item. The [Library guide](MAIN_GUIDE.md) explains how to collect papers into persistent Selection, inspect the Selection Panel, change collection membership, and review a Trash operation. Use [Tags](TAGS.md) when applying a shared tag or filtering the view; a filter and a workset serve different purposes.

## Follow a thread across papers and notes

Set a position in the [Reader](READER_GUIDE.md) before following a link or switching papers. Use [Search and navigation](SEARCH_GUIDE.md) to find another item, switch tabs, or return through shared history. Append relevant passages to an existing topic note with [Capture](CAPTURE_GUIDE.md), then add your own comparison in [Notes](NOTE_GUIDE.md). A Reader mark names a PDF position; shared history records eligible navigation between surfaces.

Use the [Command Reference](COMMAND_REFERENCE.md) for the complete current action catalog, or [Troubleshooting](TROUBLESHOOTING.md) when an interaction does not work as described.
