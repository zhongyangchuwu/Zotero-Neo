# User guide

Build a reading list in the Library, work through a PDF, annotate useful passages, and collect them in your notes. Tags, collections, bookmarks, and navigation history help you return to that work later.

## Get started

[Install Neo and try it](GETTING_STARTED.md), then learn [how commands and text entry work across the Library, Reader, and Note editor](CONCEPTS.md).

## Read a paper and keep a running note

1. Find the paper with `<Space>ff`, search by title or creator, and open the result. See [Library](MAIN_GUIDE.md) and [Search and navigation](SEARCH_GUIDE.md).
2. Open the PDF Outline with `<Space>ro` and skim its headings. Use a split view to compare a figure or result with the surrounding explanation. See [Reader](READER_GUIDE.md).
3. Press `v`, search for visible text, and choose its hint. Refine the selection, then add a highlight or comment. See [Selection and annotations](SELECTION_GUIDE.md).
4. Create a note attached to this paper in Zotero, or use one of its existing notes. With PDF text selected, open Selection Actions and choose **Capture to note**. Check the destination preview before confirming. See [Capture](CAPTURE_GUIDE.md).
5. Open the paper's notes with `<Space>fn`, write your explanation of the passage, and return to the PDF to continue reading. See [Notes](NOTE_GUIDE.md).
6. Add a topic or progress tag to the paper and set a Reader mark for a passage you want to revisit. See [Tags](TAGS.md) and [Reader bookmarks](READER_GUIDE.md#mark-a-place-and-return-to-it).

## Review and organize a group of papers

1. Select a collection, run Quick or Advanced Search, or apply tag filters to narrow the Library. See [Search and navigation](SEARCH_GUIDE.md).
2. Browse the results and press `s` on papers to keep. Commit a temporary Visual range with `s` to add adjacent items to the Selection.
3. Open `<Space>ss` to inspect the workset. Reveal papers to check them, remove unwanted entries, and review items outside the current view before a batch change.
4. Add the group to a collection or apply a shared tag. See [Library](MAIN_GUIDE.md#change-collection-membership) and [Tags](TAGS.md).
5. Clear the Selection with `<Space>sc` before starting a different group. For deletion, review the Trash confirmation; `u` restores the last batch trashed by Neo.

## Follow a thread across papers and notes

1. Set a Reader mark before following a chain of references.
2. Follow a PDF link, find another paper, or switch tabs. Search the current paper's notes, or choose **Browse library** for a topic note in the same library.
3. Compare passages in a split PDF view or across tabs, then append excerpts to the topic note and add your explanation.
4. Use `Ctrl+o` and `Ctrl+i` to traverse recorded destinations. Use a Reader mark for a named position, or choose **Show current item in Library** from the Reader or Note Command Palette to reveal the source item.
