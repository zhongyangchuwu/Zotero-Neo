# 浏览和整理文献 {#work-with-items-in-the-zotero-library}

在 Zotero 主窗口里，你可以用键盘切换分类、查找和打开论文。需要整理多篇论文时，可以先把它们标记到 Neo 选择集，再一起添加标签或调整分类。

记不住快捷键，可以按 `:` 打开命令面板搜索操作名称。按键不符合预期时，先查看[快捷键设置](SETTINGS_GUIDE.md)，再看[故障排查](TROUBLESHOOTING.md#a-key-does-nothing)。

## 开始浏览文库 {#try-it}

1. 在主窗口普通模式按 `e` 聚焦分类树，用 `j` / `k` 选择文库或分类，再按 `Enter` 显示其中的条目。
2. 按 `ww` 聚焦中间的条目列表，用 `j` / `k` 移动条目游标；按 `Enter` 或 `o` 打开游标所在条目。
3. 按 `<Space>ff` 查找当前文库中的条目，或按 `<Space>fc` 查找当前分类中的条目。查看结果预览，再确认要打开的条目。

## 用 DOI、arXiv ID 等添加论文 {#add-items-by-identifier}

在主窗口按 `<Space>ai`，或打开命令面板搜索**通过标识符添加条目**，就能调出 Zotero 自带的标识符输入框。

1. 先选中要导入到的文库或分类。文库必须允许写入，一次不能跨多个文库。
2. 输入 ISBN、DOI、PubMed ID、arXiv ID 或 ADS Bibcode。批量添加时每行一个，且不要在同一批混用不同类型的标识符。
3. 单行输入时，按 `Enter` 提交，按 `Shift+Enter` 添加一行；多行输入时，按 `Enter` 换行，按 `Shift+Enter` 提交。这些是 Zotero 原生输入框的按键规则。
4. 按 `Escape` 关闭输入框会丢弃尚未提交的草稿；提交后再关闭不会撤销已经保存的条目。查询进度、失败、附件偏好和导入后的选择都由 Zotero 处理。

论文会加入当前选中的文库或分类，与 Neo 选择集无关。同一文库里选中的多个分类都会作为导入位置。再次切回已经打开的输入框时，原来的输入内容仍会保留。

阅读器普通模式也有相同的 `<Space>ai` 操作：它会调出关联的文库窗口，并在该窗口的文库标签页打开输入框，沿用该窗口当前的分类范围，而不是阅读器条目的分类。独立阅读器只使用打开它的实际主窗口，不借用其他主窗口；该窗口已关闭或不可用时，入口不会出现在可执行命令中。

## 浏览文库与分类 {#browse-a-library-and-its-collections}

分类树决定主窗口条目列表显示的范围。按 `e` 聚焦分类树；`j` / `k` 在行之间移动，按 `Enter` 激活选中的文库或分类。`h` 折叠已展开的分类，或移到其父级；`l` 展开已折叠的分类。分类已展开或没有子项时，`l` 会聚焦条目列表。用 `ww` 聚焦中间的条目列表，`wh` 聚焦左侧窗格，`wl` 聚焦右侧详情窗格。

在条目列表中，`j` / `k` 移动条目游标；`gg` 和 `G` 分别移到首行和末行。给 `G` 一个正数会按从 1 开始的行号定位。按 `Enter` 或 `o` 打开游标所在条目。

需要改变主窗口显示的条目时，使用分类树；要在当前行之外定位条目、缩小主窗口视图或查找 PDF 文本，请参阅[搜索与导航](SEARCH_GUIDE.md)。

## 查找、新建和移动分类 {#find-and-organize-collections}

按 `:` 打开命令面板，搜索下面这些操作名称。它们目前没有默认快捷键：

- **查找并进入分类**：输入名称或完整路径，选中结果后切换到该分类。只读文库也能用。
- **向当前分类添加已有条目**：逐个查找同一文库中的条目并添加到当前分类。
- **将当前条目目标移到其他分类**：把选中的论文从一个分类移到同一文库中的另一个分类。
- **移动当前分类**：移动当前分类及其后代分类。
- **新建分类**：在所选父分类或文库根目录下创建分类。
- **重命名当前分类**：重命名当前分类。
- **删除当前分类（保留条目）**：删除分类及其后代分类，但保留文库中的条目。

除查找外，这些操作会修改文库，所以需要写入权限。

有同名分类时，可以用完整路径区分。只有确认后才会跳转；按 `Escape` 退出不会改变分类。跳转后可以用 `<C-o>` / `<C-i>` 返回之前的位置。

移动、重命名或删除分类时，最好先在左侧分类树中选中它。如果焦点不在分类树上，就必须只选中一个普通分类；选中多个分类或整个文库时，这些操作无法执行。

新建分类时，先选择父分类或文库根目录。移动分类会连同子分类一起移动，但不能移到自身或自己的子分类下面。新建、重命名和确认操作使用 Zotero 自带的输入框。

**删除分类会连同子分类一起删除，但不会删除其中的论文。** 这类删除不能用 Neo 的 `u` 撤销；请在确认前核对分类。

使用**向当前分类添加已有条目**时，先选中一个普通分类。输入关键词后，最多显示同一文库中的 100 条匹配结果。按 `Enter` 添加一篇，选择器会继续打开；按 `Escape` 结束。已经添加的论文不会因为退出而撤销。

## 先标记论文，再批量操作 {#keep-opening-and-batch-selection-separate}

浏览文献时，条目游标表示当前停在哪一行。要把几篇论文留待一起处理，可以用 Neo 选择集。它与 Zotero 原来的多选、连续行范围是不同的操作方式：

- **Neo 选择集**：在条目列表中按 `s`，将当前目标加入或移出选择集；条目游标会尽可能移到下一行。这样可以继续浏览，而保留工作集。按 `<Space>sc` 清空选择集。
- **可视范围（Visual）**：按 `v` 开始临时选择行范围，用 `j` / `k` 移动端点，按 `o` 交换范围两端。按 `s` 将范围提交到 Neo 选择集。如果范围中的每一行原本都已选中，提交会移除整个范围；否则会加入整个范围。按 `Escape` 或 `v` 取消，不会改动 Neo 选择集。
- **Zotero 原生多选**：仍由 Zotero 的列表操作维护，不会变成 Neo 选择集。只在支持原生多选来源的主窗口批量操作中使用。

Neo 选择集只保留在当前主窗口会话中，不跨重启保存。想长期保留这组文献时，可以将它们加入 Zotero 分类或添加标签。

在主窗口普通模式按 `Enter` 或 `o`，打开的始终是条目游标所在条目，不会批量打开 Neo 选择集中的条目；在可视范围中，`o` 用于交换范围端点。批量操作优先使用非空的 Neo 选择集；没有选择集时，按具体操作支持的来源使用可视范围、Zotero 原生多选或条目游标。聚焦分类树时选择的是文库范围，不会把文库或分类加入条目选择集。

### 查看 Neo 选择集 {#review-the-selection-panel}

按 `<Space>ss` 打开选择集面板。条目标为**可见**，表示它出现在当前主窗口行中；标为**隐藏**，表示它在当前视图之外；标为**不可用**，表示 Zotero 已无法解析它。用 `j` / `k` 浏览条目，按 `Enter` 在主窗口中显示所选条目。不可用条目无法显示。按 `x` 从选择集中移除当前条目，按 `c` 清空工作集，按 `r` 刷新面板；按 `Escape` 或 `q` 关闭面板。

## 把论文添加到分类或移出分类 {#change-collection-membership}

选好要整理的论文后，可以添加、移除或移动分类：

1. 按 `s` 标记条目，再用 `<Space>ss` 检查工作集。
2. 按 `<Space>ca`，选择要加入的分类。已经属于该分类的论文不会重复添加。也可以选择 **New collection…**，先指定位置、输入名称新建分类，再把论文加入；中途取消不会留下空分类。
3. 按 `<Space>cr`，选择要移出的分类。只会移除这些论文在该分类中的归属，不会删除论文，也不会影响其他分类。
4. 要把论文从一个分类移到另一个分类，按 `:` 搜索**将当前条目目标移到其他分类**。先选好来源分类，且要移动的论文都必须直接属于它。确认目标分类后，Neo 会把这些论文加入新分类，并从原分类移除。文库根目录、保存的搜索或多个分类不能作为来源；如果只想增加一个分类而不移出原分类，请用 `<Space>ca`。

候选分类旁的 `n/N` 表示已经直接属于该分类的论文数（共 N 篇），不包含只因上级分类而显示的论文。批量调整分类时，论文必须在同一文库。操作完成后，Neo 选择集会保留，方便继续整理。

## 把论文移到回收站并恢复 {#trash-and-restore-items}

在文献列表中按 `dd` 或 `x`，确认后会把选中的论文移入 Zotero 回收站。若 Neo 选择集不为空，优先处理其中的论文；否则按当前范围或 Zotero 原生多选操作。确认框会显示来源和论文数量。

如果选择集中有当前列表看不到或已经无法访问的论文，整次操作会取消，避免只删除其中一部分。成功移入回收站后，这些论文也会从 Neo 选择集中移除。

按 `u` 可以恢复 Neo 最近一次移入回收站的那一批论文。这个记录会被下一次删除操作替换；它不能撤销其他 Zotero 操作，也不能恢复已经删除的分类。

完整默认快捷键、重映射方式和各操作的目标规则见[命令参考：主窗口](COMMAND_REFERENCE.md#main-window)。
