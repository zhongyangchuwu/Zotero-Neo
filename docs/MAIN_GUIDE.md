# 文献库与工作区

在 Zotero 主窗口中，可以用键盘浏览文库、查找条目和整理工作集。本文使用默认快捷键；修改过绑定时，以 Neo 设置为准。完整按键表见[命令参考](COMMAND_REFERENCE.md)，PDF 操作见[阅读器指南](READER_GUIDE.md)。

## 开始浏览文库

1. 在主窗口普通模式按 `e` 聚焦分类树，用 `j` / `k` 选择文库或分类，按 `Enter` 显示其中的条目。`h` 折叠分类或移到父级，`l` 展开分类；分类已展开或没有子项时，`l` 聚焦条目列表。
2. 按 `ww` 聚焦中间的条目列表，用 `j` / `k` 移动条目游标，`gg` / `G` 跳到首行或末行。按 `Enter` 或 `o` 打开游标所在条目；它们不会批量打开 Neo 选择集。
3. 按 `<Space>ff` 查找当前文库中的条目，或按 `<Space>fc` 查找当前分类中的条目。输入查询，查看结果和预览，确认后前往目标。

`wh` 和 `wl` 分别聚焦左侧和右侧窗格。按 `:` 打开命令面板，搜索当前界面可用的操作名称，选择后按 `Enter` 执行；没有默认快捷键的可用操作也会显示。输入 `<Space>` 等命令前缀后稍停，可查看后续按键提示。

### 选择器与搜索

条目、笔记、标签和分类等选择器共用查询框与结果列表。用方向键或 `<C-j>` / `<C-k>` 移动结果，`<C-d>` / `<C-u>` 滚动预览，`Enter` 或 `Shift+Enter` 确认，`Escape` 取消；结果列表中的 `/` 可回到查询框。查询框接受普通文字和输入法。开启鼠标选择时，单击选择，双击确认。

要缩小主窗口视图，按 `<Space>fq` 聚焦 Zotero 快速搜索，或按 `<Space>fa` 打开高级搜索；已有的快速搜索文字可带入高级搜索。按 `<Space>tf` 切换标签筛选，`<Space>tc` 清除全部标签筛选。多个标签筛选以 AND 组合，只显示同时具备这些标签的条目。

聚焦条目列表后按 `/`，可在当前可见行中查找标题、首位作者、年份或可用的 citekey。输入一个或多个词并按 `Enter`，再按 `n` / `N` 循环查找下一项或上一项。它只移动游标，不改变分类或筛选条件；没有匹配项时游标保持原位。阅读器中的 `/` 则搜索 PDF 正文。

在主窗口按 `:` 搜索**查找并进入分类**，可以按名称或完整路径查找一个文库中的分类。预览或取消不会改变范围；确认后进入所选分类。同名分类可用完整路径区分。该操作没有默认快捷键；`<Space>fc` 查找的是分类中的条目。

## 先标记论文，再批量操作

条目游标表示当前停留的行，Neo 选择集则保存待一起处理的条目。选择集属于当前主窗口会话，切换分类、搜索或筛选不会清空它，但重启后不保留。长期整理请使用 Zotero 分类或标签。

- 在条目列表按 `s`，将当前目标加入或移出 Neo 选择集，游标会尽可能移到下一行。按 `<Space>sc` 清空选择集。
- 按 `v` 开始临时可视范围，用 `j` / `k` 移动端点，`o` 交换两端，`s` 将范围提交到选择集。范围内每一行都已选中时会整段移除，否则整段加入；`Escape` 或 `v` 取消范围，不改变选择集。
- Zotero 原生多选与 Neo 选择集分开维护。主窗口批量操作优先使用非空 Neo 选择集；选择集为空时，按具体操作支持的来源使用可视范围、原生多选或条目游标。Reader 和 Note 使用各自的当前条目或笔记，不借用主窗口选择集。

### 查看 Neo 选择集

按 `<Space>ss` 打开选择集面板。条目标为**可见**、**隐藏**或**不可用**，分别表示在当前列表中、位于当前视图之外或 Zotero 已无法解析。用 `j` / `k` 浏览，按 `Enter` 在文库中显示可用条目，`x` 移除当前项，`c` 清空，`r` 刷新，`Escape` 或 `q` 关闭。

添加或移除标签、调整分类时，选择器标题显示目标来源、实际条目数及当前列表之外的数量。附件归一到所属文献后去重；隐藏目标仍会参与操作，确认前先核对。

### 移入回收站并恢复

在条目列表按 `dd` 或 `x`，核对确认框中的来源和数量，再将目标移入 Zotero 回收站。非空 Neo 选择集优先；若选择集中有当前列表不可见或已无法访问的条目，整次操作会取消。成功移入的条目也会从选择集中移除。

按 `u` 可恢复 Neo 最近一次移入回收站的那批条目；下一次删除会替换这条记录。它不能撤销其他 Zotero 操作或恢复已删除的分类。

## 给条目添加标签和筛选

在主窗口、阅读器或笔记编辑器的普通模式按 `<Space>ta` 添加标签，按 `<Space>tr` 移除标签。添加时可选择文库已有标签，或选择明确显示的 **+ Create** 新建标签；移除时只列出至少属于一个目标的标签，并标出部分目标拥有的标签。添加会补齐所选标签，移除会移除所选标签；已符合目标状态的条目不会改写。

主窗口按上述选择集优先规则确定目标。阅读器使用当前 PDF 所属条目；笔记有所属条目时使用父条目，独立笔记则使用笔记本身。批量加减标签会处理各文库中可修改的条目，跳过缺失、只读或无需更改的条目，并提示完成和跳过数量。改变标签会修改条目；`<Space>tf` / `<Space>tc` 只改变主窗口筛选，不修改标签。

标签选择器可按名称前缀显示虚拟命名空间。例如默认分隔符 `/` 可将 `项目/待读` 显示在 `项目/` 下；选择命名空间只缩小候选范围。标签仍以完整名称存储，修改[层级分隔符](SETTINGS_GUIDE.md)不会创建父标签或改写名称。同名的手动与自动标签合并为一个候选，Zotero 中原有的标签类型不变。

## 把论文添加到分类或移出分类

先选好目标，再按 `<Space>ca` 添加到分类，或按 `<Space>cr` 从分类移除。移除只解除所选分类中的直接成员关系，不删除论文，也不影响其他分类。候选旁的 `n/N` 表示 N 篇目标中直接属于该分类的数量；操作只修改与目标分类同文库中可更改的条目，其余条目跳过并计入结果提示。添加时也可选择 **New collection…** 创建分类并加入条目，取消不会留下空分类。操作完成后 Neo 选择集保留。

要从一个分类移到另一个分类，在 `:` 中搜索**将当前条目目标移到其他分类**。先选中一个普通来源分类，再选择同文库的目标分类。可修改的直接成员将加入新分类并移出来源，其余条目跳过并计入结果提示。若只想增加归属而保留来源，请使用 `<Space>ca`。

### 查找、新建和移动分类

在命令面板还可搜索**向当前分类添加已有条目**、**新建分类**、**移动当前分类**、**重命名当前分类**和**删除当前分类（保留条目）**。这些操作默认未绑定快捷键；除查找外均需写入权限。

添加已有条目时先选中一个普通分类，搜索同一文库中的条目，每次 `Enter` 添加一项，`Escape` 结束；退出不会撤销已添加的条目。移动分类会连同子分类移动，不能移到自身或其子分类下。重命名、移动或删除时，先在分类树中选中目标；焦点不在树上时须只有一个普通分类。

**删除分类会连同子分类删除，但保留文库中的条目。** 确认前核对分类；Neo 的 `u` 不能撤销分类删除。

## 用 DOI、arXiv ID 等添加论文

在主窗口先选中可写文库或目标分类，按 `<Space>ai` 打开 Zotero 原生标识符输入框。可输入 ISBN、DOI、PubMed ID、arXiv ID 或 ADS Bibcode；批量输入每行一个，同一批不要混用标识符类型，也不能跨文库。

单行时 `Enter` 提交、`Shift+Enter` 增加一行；多行时 `Enter` 换行、`Shift+Enter` 提交。`Escape` 关闭会丢弃未提交的草稿，不会撤销已提交的条目。导入位置取自主窗口当前文库和所选分类，与 Neo 选择集无关。

## 给文献添加自定义属性

启用[条目自定义属性](SETTINGS_GUIDE.md#开关可选功能)并重启 Zotero 后，按 `<Space>pa` 定义文本、数字、单选或多选属性，在原生列菜单中显示相应列。选好文献后按 `<Space>ia` 编辑；键盘入口优先使用 Neo 选择集，原生右键入口使用 Zotero 的选中条目。批量设置会替换各目标原值，不会追加选项。

值写进条目的 Extra，可能随引用或导出内容一起显示；定义只保存在本机，可用[工作区同步与备份](SETTINGS_GUIDE.md#导出和恢复配置)迁移。删除定义不会删除已经写入条目的值。

## 切换标签页和返回

按 `<Space>,` 从选择器切换已打开的标签页，或按 `H` / `L` 切换到前一个或后一个标签页；`<Space>q` 关闭当前阅读器或笔记标签页。

按 `<C-o>` / `<C-i>` 在当前主窗口的 Neo 跳转历史中后退或前进。条目、笔记、Neo 标签页切换和可恢复的 PDF 跳转可进入历史；普通滚动、筛选或文字输入不会逐次记入。PDF 附件仍可读取时，历史可以重新打开已关闭的 PDF。后退和前进不会清空 Neo 选择集。要精确返回 PDF 中的某处，可先设置[阅读位置标记](READER_GUIDE.md)。

## 用标签页增强管理阅读分组

标签页增强默认关闭。要使用它，在 Neo 设置的**模块**页启用**标签页增强**，然后完全退出并重启 Zotero；开关立即保存，重启后生效。启用后可在设置中选择最左侧、最右侧或上方显示，位置修改立即生效，不重载 PDF 或笔记。左、右为垂直侧栏，上方为横向标签栏。导出和恢复设置见[工作区同步与备份](SETTINGS_GUIDE.md#导出和恢复配置)。

侧栏模式下，在 Main、Reader 或 Note 普通模式按 `<Space>bb` 聚焦侧栏，按 `<Space>bt` 收起或展开。也可直接点击标签页：

1. 右键标签页或点击其 **⋯**，选择**新建分组**，输入名称并按 `Enter`；右键侧栏空白处也可新建空组。
2. 使用**移至分组**，或拖动标签页和分组调整归属及顺序。文库入口不能加入分组。侧栏搜索可匹配组名、标题、作者、年份、文件名和可用的真实引用键；搜索时先清空查询再拖动。
3. 点击组名展开或折叠；组菜单可重命名、设置颜色或关闭标签页。上方模式以鼠标操作为主，通过 **⋯** 使用分组菜单，右键标签使用 Zotero 原生菜单。

也可在主窗口标记条目后按 `<Space>bc` 新建阅读分组，或按 `<Space>ba` 加入已有分组。动作开始时固定目标，非空 Neo 选择集优先；一篇文献有多份可用 PDF 时须明确选择，取消该文献的选择只会跳过这一项。确认后打开可用 PDF 并将成功打开的视图加入分组；缺少可用 PDF 的目标会跳过，没有可导入的 PDF 时不会建立空组。取消选择分组或取消打开确认不会更改分组。

分组管理打开的 Reader 和 Note 标签页，不按文库分类自动分组，也不修改论文的标签或分类。关闭标签页会将它从分组移除，空组保留；**从分组移除**或**取消分组（保留打开的标签页）**不会删除论文或关闭仍打开的文档。分组保存在本机 Neo 配置中，不通过 Zotero 同步；停用增强不会清空分组。

## 开始查找并编辑笔记

1. 在主窗口选中论文，按 `<Space>fn` 查找当前条目的笔记；Reader 使用当前 PDF 所属条目，Note 使用当前笔记的所属条目，独立笔记以自身为范围。
2. 查看预览中的正文和所属条目，用方向键选择并按 `Enter` 打开。选择 **Browse library** 可查找同一文库中其他论文的笔记和独立笔记；选择 **Current item** 回到原范围，查询会保留。普通笔记仍通过 Zotero 新建。
3. 在 Zotero 原生编辑器中编辑笔记，保存方式不变。新配置默认使用原生输入；在 Neo 设置的**交互**中启用**Vim 风格笔记编辑**后，可按 `i` 进入输入、`Escape` 返回 Normal。升级已有配置会保留原行为。

启用 Vim 编辑后，`h` / `j` / `k` / `l` 移动光标，`w` / `b` 按词移动，`gg` / `G` 移到开头或结尾；`dd` 删除一行，`u` / `<C-r>` 撤销或重做当前笔记的编辑。`yy` 复制一行并更新系统剪贴板；`p` / `P` 使用当前编辑器的 Neo 寄存器。跨笔记或从其他应用粘贴时，先按 `i` 进入输入，再使用 Zotero 原生粘贴快捷键。完整按键见[命令参考](COMMAND_REFERENCE.md)。

笔记有所属论文时，Note Normal 的 `<Space>o` 可打开该条目的 PDF；独立笔记没有所属论文附件。标签操作作用于所属条目或独立笔记本身，不使用主窗口选择集。

## 管理已安装的插件

**扩展管理面板**默认启用。在主窗口、阅读器或笔记普通模式按 `<Space>pp` 打开。按 `/` 筛选已安装的扩展，用 `j` / `k` 选择。Zotero 允许时可用 `e` / `d` 启用或停用，`p` 打开扩展设置；Neo 不允许在自己的面板里停用或卸载自身。

按 `i` 后可输入 GitHub `owner/repo`、仓库或 Release 链接，或 HTTPS `.xpi` 直链。留空可以选择精选扩展，例如 Translate for Zotero。GitHub 来源会查最新正式发布；如有多个安装包，先选一个。核对来源、文件名和可用的版本信息后按 `Enter` 安装，按 `Esc` 取消。第三方扩展可以访问 Zotero 数据和本机文件，只安装信任的来源。

Zotero 10 要求新安装的 XPI 声明更新地址；缺少 `update_url` 的安装包会被拒绝。

`u` 更新所选扩展，`U` 更新所有可更新的第三方扩展。Neo 先查原生更新；只有已装扩展没有原生更新地址时，才查本机记住的 GitHub 来源。批量更新不会因单个失败而中断。`x` 卸载所选扩展，按 `Enter` 确认。若 Zotero 延期处理，面板顶部会提示重启。安装来源只留在本机，[工作区同步与备份](SETTINGS_GUIDE.md#导出和恢复配置)仍只迁移设置。
