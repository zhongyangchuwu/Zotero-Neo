# Install Neo and try it

Neo adds keyboard controls to Zotero's Library, PDF Reader, and notes.

> The public XPI is v0.1.0; this site documents v0.2 development, so some steps here are not in the public package. See the [published user guide](https://github.com/zhongyangchuwu/Zotero-Neo/blob/v0.1.0/docs/USER_GUIDE.md) for the release.

## Install the public release

1. [Download the public XPI](https://github.com/zhongyangchuwu/Zotero-Neo/releases/download/v0.1.0/zotero-neo.xpi).
2. In Zotero, open **Tools → Plugins** and choose the gear menu.
3. Select **Install Plugin From File…** and open the downloaded XPI.
4. Restart Zotero when prompted. Neo's version appears in the plugin list.

## Try it

1. Open a PDF attachment and wait for its page to load.
2. Click the PDF page, away from a search box or comment field.
3. Press `j` to scroll down or `k` to scroll up.

**Result:** the PDF scrolls in place. If neither key works, check that Neo is enabled, click the page again, and see [Troubleshooting](TROUBLESHOOTING.md).
