# 阅读和导航 PDF

打开 PDF 后，先点击页面，再按快捷键。搜索框、批注输入框和侧栏有焦点时，按键可能由 Zotero 处理。想使用复制 DOI 或跟随链接的字母提示，需要在[模块设置](SETTINGS_GUIDE.md#开关可选功能)中开启**链接与复制提示**。

## 开始分屏阅读

1. 在阅读器中打开 PDF，点击页面区域。
2. 按下并松开 `Space`，再按 `-`，将阅读器横向分成上下两个窗格。
3. 点击上方窗格，按 `Ctrl+j` 将焦点移到下方窗格，再用 `j` / `k` 移动下方视图。点击下方窗格后按 `Ctrl+k` 回到上方窗格，分别移动两处内容。

## 分屏后怎么操作

分屏后，两个窗格可以停在 PDF 的不同位置。用 `Ctrl+j` / `Ctrl+k` 切换操作的窗格，滚动其中一个不会带动另一个。

## 翻页、滚动和缩放

用 `j` / `k` 滚动，用 `h` / `l` 翻到上一页或下一页。`Ctrl+d` / `Ctrl+u` 每次移动半个视图，`Ctrl+f` / `Ctrl+b` 每次移动一个完整视图。计数会重复对应动作：例如 `3j` 按当前滚动步长移动三次，`3l` 连续翻到后续页面。

按 `gg` 回到第一页的开头，不带计数的 `G` 滚到文档底部。若 Zotero 支持直接跳页，`gg` 或 `G` 前加正整数会跳到从 1 开始计数的页码，例如 `5G` 跳到第 5 页；不支持直接跳页时，则分别滚到顶部或底部。

按 `+` / `zI` 放大，按 `-` / `zO` 缩小；按 `=` / `z0` 恢复到适合页面宽度。滚动和缩放只改变视图，不会改变阅读器共享的后退/前进历史。

查看宽图或表格时，可先放大，再用 `zh` / `zl` 左右平移而不改变缩放比例。在[阅读器设置](SETTINGS_GUIDE.md#调整阅读器控制)中选择步进、恒速或加速滚动，以适应密集正文或大页面。

## 搜索正文，跳到标题和图表

按 `/` 打开 Zotero 的 PDF 查找，输入短语后用 `n` / `N` 跳到下一个或上一个结果。`Escape` 清除或关闭查找。要浏览论文结构，按 `<Space>ro` 打开或聚焦 Zotero 原生的大纲（Outline）侧栏，再用其中的条目浏览标题。聚焦阅读器侧栏时，`j` / `k` 移动条目，`Escape` 退出该侧栏的局部交互；再次按侧栏聚焦命令会保持焦点，不会关闭侧栏。

用 `[s` / `]s` 跳到上一个或下一个标题，用 `[f` / `]f` 跳到上一幅或下一幅图，用 `[t` / `]t` 跳到上一张或下一张表。标题来自 PDF 大纲；图表导航优先复用当前所选云端服务的有效本地分析缓存，包含整组图片／表格和题注；没有编号的对象仍可定位。无匹配缓存时，沿用 Zotero 原生结构信息和图注；首次原生分析可能需要等待。导航本身不上传 PDF，也不需要 Token。如果 PDF 没有可用的结构目标，可改用页码导航或文本查找。

按 `<Space>rm`、`<Space>ra` 或 `<Space>rt` 打开或聚焦 Zotero 原生的书签（Bookmarks）、批注（Annotations）或缩略图（Thumbnails）侧栏。各侧栏中的原生标签名称可能随 Zotero 界面语言而异；聚焦侧栏后用 `j` / `k` 移动条目。

## 复制 DOI、批注，或打开链接

在 PDF 的普通模式（Normal）下按 `y`，可以从页面上可见的 DOI、链接、批注摘录和评论中选择要复制的内容；按 `f` 则是打开链接。不需要先用鼠标选中文字。若当前处于文字选择模式（Select），先按 `Escape` 退出；在 Select 中按 `y` 复制的是选中文字。

1. 点击要操作的 PDF 窗格并保持目标可见，再按 `y` 或 `f`。
2. 查看目标旁的字母提示。例如，高亮旁可能同时显示 `A 摘录`（`Excerpt`）和 `S 评论`（`Comment`），它们是两个不同目标。只输入对应字母（大小写均可），不要输入说明文字。每次操作都会重新分配字母；页面拥挤时，提示可能由多个字母组成。
3. 输入完整字母后立即执行并关闭提示，不需要按 Enter。即使只有一个目标也必须确认。按 `Escape` 取消，不会复制内容或打开链接。

复制提示的说明文字表示复制内容：

| 目标提示 | 复制内容 |
| --- | --- |
| `摘录`（`Excerpt`） | 批注引用的摘录文字。 |
| `评论`（`Comment`） | 批注评论；无需先打开评论编辑器。 |
| `DOI` / `arXiv` | 纯标识符；arXiv 的 `v2` 等版本号会保留。 |
| `网址`（`URL`） | 完整的 HTTP(S) URL。 |
| `链接`（`Link`） | 未被识别为标识符或 HTTP(S) URL 的 Zotero 原生外部链接目标。 |

同一批注同时有摘录和评论时，它们会以相邻提示分组显示；某一项为空时会省略该项。摘录中的 DOI 仍是独立目标，因此可以复制整段摘录，也可以只复制 DOI。Neo 不会把摘录和评论合并。

提示会区分复制和跟随。按 Backspace 可修改已输入的字母前缀；无效前缀会重置，不会触发操作。按键自动重复不会确认目标。点击页面或改变焦点会使 Neo 提示失效，但原生点击和文本控件仍按原有方式工作；文本输入和输入法组合输入继续由编辑器接收。

跟随纯 DOI 或 arXiv 标识符时会打开对应的解析器 URL。已有 HTTP(S) URL 会保留其路径、查询参数、片段和字母大小写；PDF 原生链接仍由 Zotero 按内部链接、引文或外部链接的原有方式处理。`f` 不会跟随普通批注摘录或评论；复制和跟随都不会向文库添加条目。

### 提示没出现时

- 提示只来自当前正在看的 PDF 窗格。被隐藏或筛选掉的批注不会显示；阅读模式（Reading Mode）重排后的文字也不提供这种提示。
- Neo 只给能准确定位的内容标字母。扫描页没有可识别的文字层，跨行文本、手写批注或旋转文字等也可能没有提示；但部分原生链接和已有批注仍可能出现。
- 切换页面、修改批注或更改筛选条件后，旧字母可能失效。重新按 `y` / `f` 获取提示即可。页面太密时，可放大窗格或页面再试；取消操作不会改变剪贴板。

Normal 模式下，`Y` 仍会直接复制当前批注的评论。在命令面板搜索**复制批注高亮文本**（`yankAnnotation`），可直接复制当前批注的摘录；此操作没有默认快捷键。自定义绑定（包括显式解除 `y` 绑定）优先于默认按键；若按键行为不同，请查看设置中的**快捷键**。

## 通过标识符添加论文

在 PDF 普通模式下按 `<Space>ai`，或在命令面板中搜索**通过标识符添加条目**，就能打开 Zotero 的标识符输入框。输入 DOI、arXiv ID 等后由 Zotero 查找并导入；Neo 不会自动读取当前 PDF 或剪贴板。

Neo 会切回打开这篇 PDF 的 Zotero 文库窗口，使用那里当前选中的分类作为导入位置。如果该文库窗口已经关闭，独立阅读器中就无法执行此操作。批量导入的按键和限制见[通过标识符添加论文](MAIN_GUIDE.md#用-doi、arxiv-id-等添加论文)。

## 查找和核对参考文献

引用增强跟随当前阅读位置呈现功能：

| 阅读情景 | 操作入口 | 出现的内容 |
| --- | --- | --- |
| 正文引文已有 Zotero 原生预览 | 鼠标悬停引文 | 在每条文献原文下显示**文中引用**、**本地副本**和**论文详情**；分组引文的各条文献分别操作。 |
| 正在核对正文引文或文末参考文献 | 原生右键菜单 | 直接选择当前文献的引用位置、本地副本或论文详情；无法确定目标时，可转到**搜索参考文献**，不会自动挑选附近条目。 |
| 想查找整份 PDF 的参考文献 | 工具栏右侧的**查找参考文献**，或普通模式 `<Space>fr` | 只显示可筛选的参考文献清单；选择一项后再查看该文献的操作。 |

悬停不会抢走键盘焦点或查询元数据。原生单击引文跳转、拖选和双击选词仍由 Zotero 处理；鼠标按钮也可通过 Tab、Enter 和 Space 操作。

**文中引用**或条目操作中的**已识别的本地引用位置**列出整份 PDF 中匹配的提及，包含页码和原文上下文；选择一项会在发起操作的窗格跳转。**跳转到参考文献**返回该文末条目。这些本机操作不需要网络、密钥或 AI，不修改 PDF 或添加批注。

对明确识别的编号参考文献清单，搜索列表也保留没有找到正文提及的条目。**参考文献列表不完整**表示清单可能有遗漏；零个已识别提及不等于该文献未被引用。扫描版或缺少文字层的 PDF 不做 OCR；不受支持或含歧义的格式也可能漏掉条目或提及。

### 查看元数据和外部来源

从条目操作中点击**打开 DOI**、**打开 arXiv**或**网页搜索**访问外部页面；只有存在相应标识符时才显示 DOI 或 arXiv 按钮，不必先查询元数据。这些操作不会自动把论文加入文库。

打开当前文献的**论文详情**只读取缓存，即使首次打开也不会联网；未命中时显示“没有缓存的元数据。请搜索以获取。”。点击**搜索元数据**后先按规范化查询词或标识符查缓存，命中时（包括已过期的结果）不联网，未命中时才请求来源。点击**刷新元数据**会跳过缓存并请求新结果。查询仅发送当前检索词或标识符，不上传 PDF。Semantic Scholar 和 arXiv 返回原始字段及摘要；来源未提供的值保持缺失，不生成摘要，API 计数也不同于本机识别到的引用位置数。

标题查询可能返回多条候选记录。对照标题、作者和年份后，手动选择匹配记录；Neo 不会自动选择第一条。可用**打开来源**或**打开来源 PDF**查看原始记录。Semantic Scholar API 密钥是可选的；没有密钥时仍可匿名查询。密钥的保存位置和 429／离线限制见[设置参考](SETTINGS_REFERENCE.md#引用增强的元数据来源与密钥)。服务返回 429 或不可用时，Neo 会显示状态，不会自动重试。

详情显示来源和原始获取时间，并区分**已获取**、**缓存**、**已过期**。刷新失败时会显示错误，同时保留已有结果、来源和原始获取时间。缓存仅保存成功取得的参考文献元数据，不含 PDF 文本、笔记、坐标或凭据；点击**清除元数据缓存**只清除缓存，不删除文库条目、已采纳记录或密钥。保存位置与容量见[设置参考](SETTINGS_REFERENCE.md#引用增强的元数据来源与密钥)。

### 查找本地副本或添加条目

点击**本地副本**或条目操作中的**查找本地匹配**，可在当前 Reader 所属文库中按标题或标识符查找；检索词可手动修改，再点击**在文库中查找**。此功能离线可用。结果只是待核对的候选，不自动认定为同一论文或打开第一项；选择一项才打开其已有 PDF，不更改该条目。共享历史可用时，打开会记录发起操作的确切窗格和文档，可用 `Ctrl+o` 返回原 PDF 的阅读位置，再用 `Ctrl+i` 前进；不借用主窗口当前选中的条目。候选的 PDF 已删除或无法打开时，面板提示不可用，不会打开别的候选或把焦点抢回旧视图。

只有确认元数据记录后，才点击**添加到 Zotero**。条目会添加到当前 Reader 所属文库。已有 DOI 或 arXiv ID 与该记录完全相符且没有标识符冲突时，Neo 复用并返回该条目，不覆盖已有元数据或另建重复项。结果区分**已创建条目**和**已复用现有条目**，直接列出这次返回的条目，不必再搜索一次；有本地 PDF 时，明确选择该条目才打开，没有时会说明**没有可用的本地 PDF**。添加本身不会切换 PDF，也不会下载附件。只有标题相同而标识符不匹配时，添加会停止；先用本地匹配项人工核对，避免把不同论文当作同一条目。只读或不可用的文库不能添加。添加不是自动采纳、推荐或引用。

点击**关闭**或按 Escape 会回到仍可用的来源窗格；点击浮层外部或滚动原文也会退出。切换或关闭来源视图会取消在途查询，过期结果不能继续跳转或添加。长摘要可在详情内部滚动，不会因此退出；Tab 不被限制在整个阅读器的浮层中。

## 摘录图表与公式并保存到笔记

在命令面板搜索**摘录图表与公式**，打开当前 PDF 的对象列表。先核对整组图表、题注和页码；关联不完整时，可切换到**独立主体（关联纠错）**选择需要的部分。预览只显示原 PDF 的局部图像，不滚动原文；打开列表、预览和保存不会上传 PDF 或请求模型。没有可用结构或无法读取来源时，会提示不可用。

按 Enter 或点击**复制图文与来源**可复制图像、题注和原文链接。**复制结构文本**只在已有表格或公式结构时可用；这些结构文本需要自行对照原文核验，不是重新调用模型。

点击**保存为新笔记**后，列表保留当前对象，并显示**已创建笔记**或**已复用现有笔记**及笔记标题；失败会明确提示，不自动跳走。重复保存同一 PDF 版本的同一对象会复用已有笔记，不覆盖后来手工修改的正文，也不追加重复摘录。笔记归属于列表中显示的论文；独立 PDF 则创建独立笔记，保留来源关系和原文页码链接。

保存成功后，点击**打开笔记**才进入这份笔记，无需到文库重新寻找。笔记中的来源链接可回查 PDF；共享历史可用时，可在原文与笔记之间后退／前进。笔记被删除、无法访问或来源视图失效时会提示不可用，不打开其他笔记。关闭或取消列表只恢复仍有效的来源窗格，旧视图的迟到结果不会抢走新视图的焦点。

## 解释选区和询问论文

在 PDF 普通模式按 `<Space>aa` 打开 **AI 问答（实验）**。主窗口标签页中的 PDF 使用右侧原生面板；独立阅读器打开绑定这篇 PDF 的工具窗，不压缩阅读区。再次打开会聚焦同一个工具窗；关闭阅读器时，它的工具窗也会关闭。该实验默认关闭；若入口不可用，在[模块设置](SETTINGS_GUIDE.md#开关可选功能)中明确启用 `ai-qa` 并完全重启 Zotero。旧版 `reader-ai` 启用偏好不会自动开启新实验。`<Space>ai` 仍是标识符录入，不是 AI 入口。

1. 点击**配置 AI 服务**，选择服务实际支持的 **OpenAI Chat Completions** 或 **OpenAI Responses** 协议，填写基础 URL、模型 ID 与 API 密钥，再点击**保存设置**。服务须支持 JSON Schema 结构化输出；这里填写 API 基础地址，不是聊天网页或单次请求地址。地址要求 HTTPS，本机回环服务可用 HTTP。密钥保存在 Zotero 本机密码管理器，已有密钥不会回显；配置细节见[设置参考](SETTINGS_REFERENCE.md)。
2. 从 PDF 选择需要解释的文字，进入 Select 后按 `a` 或 `Enter` 打开所选文本操作，选择解释动作。也可以带着选区打开 AI 问答（实验），点击**解释选区**。
3. 在**问题**中输入问题，点击**就选区或章节提问**。有已捕获选区时使用该选区；没有选区时可准备当前章节的有限证据。若要更换选区，从 PDF 重新选择文字后打开面板。

当前输入仅限当前 Reader 的文字选区或有限章节证据；不会检索批注、笔记或其他论文，也不自动上传整份 PDF。普通打开只读取本机成果和已有文档缓存，不调用模型。生成时，相关原文与问题会发送到已配置的模型服务。默认不发送图像；只有明确勾选允许发送图表局部图像时，才会附带最多四幅相关原 PDF 裁图，所选模型也须支持图像输入。

### 准备章节的图文导引

已有章节列表时，先选择**章节或小节**，再点击**准备章节证据并请求导引**。没有结构缓存时，首次请求会先在本机准备证据；此后可选择其他章节，切换章节本身不会调用模型。每次最多纳入 40 条、32,000 字符的有限证据，不是全文分析；关联图表或表格裁图只会在明确允许发送图像后加入请求。没有表格结构或图像时，不应把题注解释当成模型已经读懂表格。

生成原稿的每个段落显示它实际引用的证据入口，而不是把整份证据列表当作该段来源。先点**预览原文**核对上下文，PDF 不会因此滚动；点击**确认跳转来源**才定位到发起操作的确切 PDF 窗格。缺失或无效证据标为不可用。来源标记区分**文字范围**与**页面区域**；文字范围不承诺 PDF 字符级定位，页面区域只表示可回查的区域。可定位来源只说明出处仍可查，不代表生成结论已得到语义核实；请对照原文和图表自行判断。固定人工核验用例见[验收指南](ACCEPTANCE.md#u10-ai-问答实验来源与持久成果)。

### 重开成果、修改和采纳

完整且通过格式与引用检查的结果会自动保存。关闭助手后，再从同一 PDF 打开即可查看，不必重新请求。关闭界面不等于取消请求；需要停止时点击**取消**，未完成输出不会保存。请求失败不会自动重试或切换服务。

点击**编辑我的文本**，修改后点击**保存修订**；**查看生成原稿**仍可核对未改动的生成内容。人工修订单独显示，不自动附上生成原稿的段落引用。新请求另存一份结果，不覆盖人工修订。记录保存在本机，不能视为已经进入 Zotero 同步；PDF 内容更换后保留旧记录，但不再用旧位置预览、跳转或采纳。

确认需要保留到文库时，点击**另存为新笔记**，生成带原文来源和页码链接的 Zotero 笔记。面板显示**已创建笔记**或**已复用现有笔记**，并提供**打开笔记**；重新打开成果也能找回当前修订已采纳的笔记。重复采纳同一修订会复用已有笔记，不覆盖后来手工修改的正文；保存新修订后需单独采纳。笔记被删除、移入回收站或无法访问时会提示不可用。

用于识别已有笔记的[内部标记](NOTE_GUIDE.md#来源笔记的内部标记)由 Neo 自动管理，不必在日常标签界面维护。采纳不自动创建 PDF 批注。**删除成果**只删除这份本机结果及其人工修订，不会删除已创建的 Zotero 笔记。

## 对照论文的两处内容

按 `Space` 后按 `-` 可水平分屏，按 `Space` 后按 `|` 可垂直分屏；每个窗格都能显示 PDF 的不同位置。用 `Ctrl+h` / `Ctrl+l` 聚焦左侧或右侧相邻窗格，用 `Ctrl+j` / `Ctrl+k` 聚焦下方或上方窗格，然后分别移动当前视图。聚焦命令只能切换到已存在且受支持的窗格；要创建对照布局，请使用分屏命令。

后退/前进会恢复可用的 PDF 阅读位置，但保持当前缩放比例和分屏布局不变。同一 PDF 打开了多个标签页时，优先返回记录中的原标签页和原窗格，不会把另一副本移到这个位置；原标签页已不可用时才查找同一附件的其他标签页或重新打开。若记录的是次窗格而目标已没有次窗格，会提示无法完整恢复，不改用主窗格。

## 给阅读位置做标记

按 `m` 后接小写字母或数字，为当前位置设置阅读器标记；按反引号后接该标签可返回。用 `[m` / `]m` 按文档顺序浏览标记，或按 `<Space>rm` 打开书签侧栏。按 `dm` 后接标签可删除一个标记，按 `dM` 清除全部标记。

在[阅读器设置](SETTINGS_GUIDE.md#调整阅读器控制)中开启**持久化标记**，可让标记在重启 Zotero 后保留；未开启时，标记仍可在当前会话中使用。用 `Ctrl+o` / `Ctrl+i` 浏览已记录的位置。[共享历史](SEARCH_GUIDE.md#共享后退与前进历史)说明阅读器跳转如何与文库及笔记导航衔接。

开启**持久化标记**时，同一 PDF 的多个阅读器共享新增、删除和清空操作；保存按顺序执行，同一论文下不同 PDF 的标记不会互相覆盖。运行中开启此设置也会连接已打开的阅读器。关闭后各阅读器保留自己的会话副本，不再写入持久存储，也不保证关闭后重开恢复。

## 一种常用的阅读方式

例如读一篇方法论文时，可以先跳到方法章节，再打开分屏，把实验结果留在另一侧。遇到需要反复核对的段落，按 `m` 加一个字母做标记；之后随时跳回来。选中文字和添加高亮的方法见[文本选择与批注](SELECTION_GUIDE.md#从一段文字开始)。
