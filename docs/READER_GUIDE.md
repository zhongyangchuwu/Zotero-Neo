# PDF 阅读与批注

打开 PDF 后，先点击要操作的页面或窗格。搜索框、批注评论框和侧栏有焦点时，按键可能由 Zotero 或输入控件处理。下面列出默认快捷键；如果修改过绑定，以[设置](SETTINGS_GUIDE.md)中的快捷键为准。

## 开始分屏阅读

1. 打开 PDF，点击页面，先按下并松开 `Space`，再按 `-`，将阅读器分成上下两个窗格。按 `Space` 后再按 `|` 可切换左右分屏。
2. 用 `Ctrl+j` / `Ctrl+k` 聚焦下方或上方窗格，用 `Ctrl+h` / `Ctrl+l` 聚焦左侧或右侧窗格，再分别移动视图。这些按键只切换已有的相邻窗格，不创建窗格。

## 翻页、滚动和缩放

`j` / `k` 向下或向上滚动，`h` / `l` 翻到上一页或下一页；`Ctrl+d` / `Ctrl+u` 移动半屏，`Ctrl+f` / `Ctrl+b` 移动一屏。可以在前面输入计数，例如 `3j` 移动三次滚动步长。

`gg` 回到第一页开头，`G` 到文档底部。若 Zotero 支持直接跳页，在 `gg` 或 `G` 前输入正整数可跳到从 1 开始计数的页码，例如 `5G` 跳到第 5 页；否则两者滚动到文档两端并忽略计数。

`+` / `zI` 放大，`-` / `zO` 缩小，`=` / `z0` 恢复适合页面宽度。放大后可用 `zh` / `zl` 左右平移。滚动方式和步长可在[阅读器设置](SETTINGS_GUIDE.md)中调整。

按 `Ctrl+o` / `Ctrl+i` 在可恢复的位置之间后退或前进。普通滚动和缩放不单独记入[跳转历史](MAIN_GUIDE.md#切换标签页和返回)；要准确回到当前段落，请先记个标记。

## 搜索正文，跳到标题和图表

在 Reader 普通模式（Normal）按 `/` 打开 Zotero 的 PDF 查找，输入文字后用 `n` / `N` 跳到下一个或上一个结果，`Escape` 清除或关闭查找。这是全文查找；下方 Flash 只查找当前视图中的可见文字。

按 `[s` / `]s` 浏览上一个或下一个标题，标题来自 PDF 的原生大纲。按 `[f` / `]f` 浏览图，`[t` / `]t` 浏览表；图表目标取决于可用的结构信息，首次本地处理可能需要等待。没有可用目标时，可按页码导航或搜索文字。

要在某一节内查字词，用 `<Space>rs` 选择章节范围再搜索；要在多张图表之间筛选并先看预览，用 `<Space>rf`。确认目标才跳转。

`<Space>ro` 打开或聚焦大纲（Outline），`<Space>rm`、`<Space>ra`、`<Space>rt` 分别打开或聚焦书签、批注和缩略图侧栏。侧栏中用 `j` / `k` 移动条目，`Escape` 退出局部交互；重复执行聚焦命令不会关闭侧栏。

滚动 PDF、EPUB 或网页快照时，大纲会标出当前章节。有页内坐标的 PDF 可以区分同页小节；折叠的小节只高亮可见的上级，不会替你展开。鼠标停在大纲上时，侧栏不会自动滚动。

## 给阅读位置做标记

按 `m` 后接一个小写字母或数字，例如 `ma`，为当前位置设置标记；按反引号再按同一标签可返回。`[m` / `]m` 按文档顺序循环浏览标记；`dm` 后接标签删除一个，`dM` 清除该 PDF 的全部标记。书签侧栏中可用 `j` / `k` 选择、`Enter` 跳转、`d` 删除所选标记，或用 `x` 清空。

标记属于当前 PDF，不是跨 PDF 的大写全局标记。跨文档返回可使用 `Ctrl+o` / `Ctrl+i` 共享历史；历史取决于目标是否可恢复。

在[阅读器设置](SETTINGS_GUIDE.md)中开启**持久化标记**后，标记可在重启后恢复，同一 PDF 的多个阅读器共享增删操作；不同 PDF 的标记分别保存。未开启时标记只保留在当前阅读器会话，关闭后不保证恢复。保存失败时会有提示；若关联的批注已不存在，跳转仍会尝试恢复记录的位置。

## 从一段文字开始

1. 点击 PDF 正文，按 `v` 进入文本选择模式（Select），输入当前视图中可见的词或短语。输入对应字母提示选择位置，或按 `Enter` 选择最近的匹配项。
2. 按 `zy` 为选区添加黄色高亮，或按 `y` 复制文字。需要退出 Select 时按 `Escape`。

Flash 匹配可见文字，支持 Unicode 和输入法输入。部分单词会扩展为完整词元，短语会扩展到首末完整词元，标点可单独选择；查询中有 ASCII 大写字母时区分大小写，否则忽略大小写。匹配目标超过 48 个时继续输入以缩小范围。按 `Escape` 取消本次 Flash 查找并保留之前的选区。

Flash 需要可选择的文字层，不提供 OCR。扫描页或当前视图中不可见的文字无法这样查找；可用 `/` 搜索全文，或先用其他工具为扫描 PDF 准备文字层。

## 调整选中的文字范围

Neo 也可接管已有的 Zotero 原生文字选区。在 Select 中，`h` / `l` 按词元调整活动端，`j` / `k` 移到相邻视觉行并吸附到词元边界；标点可单独选择。`H` / `L` 按字符微调，`w` / `b` 按浏览器词边界移动，`0` / `$` 移到行首或行尾。

按 `o` 交换锚点与活动端；按 `s` 再用 Flash 选择另一端，原锚词和目标词会完整保留。`)` / `(` 按句子扩展，`}` / `{` 按段落扩展；原文无法可靠匹配时会使用原生段落或词元退路，边界有歧义时请核对原文。

选区中的 `y` 复制文字并规范化换行和空白，`#` 查找选中文字。`zy`、`zr`、`zg`、`zb`、`zp` 分别创建黄色、红色、绿色、蓝色和紫色高亮。按 `a` 或 `Enter` 打开选区操作，可选择添加下划线或批注评论；`za` / `i` 也可创建批注并打开评论编辑器。

第三方插件可以通过[公开选区 API](DEVELOPMENT.md#reader-选择-api)为这个面板注册操作。

文字批注支持一页内或相邻两页中可完整定位的选区。范围过大或部分文字无法定位时，选区会保留；缩小范围重试，或先按 `y` 复制文字。

## 查找和管理已有批注

在 Normal 中按 `[a` / `]a` 选择上一条或下一条批注，或按 `<Space>ra` 打开批注侧栏。选中后，`Y` 复制评论；在命令面板搜索**复制批注高亮文本**可复制摘录，该操作默认没有快捷键。Normal 中的 `y` 也可通过提示选择可见批注的摘录或评论。

`zy`、`zr`、`zg`、`zb`、`zp` 可更改选中批注的颜色；`Zy`、`Zr`、`Zg`、`Zb`、`Zp` 按颜色筛选，`Za` 清除筛选。`dd` 确认后会永久删除选中的批注，无法撤销；确认提示中按 `Escape` 可取消。

## 编辑批注评论

单击侧栏批注或文内批注浮层只读评论中带蓝色下划线的网址即可打开。支持裸 HTTP(S) 地址和受支持的 `zotero://` 内部地址。单击普通文字或空白处仍按 Zotero 原有方式进入编辑。

选中批注，并在[阅读器设置](SETTINGS_GUIDE.md)中启用**批注评论编辑**后，按 `i` 或 `Enter` 打开评论编辑器。普通输入写入评论，`Enter` 换行；输入法组字时，`Escape` 先由输入法处理。

输入后立即保存本机草稿，停止输入约两秒后自动尝试保存到 Zotero 批注。普通 `Escape` 会提交最后的草稿并关闭编辑器，不是放弃修改。关闭 PDF 视图或阅读器前先按 `Escape` 提交；不要依赖销毁视图补存未保存文字。已经接纳的保存可以在视图关闭后完成。

本机草稿可在重开视图、Reader 或重载 Neo 后恢复，范围是当前 Zotero 配置文件。保存失败时可点击**重试**；如果批注已在别处修改，先核对，再选择**覆盖**或**丢弃草稿**。出现“本机草稿保存失败”时，保持 Zotero 开启并重试或复制文字；强制关闭视图时会弹出草稿供复制。重启或停用前，请确认草稿已持久保存。

## 复制 DOI、批注，或打开链接

启用[链接与复制提示](SETTINGS_GUIDE.md)后，在 PDF 的 Normal 中按 `y`，可从当前窗格可见的 DOI、arXiv ID、网址、批注摘录和评论中选择要复制的内容；按 `f` 可打开可见链接或标识符。Select 中的 `y` 则复制选中文字。

1. 点击要操作的 PDF 窗格，保持目标可见，再按 `y` 或 `f`。
2. 输入目标旁显示的完整字母提示，大小写均可。摘录和评论是不同目标；只输入字母，不输入旁边的说明文字。即使只有一个目标也需要输入提示。
3. 输入完整提示后立即执行，无需按 `Enter`。`Backspace` 修改已输入的前缀，`Escape` 取消；每次重新打开提示时字母可能不同。

复制 DOI 或 arXiv 时得到标识符，复制网址时得到完整 URL。跟随 DOI 或 arXiv 会打开对应解析器；原生内部链接、引文和外部链接仍由 Zotero 处理。`f` 不跟随普通批注摘录或评论，复制和跟随也不会向文库添加条目。

提示只来自当前 PDF 窗格中可定位的内容；隐藏的批注、没有可识别文字层的扫描页或复杂文字布局可能没有提示，Reading Mode 重排文字也不提供这些提示。切换页面、修改批注或筛选后，重新按 `y` / `f` 获取提示。取消不会改变剪贴板。

## 查找和核对参考文献

启用引用增强后，可在正文引文的 Zotero 原生预览中查看**文中引用**、**本地副本**和**论文详情**，或从原生右键菜单选择当前文献的操作。按 `<Space>fr` 或点击工具栏的**查找参考文献**，可筛选整份 PDF 的参考文献清单，再选择一项操作。

**文中引用**列出已识别的正文提及、页码和上下文；选择一项会跳到发起操作的窗格，**跳转到参考文献**可返回文末条目。本机定位不需要网络，不修改 PDF 或添加批注。

扫描版或缺少文字层的 PDF 不做 OCR，不受支持或含歧义的格式也可能漏掉条目或提及。编号清单即使连续也不保证完整，未找到正文提及不等于文献未被引用；请对照原文核对。

### 查看元数据和外部来源

**论文详情**先读取缓存；明确点击**搜索元数据**或**刷新元数据**后才可能查询外部来源。标题搜索结果是候选，须核对。也可按可用标识符选择**打开 DOI**、**打开 arXiv**或**网页搜索**；打开外部页面不会自动导入。查询来源和可选密钥见[引用设置](SETTINGS_GUIDE.md#引用增强的元数据来源与密钥)。

### 查找本地副本或添加条目

点击**本地副本**或**查找本地匹配**，在当前 Reader 所属文库中按标题或标识符查找。结果是待核对的候选，明确选择后才打开已有 PDF；共享历史可用时可按 `Ctrl+o` 返回原位置。

确认元数据后可点击**添加到 Zotero**。完全匹配且无标识符冲突的现有条目会被复用，不会覆盖已有元数据；仅标题相同而标识符不匹配时会停止添加，需先人工核对。添加不会自动打开或下载 PDF，只读或不可用的文库不能添加。

## 其他阅读器操作

在 Normal 中按 `<Space>rr` 切换 Zotero 原生 Reading Mode；重排正文仍支持 Flash、选区调整和文字批注。精确 PDF 位置及依赖 PDF 文本层或链接叠加层的提示适用于 PDF 视图。

按 `<Space>ai` 可在关联的 Zotero 文库窗口打开原生标识符输入框，再输入 DOI 或 arXiv ID；不会自动读取 PDF 或剪贴板。文库窗口已关闭时，独立阅读器不能执行此操作。更多快捷键见[命令参考](COMMAND_REFERENCE.md)。
