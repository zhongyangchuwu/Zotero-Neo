# 命令与快捷键速查

以下为默认绑定；自定义设置、当前焦点和功能开关会影响可用按键。Reader 指阅读器，Main 指主窗口，Note 指笔记编辑器。操作还需要有效目标，例如当前条目或选中的批注。

更多操作见[文献库与工作区指南](MAIN_GUIDE.md)、[阅读器指南](READER_GUIDE.md)和[设置与偏好](SETTINGS_GUIDE.md)。

## 按键记法与输入规则

- 按键区分大小写：`g` 与 `G` 不同，`gg` 表示连续按两次 `g`。`<Space>` 是空格，`<C-d>` 是 Ctrl+d，`<Esc>` 是 Escape，`<BS>` 是 Backspace；`<Enter>` 与 `<Return>` 表示同一按键。Ctrl 与 Meta 统一按 Ctrl 处理。
- 部分命令前可输入数字计数。`0` 只有跟在已有计数后才是计数的一部分，否则是独立按键；计数可能表示重复次数、指定位置，也可能被忽略，见各表说明。
- 输入未完成的序列时，`<Esc>` 先取消序列和计数；`<BS>` 先删除末键，再逐位删除计数。短绑定同时是长绑定前缀时，稍等会执行短绑定，继续输入可匹配长绑定。
- 文字输入框及输入法组合保留原生输入行为；同一按键在不同模式和界面中可能有不同作用。输入问题见[常见问题与排查](TROUBLESHOOTING.md)。

## 命令面板、重映射与未绑定操作

在 Main、Reader 或 Note 的 Normal 模式按 `:` 打开命令面板，可搜索当前可用的操作，包括未绑定快捷键的操作。方向键选择，`<Enter>` 执行，`<Esc>` 关闭；面板不接收参数或计数。安装并启用 Actions & Tags 后，其可用的已命名动作也会出现在面板中。

查询自定义绑定、录制或解决冲突，见[修改快捷键](SETTINGS_GUIDE.md#修改一个快捷键)。

## 共享操作

下表适用于 Main、Reader 和 Note Normal，特殊范围另行注明。`<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` 在 Note Insert 中也可用。

| 默认按键 | 操作 |
| --- | --- |
| `:` / `<Space>ps` / `<Space>pp` | 打开命令面板、设置或 Plugin Manager。 |
| `<Space>ff` / `<Space>fc` / `<Space>fn` | 查找文库条目、当前分类条目或笔记。 |
| `<Space>,` / `H` / `L` / `<Space>q` | 选择标签页、切换上一个/下一个标签页、关闭当前标签页；`H` / `L` 忽略计数。关闭已分组的标签页会移除其成员关系。 |
| `<C-o>` / `<C-i>` | 沿共享跳转历史后退/前进；支持计数，例如 `2<C-o>`。 |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | 向左/下/上/右聚焦最近的可用窗格，不循环，也不创建窗格。 |
| `<Space>ta` / `<Space>tr` | 为当前上下文目标添加/移除标签。 |
| `<Space>yy` | 复制当前上下文目标的 citekey。 |
| `<Space>bb` / `<Space>bt` | 聚焦或收起/展开标签页侧栏；须启用标签页增强。 |

关于哪些位置会记入历史、关闭 PDF 后如何返回，见[切换标签页和返回](MAIN_GUIDE.md#切换标签页和返回)。

## 主窗口

Main Normal 中，焦点决定命令作用于分类树还是条目列表；可编辑字段保留原生输入。条目操作通常优先使用非空 Neo 选择集，否则使用当前操作的临时目标或条目游标。Neo 选择集不跨重启保存，且与 Zotero 原生多选及分类树选择不同。目标规则与完整流程见[文献库与工作区指南](MAIN_GUIDE.md)。

| 默认按键 | 操作 |
| --- | --- |
| `j` / `k` | 在分类树或条目列表上下移动；支持计数。 |
| `gg` / `G` | 到首行/末行；`G` 前的正数指定从 1 开始的行，`gg` 始终到首行。 |
| `h` / `l` / `<BS>` | 折叠分类或转到父级 / 展开分类或聚焦条目列表 / 转到父级；在条目列表按 `h` 返回分类树。 |
| `za` / `zo` / `zc` | 切换、展开或折叠当前分类。 |
| `R` / `M` | 展开/折叠文库树中的所有分类。 |
| `e` / `wh` / `wl` / `ww` | 聚焦分类树、左窗格、右窗格或条目列表。 |
| `<Enter>` / `o` | 激活分类或打开当前条目 / 打开条目游标所在的条目或 PDF；`o` 不批量打开选择集。 |
| `/` / `n` / `N` | 在获得焦点的条目列表中查找可见行 / 查找下一个或上一个结果；`n` / `N` 每次只移动一次。 |
| `<Space>fq` / `<Space>fa` | 聚焦 Zotero Quick Search / 打开 Advanced Search，与 `/` 内部查找不同。 |
| `s` / `v` / `<Esc>` | 切换当前条目的选择集成员资格 / 开始临时范围选择 / 取消临时范围或原生多选；取消不会清空选择集。 |
| `<Space>ss` / `<Space>sc` | 打开选择集面板 / 清空 Neo 选择集。 |
| `dd` 或 `x` / `u` | 确认后将目标移入回收站 / 恢复 Neo 最近一次移入的条目批次。隐藏的选择集成员会阻止移入回收站。 |
| `<Space>ta` / `<Space>tr` / `<Space>tf` / `<Space>tc` | 添加/移除标签、切换标签筛选、清除标签筛选。 |
| `<Space>ca` / `<Space>cr` | 添加/移除同一文库中条目与分类的直接成员关系。Reader 使用当前条目；Note 不提供这两个操作。 |
| `<Space>ai` | 在可写文库及当前分类打开 Zotero 原生标识符录入；不使用条目选择集。Reader 中使用关联主窗口的范围。 |
| `<Space>pa` / `<Space>ia` | 管理自定义属性 / 编辑当前有效条目的属性；须启用条目自定义属性。 |
| `<Space>bc` / `<Space>ba` | 创建阅读分组 / 向现有分组添加目标 PDF；须启用标签页增强并重启。确认后打开所选 PDF 并将成功打开的视图加入分组。 |

Main Select 中，`j` / `k` 扩展范围，`gg` / `G` 扩展到首行/末行（`G` 可带行号），`o` 交换两端，`s` 提交，`v` / `<Esc>` 取消。分类查找、移动、新建、重命名和删除等未绑定操作可通过命令面板查找；删除分类会保留条目，但 `u` 不能撤销分类结构变更。

## Reader 普通模式

| 默认按键 | 操作 |
| --- | --- |
| `j` / `k` / `zh` / `zl` | 上下滚动或水平平移；计数按倍数增加步长。 |
| `h` / `l` | 上一页/下一页；计数重复翻页。 |
| `<C-d>` / `<C-u>` / `<C-f>` / `<C-b>` | 向下/上移动半屏或整屏；支持计数。 |
| `gg` / `G` | 到文档首/末；Zotero 支持页码导航时，`5gg` 或 `5G` 到第 5 页。否则滚动到文档边界并忽略计数。 |
| `+` 或 `zI` / `-` 或 `zO` / `=` 或 `z0` | 放大、缩小、重置缩放；前两者支持计数。 |
| `zt` / `zz` | 将当前页面放在视口顶部/中央。 |
| `/` / `n` / `N` / `<Esc>` | 打开 PDF 查找、下一个/上一个结果、清除或关闭查找；`n` / `N` 忽略计数。 |
| `f` / `y` | 为当前视图中可见链接显示跟随提示 / 为可复制的标识符、外部链接或批注内容显示复制提示。 |
| `[s` / `]s`，`[f` / `]f`，`[t` / `]t` | 上一个/下一个标题、图或表；图表目标取决于 PDF 中可识别的内容。标题导航在 Reader 各侧栏也可用。 |
| `<Space>rf` / `<Space>rs` | 筛选与预览图表 / 在所选章节范围内查找文字。 |
| `[a` / `]a`，`[m` / `]m` | 上一个/下一个批注或阅读位置标记，到边界时循环。 |
| `m` 后接小写字母或数字 / 反引号后接标签 | 设置标记 / 跳到该标记；`dm` 后接标签删除一个，`dM` 删除全部。 |
| `<Space>ro` / `<Space>rm` / `<Space>ra` / `<Space>rt` | 打开或聚焦目录、书签、批注或缩略图侧栏。 |
| `<Space>-` / <code>&lt;Space&gt;&#124;</code> | 切换水平/垂直分屏。 |
| `<Space>rr` / `<Space>fr` | 切换 Zotero Reading Mode / 查找参考文献；后者须启用引用功能。 |
| `v` | 在启用文本选择模式时进入 Reader Select。 |
| `i` 或 `<Enter>` / `dd` / `Y` | 编辑选中批注的评论 / 确认后删除选中批注 / 复制选中批注的评论。 |
| `zy` / `zr` / `zg` / `zb` / `zp` | 将选中批注改为黄、红、绿、蓝、紫色。 |
| `Zy` / `Zr` / `Zg` / `Zb` / `Zp` / `Za` | 按黄、红、绿、蓝、紫色筛选批注 / 清除颜色筛选。 |

评论编辑开启时，框内 `<Enter>` 换行，`<Esc>` 保存并关闭。关闭该设置后，Reader Normal 的 `i` 让按键交给原生输入。详见[编辑评论](READER_GUIDE.md#编辑批注评论)。

## Reader Select 与批注操作

启用文本选择模式后，在 Reader Normal 按 `v` 使用 Flash 选择文本；已有可用原生选区时也可直接使用。输入可见文字并选择提示，或按 `<Enter>` 选择最近匹配，`<Esc>` 取消 Flash 并保留已有选区。Reader Select 的按键忽略计数。

| 默认按键 | 操作 |
| --- | --- |
| `s` | 用 Flash 选择另一端，保留锚点。 |
| `j` / `k` / `h` / `l` | 按视觉行或词元调整活动端；`H` / `L` 按字符精调。 |
| `w` / `b` / `0` / `$` | 移到下一词/上一词、行首/行尾。 |
| `)` / `(` / `}` / `{` | 按句或段落边界调整选区。 |
| `o` | 交换选区锚点和活动端。 |
| `zy` / `zr` / `zg` / `zb` / `zp` | 为选区创建黄、红、绿、蓝、紫色批注。 |
| `za` 或 `i` / `y` / `#` | 新建批注并编辑评论 / 复制选区文字 / 搜索选中文字。 |
| `a` 或 `<Enter>` | 打开选区操作面板，可选择下划线或添加批注评论等操作。 |
| `v` 或 `<Esc>` | 退出 Select。 |

选区操作面板中，方向键或 `j` / `k` 移动，`<Home>` / `g` 和 `<End>` / `G` 到首项/末项，`1` 至 `9` 或 `<Enter>` 执行；`<Esc>` 关闭面板并保留选区。

## Note 编辑器

启用**Vim 风格笔记编辑**后，Note Normal 可使用下列按键；`i` 进入 Insert，`<Esc>` 返回 Normal。Insert 中的文字和输入法由 Zotero 编辑器处理。Note 的共享操作使用当前笔记上下文，不使用 Main 选择集。

| 默认按键 | 操作 |
| --- | --- |
| `h` / `j` / `k` / `l` | 按字符/行移动光标；支持计数。 |
| `w` / `b` / `0` / `$` / `gg` / `G` | 移动到词、行或文档边界；除 `gg` / `G` 外支持计数。 |
| `i` / `a` / `A` / `I` / `o` / `O` | 在当前位置、光标后、行尾、行首或新建的下/上行进入 Insert。 |
| `x` / `dd` / `yy` | 删除字符、删除当前行、复制当前行；`x` 支持计数。 |
| `dh` / `dj` / `dk` / `dl` / `dw` / `db` / `d0` / `d$` / `diw` | 按方向、词或行边界删除，或删除内部词。 |
| `yh` / `yj` / `yk` / `yl` / `yw` / `yb` / `y0` / `y$` / `yiw` | 按相应范围复制。 |
| `ch` / `cj` / `ck` / `cl` / `cw` / `cb` / `c0` / `c$` / `ciw` | 按相应范围替换并进入 Insert。 |
| `p` / `P` / `u` / `<C-r>` | 在光标后/前粘贴 Note 寄存器、撤销/重做。 |
| `<Space>o` / `<Space>e` | 打开 Note 上下文条目 / 聚焦 Main 分类树。 |

复制会更新 Note 寄存器和系统剪贴板；删除或替换更新 Note 寄存器，`p` / `P` 粘贴其中内容。`d` / `y` / `c` 操作符及撤销、粘贴忽略计数。

### Plugin Manager

按 `<Space>pp` 打开。筛选框中的 `<Esc>` 返回结果列表；以下按键用于结果列表。

| 默认按键 | 操作 |
| --- | --- |
| `j` 或 `<Down>` / `k` 或 `<Up>` / `gg` 或 `<Home>` / `G` 或 `<End>` | 移动或跳到首项/末项。 |
| `<C-d>` / `<C-u>` / `/` / `<Esc>` 或 `q` | 向下/上翻页、筛选、关闭。 |
| `r` / `i` | 重新读取已装列表（不检查更新）／在面板内打开安装输入框。输入来源或用方向键选精选扩展；多安装包时用方向键选择。`Enter` 继续或确认，`Esc` 取消。 |
