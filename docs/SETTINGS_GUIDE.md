# 修改 Neo 设置

在主窗口、阅读器或笔记的普通模式下，按 `<Space>ps` 打开 Neo 设置。主题、滚动等设置通常会立即保存；修改快捷键后要点击**应用绑定**。关闭或开启可选功能后，还需要点击**保存模块请求**并重启 Zotero。

## 修改一个快捷键

1. 依次按 `Space`、`p`、`s` 打开 Neo 设置。
2. 进入**快捷键**，选择命令所属上下文，再按动作或按键搜索。例如，翻页属于 Reader，不属于 Main 或 Note。
3. 用**录制**替换绑定，或用**添加**保留原绑定并增加另一组按键。输入按键或序列后，点击**完成**加入草稿；录制时点击**取消**放弃捕获的按键。
4. 检查校验消息，再点击**应用绑定**。应用前只是草稿；保存后的非默认绑定标为**自定义**。

录制时，`Enter` 和 `Escape` 是要记录的按键，不是录制器控制。请使用界面上的**完成**和**取消**按钮。

## 找到命令和当前快捷键

输入多键命令的前缀后，**前缀提示**列出可用的后续按键。主窗口、阅读器和笔记 Normal 默认使用 `<Space>` 作为命令前缀。按 `:` 打开命令面板，搜索当前上下文可用的动作，包括支持但尚未绑定的动作。

在**快捷键**中展开**前缀提示**，可以开关提示，调整**显示延迟（ms）**和**字号（px）**。

快捷键搜索覆盖动作名称、ActionId、当前与默认按键、分组和上下文，结果标明默认、自定义或未绑定。未绑定动作只可加入其支持的上下文。选择所有分组可查看 Zotero 原生快捷键；这些条目只读，修改 Neo 绑定不会改变原生快捷键。

关闭任一可选模块后，其对应动作及用户绑定仍保留在设置中，但不参与当前按键匹配、前缀提示或命令面板；重新启用不需要重建绑定。核心模块没有关闭开关。

## 遇到快捷键冲突

- 完全重复的绑定、不支持的动作/上下文组合，以及 Zotero 或文本编辑保留的按键会阻止应用。请更换序列或删除冲突条目。
- 一个序列是另一序列的前缀时，较短命令可能等待后续按键。这种组合允许保存；需要立即执行时，请换用不同序列。
- 已有的不兼容绑定可能只允许删除。先删除旧条目，再分配替代绑定。
- 保存失败时，草稿保留，设置会报告失败。

## 调整外观和语言

Neo 面板默认跟随 Zotero 的背景、文字、边框和强调色，并随宿主明暗切换更新。普通选中行使用中性底色，焦点、操作反馈和模式标记保留必要的颜色区分。

在**外观 → 交互配色**中选择 Zotero、Catppuccin、Tokyo Night、Gruvbox 或自定义配色，仅调整 Neo 的交互标记和状态提示，不改变面板主题或 Zotero 原生批注颜色。**标记宽度（px）**调整 Main 条目标记，**状态样式**可选中性或着色；已有自定义配色继续保留。

在**高级**中，将**语言**设为跟随 Zotero、English 或中文。它控制设置界面，以及前缀提示、命令面板和快捷键中的本地化动作标签；跟随 Zotero 使用宿主语言。

## 调整阅读器控制

在**阅读器**中选择**滚动模式**：

- **步进**：每次 `j`、`k`、`zh` 或 `zl` 移动固定距离，通过**滚动步长（px）**调整。
- **恒速**：按住滚动键时保持固定速度，通过**滚动速度（px/s）**调整。
- **加速**：按住时改变速度，可调整初始速度、最大速度、加速度和减速度。开启**松开按键时立即停止**后，不再逐渐减速。

界面只显示当前模式的参数。开启**持久化标记**可跨重启保存 marks；存储和同步规则见[设置参考](SETTINGS_REFERENCE.md)。**默认颜色**用于没有明确指定颜色的下划线和添加批注评论。

**文本选择模式**控制 `v` 和原生 Zotero 文本选择能否进入 Reader Select。**批注评论编辑**控制阅读器 Normal 的 `i` / `Enter` 是否打开选中批注的评论编辑器；关闭后不影响 Zotero 原生评论字段或 Select 中独立的“添加批注评论”动作。

## 调整笔记和选择器

新配置默认使用 Zotero 原生笔记编辑；要使用 Vim 按键，在**交互**中开启**Vim 风格笔记编辑**。关闭后仍能用 Neo 查找和打开笔记。

**鼠标单击选择、双击确认**对新配置默认开启：单击选择共享选择器中的结果，双击确认；悬停不改变选择。升级已有配置会保留原来的两项设置，包括此前未显式保存的旧默认值。

## 开关可选功能

在**模块**页面，可以开关**链接与复制提示**、**扩展管理面板**、**翻译增强**、**引用增强**、**AI 问答（实验）**、**标签页增强**和**条目自定义属性**。链接与复制提示、扩展管理面板和引用增强默认开启；其他四项对新配置默认关闭。`translation` 与 `ai-qa` 依赖固定启用的 `reader-selection`，核心模块没有关闭开关。

1. 在**模块**中修改需要调整的可选功能开关。
2. 点击**保存模块请求**。出现**等待重启**表示设置已经保存，只是还没生效。
3. 完全退出 Zotero 后重新打开。只关闭设置窗口或重新打开 PDF 不会生效。

点击**恢复默认模块请求**会将链接与复制提示、扩展管理面板和引用增强设为开启，将翻译增强、AI 问答（实验）、标签页增强和条目自定义属性设为关闭；翻译关闭值会显式保留，完全重启 Zotero 后生效。它不会重置快捷键、主题或其他设置。

启用 AI 问答（实验）后，在 Reader Normal 中按 `<Space>aa` 打开面板。旧版本 `reader-ai` 偏好不会自动启用这个实验；需要在**模块**页面明确打开 `ai-qa` 并完全重启 Zotero。Neo 热重载沿用当前进程已应用状态。服务参数不在 Zotero 原生偏好页中配置；字段、凭据存储与数据范围见[设置参考](SETTINGS_REFERENCE.md)，操作流程见[AI 问答操作指南](READER_GUIDE.md#解释选区和询问论文)。

引用增强（`references`）默认开启；在 Reader Normal 中按 `<Space>fr` 打开。旧启动快照中缺少 `references` 标记的进程会将它保持为关闭；Neo 热重载沿用启动时应用的模块快照，重新打开 PDF 也不会改变模块状态。保存模块请求并完全重启 Zotero 后，模块才读取已保存的请求；未保存过的值按默认值开启。引用功能与 `ai-qa` 无关，本机分析和文库匹配不需要网络或 API 密钥。具体操作见[阅读器指南](READER_GUIDE.md#查找和核对参考文献)，元数据来源与密钥存储见[设置参考](SETTINGS_REFERENCE.md#引用增强的元数据来源与密钥)。

启用**条目自定义属性**并完全重启 Zotero 后，在 Main 按 `<Space>pa` 管理定义，按 `<Space>ia` 编辑所选文献的值；操作及 Extra 风险见[给文献添加自定义属性](MAIN_GUIDE.md#给文献添加自定义属性)。


### 准备翻译增强

在**翻译增强**卡片请求启用并保存时，Neo 会先检查 Translate for Zotero；此入口不依赖扩展管理面板。

1. 未安装时，核对确认框中的插件、版本和官方来源后允许下载。Neo 只准备固定的 **2.4.8**，并校验发行包 SHA-256；取消或失败不会保存本次启用请求。
2. 已安装但停用时，明确确认启用；已安装其他版本时，不会静默替换或降级。卡片分别显示安装、运行时、支持版本与重启状态。
3. 仅新安装时，Neo 尝试初始化尚无用户配置的选中文本自动翻译及目标语言；既有用户值保留。服务和密钥仍在 Translate for Zotero 的设置中管理。
4. 准备完成后保存模块请求，完全退出并重新启动 Zotero，再按[保存自动译文](SELECTION_GUIDE.md#保存自动翻译的译文)操作。

首次迁移只在翻译模块偏好缺失时保留已有 Translate for Zotero 用户的使用：已安装（即使停用或尚未启动）或已有服务配置均会保留；明确关闭值不会被覆盖。关闭翻译增强不会停用上游插件或删除已有译文便签。

## 调整标签页显示

在 Neo 设置的**模块**页面找到**标签页增强**卡片，勾选**请求启用**后点击**保存模块请求**，再完全退出并重新启动 Zotero。它默认关闭；只关闭设置窗口、重新打开 PDF 或热重载 Neo 都不会应用新的模块请求。显示控件位于同一卡片的**标签页显示**区域，不在 Zotero 原生偏好页中；模块已启用时，显示位置变更会立即生效。

在**标签页显示**中选择**最左侧**、**最右侧**或**上方**；默认位置仍是**最左侧**。前两项显示垂直侧栏，上方模式由 Neo 绘制横向标签栏并保留 Zotero 原生工具栏。切换位置不会更改阅读分组，也不会重载 Reader、PDF 或 Note。上方模式以鼠标操作为主，保留 Zotero 原生键盘输入；不新增快捷键，现有快捷键定义保持不变。

宽度可设为 `180`–`520` px（默认 `260` px）；左／右侧栏可按现有方式收起或聚焦。上方模式的组和标签操作使用顶部界面的鼠标入口；原生标签操作由顶部界面逐项适配，具体可用的菜单、拖放或其他操作以最终界面为准。

**标题格式**可以用 `{citekey} — {title}` 显示引用键和标题。占位符、转义、校验、空值回退和标点行为见[设置参考](SETTINGS_REFERENCE.md#标签页增强的显示设置)。点击**恢复标签页显示默认值**只重置显示偏好，不删除保存的分组。停用标签页增强并完全重启 Zotero 后会恢复原生标签栏和工具栏，已保存的分组及标题设置仍保留。分组操作见[用标签页增强管理阅读分组](MAIN_GUIDE.md#用标签页增强管理阅读分组)；准确按键见[命令参考](COMMAND_REFERENCE.md#标签页侧栏)。


如果快捷键打不开设置，可以在 Zotero 的插件偏好页点击 **Open Neo Settings**。安装、更新和禁用 Neo 仍在 Zotero 插件管理器中操作。模块 ID 和详细状态见[设置参考](SETTINGS_REFERENCE.md#模块)。

## 使用标签命名空间

在**高级**中，**命名空间分隔符**将扁平 Zotero 标签显示为虚拟路径。默认 `/` 支持路径匹配；留空则按平面标签匹配。存储的标签名称不变。

## 查看已安装的插件

启用**扩展管理面板**后，在文献库、PDF 或笔记的普通模式下按 `<Space>pp` 打开 Plugin Manager。这里可以查看已安装扩展的状态，以及 Zotero 允许的启停、设置和项目链接。

列表也提供未安装的 Translate for Zotero 条目。选中后按 `i`，经确认下载并校验固定官方 2.4.8。插件可访问 Zotero 数据与本机文件，只安装你信任的插件。

选中已安装插件后按 `u`，经确认让 Zotero 检查该插件的更新；有可用更新时，再确认安装。`r` 只重新读取列表，不检查更新，也不改变自动更新策略。任意来源安装、插件市场搜索和卸载仍使用 Zotero 自带的插件管理器。

启用翻译增强并准备 Translate for Zotero 后，Reader Select 的所选文本操作可提供手动翻译；保存自动结果的版本边界见[选择指南](SELECTION_GUIDE.md#保存自动翻译的译文)。Better BibTeX 为 `<Space>yy` 提供 citekey；目标无法解析或任一 citekey 缺失时，Neo 拒绝复制并保留剪贴板。

## 导出和恢复配置

在 Zotero 设置的 Neo 偏好页点击 **Open Neo Settings**，打开**设置快照**。工作台分为**导出**、**恢复**和**托管快照**。也可在 Main 的命令面板搜索“设置快照”；动作 `openSettingsSnapshots` 没有默认快捷键，旧 `openSettingsTransfer` 自定义绑定会自动迁移。

### 先检查每个插件的模板

展开**插件模板与支持范围**。Zotero 和 Neo 使用内置验证模板；其他已安装插件可**扫描／重新扫描**。扫描只读取静态偏好界面与默认值声明，不执行界面脚本、不读取当前设置值，也不证明所有设置都受支持。

草稿不可恢复。逐字段确认**便携，可纳入快照**，将可能含密码或令牌的字段标记为**敏感**，再**确认本机审核**。不支持的字段不能放行；依赖动态界面、任意代码或本机资源的配置不能靠扫描自动迁移。插件版本、声明来源或模板修订变化后需要重新审核。模板 JSON 只含字段定义，不含设置值；导入他人模板仍是草稿，不会继承对方的审核授权。

本机已知敏感性不会因导入、取消选中或重新扫描而降低。声明过的数字范围和静态枚举按本机控件约束验证，快照文件不能自行放宽限制。

### 导出到自管文件

1. 选择容器：默认 **age 加密**；**JSON 明文**不需要密码，但排除所有本机已知秘密，不适合保密配置。
2. 使用对应插件的**仅导出此插件…**，或勾选多个插件后点击**导出所选插件…**。保存用户覆盖值，不把整套默认值固定到另一台设备。
3. age 可额外授权**包含受支持的密码与 API 凭据**；库级设置也需单独授权，恢复时必须匹配原生账户／文库身份。两项默认不选。
4. age 两次输入相同的非空密码，再选择 `.age` 文件；JSON 选择 `.json` 文件。保存后会读回核对，并显示位置、插件、设置项数和跳过原因。

age 使用标准密码加密，派生约需 256 MiB 内存，可停止。自行保管文件和密码；忘记密码不能恢复。文件不是 XPI，不包含插件安装包、文库数据库、PDF、字体、缓存或账号会话。旧版 Neo 加密配置文件仍可导入。

### 按插件托管到 Zotero 附件

进入**托管快照**，选择插件、标题、可写文库和分类，明确同意后创建可见的存储附件；没有固定隐藏条目，也不会默认占用文库。每个托管目标只保存一个插件，可以为不同插件分别管理。

- **JSON**：排除秘密，可选择自动发布本机变更；约每 60 秒检查，内容未变不重写。只发布，不自动应用下载的设置。
- **age**：每次手动创建／更新都输入密码，永不自动更新，密码不保存在绑定中。
- 本机绑定记录目标身份与已确认的内容指纹，不随快照迁移。原生改名、移动分类或文件路径变化但内容未变时继续跟随；外部内容改变、删除、未下载或只读时暂停，不覆盖、不自动重建。原生缓存有未保存编辑时也拒绝写入，不代为保存或丢弃。查看提示后重新预览来源，或明确创建新目标。
- 修改现有绑定可调整标题、分类和 JSON 自动发布；更换插件、文库或容器需创建新目标，原附件保留。忘记本机绑定不删除附件。
- 修改标题或自动发布选项不会移除附件已有的其他分类。打开配置后若标题、分类或绑定选项已变化，会拒绝旧表单；刷新列表并重新打开配置后再修改。

跨设备依赖 Zotero **数据同步**传输附件条目，以及**文件同步**传输附件内容；Neo 不配置同步账号、服务或配额。本机保存成功不代表另一台设备已收到，未验证真实账号的跨设备网络同步。另一台设备需自行安装插件、审核模板，再从所选文库中刷新并选择附件来源。

文件与附件使用相同快照格式。可用 Zotero 原生“另存为”将附件取回文件，也可将已有快照作为存储附件加入可写文库后，从附件来源导入；来源列表不是自动订阅或恢复。

### 预览并选择恢复项

1. 进入**恢复**，点击**选择快照文件…**，或展开**从 Zotero 附件选择**，选定文库和附件。JSON 直接显示预览；age 输入来源密码后点击**解锁并预览**。预览不会写入设置。
2. 对照**本机当前值**和**恢复为**，勾选要恢复的设置。秘密只显示是否设置，长值会截断。需要本机路径的项目必须先映射；阻止项不可勾选，未知或未审核的插件会跳过。
3. 如需保留旧配置，点击**导出当前配置…**。导出页会预选本次勾选项涉及的插件，仍沿用常规导出范围：不会逐项记录本机默认值，JSON 也不包含秘密。保存或取消文件保存都会回到原预览，不会恢复设置。
4. 点击**恢复所选 N 项…**，核对覆盖提示后点击**确认恢复**。Neo 不自动保存旧值；明文快照的预览和直接恢复都不需要密码。来源、模板或本机原值变化时，请重新预览。完成后查看逐项结果和**需重启**标记。

恢复不是跨插件原子事务。停止、关闭或部分失败不撤销已接纳的写入；修复问题后可重新预览再试。如果需要回退，可以导入之前自行导出的配置并选择要还原的设置。新增 CSL 的删除或可见性仍需手动处理。需重启的 CSL、依赖它的 Quick Copy 配置及模块请求，须完全退出并重开 Zotero。

### 当前支持范围

- **Zotero**：白名单可移植偏好、当前原生快捷键覆盖、Quick Copy 与站点规则、数据型 Locate 配置、CSL 来源及自定义文本、WebDAV 配置和可选密码。WebDAV 验证状态不复制，恢复后须重新验证。原生同步的库级项仅按显式授权和匹配身份处理。
- **Neo**：自有偏好覆盖、规范绑定及迁移、可选模块请求、显示与滚动、文档分析与 AI 服务配置，以及明确选择的 MinerU、Semantic Scholar、当前 AI 端点凭据。条目自定义属性只迁移定义，不迁移文献中的值。
- **其他插件**：仅本机已审核模板中的受支持偏好覆盖；安装插件、动态配置、独立数据库或凭据服务不由扫描器代办。模板不等于完整插件备份。
- **人工处理／排除**：数据目录、关联附件根目录与相对路径、文库树身份、可执行启动器、代码型 CSS／模板／自定义解析器、CSL 删除／可见性和 Locate 重置等以预览提示为准。账户会话、翻译器源码、Locate 图标、设备朗读声音清单不迁移；字体名称不携带字体文件。marks、导航历史、阅读分组、托管绑定、文档／AI 成果和缓存不在快照内。

这不是全部 profile 或所有插件的通用迁移。没有 1 MB 产品限制；有防止资源耗尽的技术上限，格式与扩展边界见[开发指南](DEVELOPMENT.md#配置迁移格式与加密边界)。
