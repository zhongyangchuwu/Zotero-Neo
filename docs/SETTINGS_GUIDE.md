# 设置与偏好

在 Zotero 的 Neo 偏好页点击 **Open Neo Settings**，或在主窗口、阅读器、笔记的普通模式下按 `<Space>ps`。普通设置通常立即保存；快捷键确认后立即保存，模块开关立即保存，但需要完全重启 Zotero 才能应用。设置面板中的**使用指南**会打开本页。

下表是新配置的默认值。升级已有配置时，鼠标选择和 Vim 笔记编辑保留原有行为，包括以前的默认值和手动选择。

## 修改一个快捷键

1. 打开 Neo 设置，进入**快捷键**，选择命令所属上下文，再按动作或按键搜索。例如，翻页属于 Reader，不属于 Main 或 Note。
2. 聚焦要修改的绑定标签并按 `Enter`，或点击标签进入录制。也可用**添加快捷键**保留原绑定并增加另一组按键。
3. 依次输入按键；`Backspace` 删除最后一键，普通 `Enter` 确认并立即保存，`Esc` 取消并保留旧绑定。保存后的非默认绑定标为**自定义**。
4. 要绑定字面的 `<Enter>`、`<Esc>` 或 `<BS>`，使用行内**编辑表达式**输入规范按键语法，再按 `Enter` 保存。

### 遇到快捷键冲突

完全重复的绑定会在当前行显示占用动作；普通 `Enter` 不会覆盖，可选择行内的**覆盖已有绑定**，或继续修改序列。Zotero 和文本编辑保留的按键不能分配。

一个序列是另一序列的前缀时，较短命令可能等待后续按键；这种组合允许保存。已有的不兼容绑定可能只允许删除，先删除旧条目再分配替代绑定。保存失败时按提示修正后重试；其他问题见[故障排查](TROUBLESHOOTING.md)。

## 找到命令和当前快捷键

输入多键命令的前缀后，**前缀提示**列出可用的后续按键。主窗口、阅读器和笔记 Normal 默认使用 `<Space>` 作为命令前缀。按 `:` 打开命令面板，搜索当前上下文可用的动作，包括支持但尚未绑定的动作。

快捷键搜索覆盖动作名称、当前与默认按键、分组和上下文，结果标明默认、自定义或未绑定。未绑定动作只可加入其支持的上下文。选择所有分组可查看只读的 Zotero 原生快捷键；修改 Neo 绑定不会改变它们。

关闭可选模块后，对应动作和用户绑定仍保存在设置中，但不参与按键匹配、前缀提示或命令面板；重新启用后不必重建绑定。完整动作和默认按键见[命令参考](COMMAND_REFERENCE.md)。

## 调整外观和语言

Neo 界面默认随 Zotero 切换明暗。**交互配色**另管 Neo 的选区标记和着色状态，不改 Zotero 原生批注颜色。

| 设置 | 新配置默认值 | 可调整内容 |
| --- | --- | --- |
| 交互配色 | Zotero | 可选 Catppuccin、Tokyo Night、Gruvbox 或自定义配色。 |
| 标记宽度 | 3 px | 主窗口条目标记宽度，范围 1–4 px。 |
| 状态样式 | 中性 | 可切换为着色。 |
| 语言 | 跟随 Zotero | 在**高级**中可改为 English 或中文；影响 Neo 设置、命令标签及阅读器提示，不改变 Zotero 界面语言。 |

### 界面外观与自定义 CSS

在 **Neo 设置 → 外观 → 界面外观**选择 **Classic**（默认）、**Terminal** 或 **Modern**。Terminal 在浅色 Zotero 中用浅灰白底、直角、细线与等宽字体；切换到深色时自动改用深底。预设和**自定义 CSS**自动保存，已打开的 Neo 界面立即更新。两项分别保存为 `extensions.zotero-neo.appearance.preset` 和 `extensions.zotero-neo.appearance.customCss`，随工作区备份和文库同步一起导出，可在另一台设备上恢复。

也可在 [Zotero 配置文件目录](https://www.zotero.org/support/kb/profile_directory)中编辑 `docs/custom-neo.css`；仅当该文件不存在时，才读取旧的 `docs/custom-picker.css`。打开一个新的 Neo 面板可刷新所在窗口的文件样式。设置里非空的 CSS 优先，不与文件合并；只同步设置里的 CSS，不同步文件本身。

用 `.neo-appearance` 设置所有受支持的 Neo 界面，也可单独选 `.picker-root`（选择器）、`.neo-extensions`（扩展）、`.neo-find`（行内查找）、`.neo-settings` / `.neo-snapshots`（设置和快照）、`.neo-sidebar`（标签与阅读器侧栏）、`.neo-hints`（按键与阅读器提示）、`.neo-statusbar`（状态条）或 `.neo-reader-overlay`（选区操作及批注评论）。这些选择器只影响 Neo 自有容器，不影响 Zotero 原生控件或 PDF 纸面。可使用 `@media` 和 `@supports`，不加载 `@import`、`url()` 等外部资源。

常用令牌：`--neo-bg`、`--neo-surface`、`--neo-surface-subtle`、`--neo-border`、`--neo-fg`、`--neo-muted`、`--neo-accent`、`--neo-selected-bg`、`--neo-selected-fg`、`--neo-radius`、`--neo-shadow`、`--neo-font-ui`、`--neo-font-mono`。

```css
.neo-appearance[data-zotero-neo-preset="terminal"][data-zotero-neo-theme="light"] {
  --neo-accent: #1557a2;
}

.picker-root[data-picker-theme="terminal"] {
  --picker-row-height: 30px;
}
```

原有 `.picker-*`、`data-picker-theme` 和 `--picker-*` 写法仍可用。

用 `.picker-root[data-picker-panes="1"]` 或 `.picker-root[data-picker-panes="2"]` 分别调整单栏或双栏选择器，例如设置 `--picker-width`。`.picker-check` 是勾选标记，`.picker-row[data-marked="true"]` 匹配已勾选行，`.picker-row[data-row-kind="action"]` 匹配新建分类等动作行。

## 调整阅读器控制

在**阅读器**中选择滚动模式；界面只显示当前模式的参数。步进按固定距离移动，恒速按住时保持速度，加速模式按住时改变速度。

| 设置 | 新配置默认值 | 作用 |
| --- | --- | --- |
| 文本选择模式 | 开 | 允许 `v` 或 Zotero 原生文本选择进入 Reader Select。 |
| 批注评论编辑 | 开 | 允许 Reader Normal 的 `i` / `Enter` 编辑选中批注的评论；关闭不影响原生评论字段或 Select 的添加评论动作。 |
| 滚动模式 | 恒速 | 可选步进、恒速或加速。 |
| 滚动步长 | 60 px | 步进模式下每次移动的距离。 |
| 滚动速度 | 2000 px/s | 恒速模式按住滚动键时的速度。 |
| 初始速度／最大速度 | 各 2000 px/s | 加速模式的起始速度与速度上限。 |
| 加速度／减速度 | 2600／4200 px/s² | 加速模式按住及松开按键时的速度变化。 |
| 松开按键时立即停止 | 关 | 开启后加速模式不再逐渐减速。 |
| 持久化标记 | 关 | 开启后可在重启 Zotero 后跳回已保存位置。 |
| 默认颜色 | 黄色 | 用于没有明确指定颜色的下划线和添加批注评论。 |

开启位置标记保存后，标记写入父条目的 Extra；独立 PDF 写入附件的 Extra。写入失败时回退到不同步的本地偏好，因此不要把它当作一定已同步的备份。

`<Space>rb` 是 Reader 会话内的正文选择过滤开关，默认关闭，不是持久化设置。它只为可见 PDF 页面按需准备 Neo Select 使用的布局，不改变普通鼠标拖选或 Zotero 原生复制、高亮。详见[调整选中的文字范围](READER_GUIDE.md#调整选中的文字范围)。

## 选择启动焦点

在**交互 → 主窗口 → 启动焦点**中，默认选中**条目列表**；希望启动后直接输入查询时，改选 **Zotero 快速搜索**。设置立即保存，下次启动进入文库时生效；不会改变恢复的阅读器标签页，也不会在插件重载时抢焦点。

## 调整笔记和选择器

| 设置 | 新配置默认值 | 作用 |
| --- | --- | --- |
| Vim 风格笔记编辑 | 关 | 在**交互**中开启后使用 Vim 按键；关闭时仍可用 Neo 查找和打开笔记，并保留 Zotero 原生编辑。 |
| 使用鼠标选择和确认 | 开 | 单击选择结果，双击确认；悬停不改变选择。 |
| 显示前缀提示 | 开 | 在**快捷键 → 前缀提示**中控制多键命令提示。 |
| 显示延迟 | 200 ms | 可设为 0–1000 ms。 |
| 字号 | 15 px | 前缀提示字号，可设为 12–24 px。 |

## 开关可选功能

**模块**控制 Neo 自带的可选功能。

| 可选模块 | 新配置默认值 | 用途 |
| --- | --- | --- |
| 链接与复制提示 | 开 | 显示链接和复制目标提示。 |
| 扩展管理面板 | 开 | 查看并管理已安装的插件。 |
| 引用增强 | 开 | 查找参考文献和按需查询元数据。 |

切换开关立即保存；保存值与当前运行状态不同时，模块页顶部显示一条**部分更改将在重启 Zotero 后生效**提示。切回当前状态后提示消失。完全退出 Zotero 后重新打开才能应用；只关闭设置窗口、重开 PDF 或热重载 Neo 不会生效。**恢复功能默认值**只重置本页功能开关，并立即保存。

Neo 不再提供 AI 问答或 Translate for Zotero 接入；这不会卸载已安装的翻译插件，也不会删除已保存的译文便签。

文档准备、解析对照、图表筛选、对象摘录、章节笔记和章节内查找及其 `<Space>ru`、`<Space>rd`、`<Space>rf`、`<Space>re`、`<Space>rn`、`<Space>rs` 命令已移除。旧 `documentAnalysis.*` 偏好、已移除命令的自定义绑定和旧备份中的相关字段会被忽略；已有章节笔记、图表摘录、标签和旧缓存不会被迁移或主动删除。图表跳转改用会话内存，不再提供云端解析、解析缓存或本地规则 JSON 配置。

## 使用标签命名空间

在**高级 → 标签命名空间**设置**命名空间分隔符**，默认为 `/`。留空时按完整标签名匹配。该偏好只影响候选分组，不改写 Zotero 的标签名。例子见[标签操作](MAIN_GUIDE.md#给条目添加标签和筛选)。

## 引用增强的元数据来源与密钥

DOI 和标题查询使用 Semantic Scholar，arXiv ID 查询使用 arXiv；发送的是查询词或标识符，不是 PDF。主动搜索优先使用缓存，刷新才绕过缓存；刷新失败不会清除已有结果。参见[参考文献操作](READER_GUIDE.md#查找和核对参考文献)。

Semantic Scholar API Key 可选，匿名查询同样可用，额度受服务限制。可从 [Semantic Scholar API 页面](https://www.semanticscholar.org/product/api)申请。在**设置 → 阅读器 → Semantic Scholar**填写或修改后立即保存到 Zotero 本机密码管理器，删空即清除；打开设置和编辑密钥本身不会发送 PDF。点击**验证**会向服务发送只读检查请求。密钥与元数据缓存独立，**清除元数据缓存**不会删除凭据或文库条目。

## 导出和恢复配置

在 Neo 设置右上角打开 **工作区同步与备份**，或在主窗口命令面板搜索同名动作（旧称“设置快照”也能搜到）。工作区同步和备份包含 Neo 的快捷键和偏好，但不再包含旧 Neo 自定义属性定义；文献条目中的属性值仍随条目保存。此功能不替代文库备份。

工作区备份和文库同步都会记录可管理的第三方扩展，包括名称、版本、启停状态和已知安装来源。手动安装、未记录来源的扩展也会列入。不包括 Neo 和系统扩展；安装来源不会携带凭据。

### 开启文库同步

切到 **文库同步**，直接选择 **开启文库同步**。默认在“我的文库”创建 `[Zotero-Neo] 工作区同步` 附件，包含 Neo 配置、扩展清单和已选插件设置。要自选名称、文库或分类，展开 **更改存放位置与名称**。

普通同步不需要密码，约每 5 分钟检查设置，只在有变化时更新附件。跨设备需要 Zotero 的数据同步和文件同步都开启；附件到达另一台设备后，在 **恢复** 中选取它，不会自动覆盖那台设备的设置。

勾选 **包含 API 密钥等敏感凭据（启用密码加密）** 可纳入受支持的凭据；也可只启用密码保护。加密同步需要手动更新，每次输入密码，不保存密码。不再同步时可断开本机连接，文库附件会保留。

### 导出备份文件

在 **备份** 中选择插件，再选择保存位置。默认不加密，不含已识别的密码和密钥。需要凭据或密码保护时，勾选对应选项并输入一次密码。某些普通设置也可能含路径、个人信息或未识别的秘密；分享前请确认范围。

可另选标签颜色、阅读器主题等文库级设置，只能恢复到原文库。旧的 `.json`、`.age` 备份以及原来的单插件文库附件仍可恢复；其中旧 Neo 自定义属性定义会被忽略，不影响其他设置和扩展的恢复。丢失密码无法解密。

### 恢复设置和解决冲突

1. 在 **恢复** 直接选 `[Zotero-Neo] 工作区同步`；也可选择备份文件，或展开 **文库来源** 查找其他附件。加密备份输入来源密码并按 `Enter` 解锁。
2. 在同一页核对扩展和设置。有来源的缺失扩展默认勾选，只保留你信任的来源。遇到 **无安装来源**，可跳过，也可用 **补充来源** 粘贴 GitHub `owner/repo`、仓库或 Release 链接，或 HTTPS `.xpi` 直链；核对来源后勾选。已装扩展可对齐启停，状态相同的只显示数量。
3. 对照 **本机当前值** 和 **恢复为** 勾选设置；需要本机文件或目录的项目须先映射。缺失插件的设置要等安装后与本机插件核对；无法核对的项不会写入。要保留旧值，可先选 **备份当前设置**。
4. 选择 **恢复所选 N 项**。Zotero 先安装缺失扩展，再对齐启停，最后恢复设置；没有第二次确认，也不会卸载本机已有的其他扩展。单项失败不影响其余项目，原因会列在结果中。若页顶提示重启，请完全退出再打开 Zotero。

来源或本机值变化后，可选择 **刷新差异**。停止或部分失败不会撤销已完成的修改。

如果其他设备改了同步附件，Neo 会停写并给出两个选择：**查看并应用云端改动**打开差异供你选择；**以本机为准覆盖云端**用本机配置更新该附件并恢复同步。只恢复部分云端设置不会立即反向覆盖剩余内容。

### 选择第三方插件设置

展开插件设置清单，扫描或导入设置模板，再直接勾选要备份的字段；可将字段标为敏感。未知或不支持的字段不会写入。工作区备份不迁移独立数据库、脚本、登录会话、文库附件、位置标记、导航历史或阅读成果。
