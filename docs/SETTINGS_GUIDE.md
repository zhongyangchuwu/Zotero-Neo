# 修改 Neo 设置

在主窗口、阅读器或笔记的普通模式下，按 `<Space>ps` 打开 Neo 设置。主题、滚动等设置通常会立即保存；修改快捷键后要点击**应用绑定**。关闭或开启可选功能后，还需要点击**保存模块请求**并重启 Zotero。

## 修改一个快捷键

1. 依次按 `Space`、`p`、`s` 打开 Neo 设置。
2. 进入**快捷键**，选择命令所属上下文，再按动作或按键搜索。例如，翻页属于 Reader，不属于 Main 或 Note。
3. 用**录制**替换绑定，或用**添加**保留原绑定并增加另一组按键。输入按键或序列后，点击**完成**加入草稿；录制时点击**取消**放弃捕获的按键。
4. 检查校验消息，再点击**应用绑定**。应用前只是草稿；保存后的非默认绑定标为**自定义**。

录制时，`Enter` 和 `Escape` 是要记录的按键，不是录制器控制。请使用界面上的**完成**和**取消**按钮。

## 找到命令和当前快捷键

输入多键命令的前缀后，**前缀提示**列出可用的后续按键。主窗口、阅读器和笔记 Normal 默认使用 `<Space>` 作为命令前缀。按 `:` 打开命令面板，搜索当前上下文可用的动作，包括支持但尚未绑定的动作。

在**快捷键**中展开**前缀提示**，可以开关提示，调整**显示延迟（ms）**和**字号（px）**。

快捷键搜索覆盖动作名称、ActionId、当前与默认按键、分组和上下文，结果标明默认、自定义或未绑定。未绑定动作只可加入其支持的上下文。选择所有分组可查看 Zotero 原生快捷键；这些条目只读，修改 Neo 绑定不会改变原生快捷键。

关闭 `reader-hints`（**链接与复制提示**）或 `extensions`（**扩展管理面板**）后，其对应动作及用户绑定仍保留在设置中，但不参与当前按键匹配、前缀提示或命令面板；重新启用不需要重建绑定。九个核心模块没有关闭开关。

## 遇到快捷键冲突

- 完全重复的绑定、不支持的动作/上下文组合，以及 Zotero 或文本编辑保留的按键会阻止应用。请更换序列或删除冲突条目。
- 一个序列是另一序列的前缀时，较短命令可能等待后续按键。这种组合允许保存；需要立即执行时，请换用不同序列。
- 已有的不兼容绑定可能只允许删除。先删除旧条目，再分配替代绑定。
- 保存失败时，草稿保留，设置会报告失败。

## 调整外观和语言

在**外观**中选择 Zotero、Catppuccin、Tokyo Night、Gruvbox 或自定义主题。颜色用于 Neo 的交互标记和状态提示；**标记宽度（px）**调整 Main 条目标记，**状态样式**可选中性或着色。

在**高级**中，将**语言**设为跟随 Zotero、English 或中文。它控制设置界面，以及前缀提示、命令面板和快捷键中的本地化动作标签；跟随 Zotero 使用宿主语言。

## 调整阅读器控制

在**阅读器**中选择**滚动模式**：

- **步进**：每次 `j`、`k`、`zh` 或 `zl` 移动固定距离，通过**滚动步长（px）**调整。
- **恒速**：按住滚动键时保持固定速度，通过**滚动速度（px/s）**调整。
- **加速**：按住时改变速度，可调整初始速度、最大速度、加速度和减速度。开启**松开按键时立即停止**后，不再逐渐减速。

界面只显示当前模式的参数。开启**持久化标记**可跨重启保存 marks；存储和同步规则见[设置参考](SETTINGS_REFERENCE.md)。**默认颜色**用于没有明确指定颜色的下划线和添加批注评论。

**文本选择模式**控制 `v` 和原生 Zotero 文本选择能否进入 Reader Select。**批注评论编辑**控制阅读器 Normal 的 `i` / `Enter` 是否打开选中批注的评论编辑器；关闭后不影响 Zotero 原生评论字段或 Select 中独立的“添加批注评论”动作。

## 调整笔记和选择器

在**交互**中，可以关闭**Vim 风格笔记编辑**，改用 Zotero 原来的编辑方式。关闭后仍能用 Neo 查找和打开笔记。

**鼠标单击选择、双击确认**用于共享选择器。开启后，单击选择结果，双击确认；悬停不改变选择。

## 管理可选增强

“模块”页提供三项独立开关：**链接与复制提示**（`reader-hints`）和**扩展管理面板**（`extensions`）默认开启；**翻译增强**（`translation`）对新配置默认关闭。修改请求后点击**保存模块请求**，再完全退出并重新启动 Zotero；仅关闭设置、重开阅读器或热重载 Neo 都不会应用新请求。

点击**恢复默认模块请求**会把三项偏好明确写成规范默认值：`reader-hints=true`、`extensions=true`、`translation=false`。重启 Zotero 后应用；此操作不会清除模块偏好，也不会重置快捷键、主题或其他设置。

首次启动时，如果 `extensions.zotero-neo.modules.translation.enabled` 尚不存在，Neo 会根据此时是否存在 Translate for Zotero 运行时，或是否留有其用户配置进行一次迁移：检测到其中任一项时启用翻译增强，否则保持关闭。此检测不查询已安装插件的元数据。已有偏好值（包括明确的 `false`）始终优先，不会被迁移覆盖。

### 首次准备翻译依赖

在“翻译增强”行可以查看依赖状态，并使用**准备翻译插件**、**重新检查依赖**或**打开 Translate 设置**。此准备入口不依赖**扩展管理面板**是否开启。若保存时刚把翻译增强从关闭改为开启，Settings 也会先执行准备；依赖准备成功后才保存模块请求。

没有安装 Translate for Zotero 时，Neo 会在安装前显示插件身份、版本和来源并请求确认，再通过 Zotero 原生安装器安装官方固定版本 **2.4.8**。取消确认或点击**取消准备**会放弃本次准备，原模块请求不变。已有插件但处于停用状态时，准备会另行请求确认启用，不会改写其配置。

只有这次由 Neo 新安装的插件会尝试初始化 `extensions.zotero.ZoteroPDFTranslate.enableAuto` 和 `extensions.zotero.ZoteroPDFTranslate.targetLanguage`：准备安装前先记录哪些键没有用户值，安装成功后仅为这些键分别写入 `true` 和按 Neo 界面语言选择的 `zh-CN` 或 `en-US`。上游启动时自行写入的默认目标语言不会掩盖这次初始化。如果卸载后重装时仍保留这些用户偏好，原值也会保留；已有插件的自动翻译选项、目标语言、服务和凭据均不被覆盖，仍由 Translate for Zotero 自己管理。

| 依赖状态 | 含义与处理 |
| --- | --- |
| 未安装 | 使用“准备翻译插件”并确认安装。 |
| 已停用 | 使用准备入口并明确确认启用现有插件。 |
| 等待重启 | 插件安装或更新尚未完成重启；重新启动 Zotero 后再检查。模块请求本身也只在完整重启后应用。 |
| 运行时未就绪 | 插件已启用，但其运行时尚不可用；启动完成后点“重新检查依赖”。仅有已安装元数据不代表运行时已就绪。 |
| 版本不支持 | 仍可启用翻译增强以保留上游公开 API 支持的手动“翻译”动作；自动译文“保存译文”不可用。Neo 不会自动替换或降级现有版本。若要自行管理版本，可使用 Plugin Manager 或 Zotero 原生插件管理器，然后重新检查。 |
| 已就绪 | 支持版本的上游运行时已就绪，可使用自动结果的“保存译文”。 |
| 检查失败 | 检查或准备出错时，状态会显示错误；可重新检查，或通过“打开 Translate 设置”查看上游配置。 |

关闭翻译增强并在重启后生效，只会移除 Neo 的手动翻译、保存按钮和侧栏译文角色；不会停用或卸载 Translate for Zotero，也不会删除已保存的原生便签。上游翻译设置和服务仍归 Translate for Zotero 管理。**扩展管理面板**仍可作为另一种安装或管理插件的入口，但不是翻译依赖准备的前提。

如果快捷键打不开设置，可以在 Zotero 的插件偏好页点击 **Open Neo Settings**。模块 ID 和详细运行状态见[设置参考](SETTINGS_REFERENCE.md#模块)。

## 使用标签命名空间

在**高级**中，**命名空间分隔符**将扁平 Zotero 标签显示为虚拟路径。默认 `/` 支持路径匹配；留空则按平面标签匹配。存储的标签名称不变。

## 查看已安装的插件

启用**扩展管理面板**后，在文献库、PDF 或笔记的普通模式下按 `<Space>pp` 打开 Plugin Manager。这里可以查看已安装扩展的状态，以及 Zotero 允许的启停、设置和项目链接。

列表也提供尚未安装的 Translate for Zotero 条目。选中它后按 `i`，从项目官方发行地址下载，核对原生确认框中的插件身份、版本和来源后安装。插件能够访问 Zotero 数据和本机文件，只安装你信任的插件。

选中已安装插件后按 `u`，让 Zotero 检查该插件的更新；有可用更新时，经确认后安装。需要重启时，面板会保留提示。`r` 只重新读取列表，不检查更新，也不修改 Zotero 的自动更新策略。按 `p` 打开所选插件已注册的设置。任意来源安装、插件市场搜索和卸载仍使用 Zotero 自带的插件管理器。

Translate for Zotero 的翻译服务、目标语言和密钥仍由它自己的设置管理；[保存自动译文](SELECTION_GUIDE.md#保存自动翻译的译文)不需要另配一套翻译服务。Better BibTeX 为 `<Space>yy` 提供 citekey；目标无法解析或任一 citekey 缺失时，Neo 拒绝复制并保留剪贴板。

控件默认值见[设置参考](SETTINGS_REFERENCE.md)，动作上下文和完整绑定见[命令参考](COMMAND_REFERENCE.md)。
