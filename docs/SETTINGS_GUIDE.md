# 修改 Neo 设置

在主窗口、阅读器或笔记的普通模式下，按 `<Space>ps` 打开 Neo 设置。主题、滚动等设置通常会立即保存；修改快捷键后要点击**应用绑定**。关闭或开启可选功能后，还需要点击**保存模块请求**并重启 Zotero。

## 修改一个快捷键

1. 依次按 `Space`、`p`、`s` 打开 Neo 设置。
2. 进入**快捷键**，选择命令所属上下文，再按动作或按键搜索。例如，翻页属于 Reader，不属于 Main 或 Note。
3. 用**录制**替换绑定，或用**添加**保留原绑定并增加另一组按键。输入按键或序列后，点击**完成**加入草稿；录制时点击**取消**放弃捕获的按键。
4. 检查校验消息，再点击**应用绑定**。应用前只是草稿；保存后的非默认绑定标为**自定义**。

录制时，`Enter` 和 `Escape` 是要记录的按键，不是录制器控制。请使用界面上的**完成**和**取消**按钮。

## 找到命令和当前快捷键

输入多键命令的前缀后，**前缀提示**列出可用的后续按键。主窗口、阅读器和笔记 Normal 默认使用 `<Space>` 作为命令前缀。按 `:` 打开命令面板，搜索当前上下文可用的动作，包括支持但尚未绑定的动作。

在**快捷键**中展开**前缀提示**，可以开关提示，调整**显示延迟（ms）**和**字号（px）**。

快捷键搜索覆盖动作名称、ActionId、当前与默认按键、分组和上下文，结果标明默认、自定义或未绑定。未绑定动作只可加入其支持的上下文。选择所有分组可查看 Zotero 原生快捷键；这些条目只读，修改 Neo 绑定不会改变原生快捷键。

关闭任一可选模块后，其对应动作及用户绑定仍保留在设置中，但不参与当前按键匹配、前缀提示或命令面板；重新启用不需要重建绑定。核心模块没有关闭开关。

## 遇到快捷键冲突

- 完全重复的绑定、不支持的动作/上下文组合，以及 Zotero 或文本编辑保留的按键会阻止应用。请更换序列或删除冲突条目。
- 一个序列是另一序列的前缀时，较短命令可能等待后续按键。这种组合允许保存；需要立即执行时，请换用不同序列。
- 已有的不兼容绑定可能只允许删除。先删除旧条目，再分配替代绑定。
- 保存失败时，草稿保留，设置会报告失败。

## 调整外观和语言

在**外观**中选择 Zotero、Catppuccin、Tokyo Night、Gruvbox 或自定义主题。颜色用于 Neo 的交互标记和状态提示；**标记宽度（px）**调整 Main 条目标记，**状态样式**可选中性或着色。

在**高级**中，将**语言**设为跟随 Zotero、English 或中文。它控制设置界面，以及前缀提示、命令面板和快捷键中的本地化动作标签；跟随 Zotero 使用宿主语言。

## 调整阅读器控制

在**阅读器**中选择**滚动模式**：

- **步进**：每次 `j`、`k`、`zh` 或 `zl` 移动固定距离，通过**滚动步长（px）**调整。
- **恒速**：按住滚动键时保持固定速度，通过**滚动速度（px/s）**调整。
- **加速**：按住时改变速度，可调整初始速度、最大速度、加速度和减速度。开启**松开按键时立即停止**后，不再逐渐减速。

界面只显示当前模式的参数。开启**持久化标记**可跨重启保存 marks；存储和同步规则见[设置参考](SETTINGS_REFERENCE.md)。**默认颜色**用于没有明确指定颜色的下划线和添加批注评论。

**文本选择模式**控制 `v` 和原生 Zotero 文本选择能否进入 Reader Select。**批注评论编辑**控制阅读器 Normal 的 `i` / `Enter` 是否打开选中批注的评论编辑器；关闭后不影响 Zotero 原生评论字段或 Select 中独立的“添加批注评论”动作。

## 调整笔记和选择器

在**交互**中，可以关闭**Vim 风格笔记编辑**，改用 Zotero 原来的编辑方式。关闭后仍能用 Neo 查找和打开笔记。

**鼠标单击选择、双击确认**用于共享选择器。开启后，单击选择结果，双击确认；悬停不改变选择。

## 开关可选功能

在**模块**页面，可以开关**链接与复制提示**、**扩展管理面板**、**引用增强**、**AI 问答（实验）**和**标签页增强**。链接与复制提示、扩展管理面板和引用增强默认开启；AI 问答和标签页增强默认关闭。`ai-qa` 依赖固定启用的 `reader-selection`，核心模块没有关闭开关。

1. 在**模块**中修改需要调整的可选功能开关。
2. 点击**保存模块请求**。出现**等待重启**表示设置已经保存，只是还没生效。
3. 完全退出 Zotero 后重新打开。只关闭设置窗口或重新打开 PDF 不会生效。

点击**恢复默认模块请求**会将链接与复制提示、扩展管理面板和引用增强设为开启，将 AI 问答（实验）和标签页增强设为关闭；完全重启 Zotero 后生效。它不会重置快捷键、主题或其他设置。

启用 AI 问答（实验）后，在 Reader Normal 中按 `<Space>aa` 打开面板。旧版本 `reader-ai` 偏好不会自动启用这个实验；需要在**模块**页面明确打开 `ai-qa` 并完全重启 Zotero。Neo 热重载沿用当前进程已应用状态。服务参数不在 Zotero 原生偏好页中配置；字段、凭据存储与数据范围见[设置参考](SETTINGS_REFERENCE.md)，操作流程见[AI 问答操作指南](READER_GUIDE.md#解释选区和询问论文)。

引用增强（`references`）默认开启；在 Reader Normal 中按 `<Space>fr` 打开。旧启动快照中缺少 `references` 标记的进程会将它保持为关闭；Neo 热重载沿用启动时应用的模块快照，重新打开 PDF 也不会改变模块状态。保存模块请求并完全重启 Zotero 后，模块才读取已保存的请求；未保存过的值按默认值开启。引用功能与 `ai-qa` 无关，本机分析和文库匹配不需要网络或 API 密钥。具体操作见[阅读器指南](READER_GUIDE.md#查找和核对参考文献)，元数据来源与密钥存储见[设置参考](SETTINGS_REFERENCE.md#引用增强的元数据来源与密钥)。

## 调整标签页显示

在 Neo 设置的**模块**页面找到**标签页增强**卡片，勾选**请求启用**后点击**保存模块请求**，再完全退出并重新启动 Zotero。它默认关闭；只关闭设置窗口、重新打开 PDF 或热重载 Neo 都不会应用新的模块请求。显示控件位于同一卡片的**标签页显示**区域，不在 Zotero 原生偏好页中；模块已启用时，显示位置变更会立即生效。

在**标签页显示**中选择**最左侧**、**最右侧**或**上方**；默认位置仍是**最左侧**。前两项显示垂直侧栏，上方模式由 Neo 绘制横向标签栏并保留 Zotero 原生工具栏。切换位置不会更改阅读分组，也不会重载 Reader、PDF 或 Note。上方模式以鼠标操作为主，保留 Zotero 原生键盘输入；不新增快捷键，现有快捷键定义保持不变。

宽度可设为 `180`–`520` px（默认 `260` px）；左／右侧栏可按现有方式收起或聚焦。上方模式的组和标签操作使用顶部界面的鼠标入口；原生标签操作由顶部界面逐项适配，具体可用的菜单、拖放或其他操作以最终界面为准。

**标题格式**可以用 `{citekey} — {title}` 显示引用键和标题。占位符、转义、校验、空值回退和标点行为见[设置参考](SETTINGS_REFERENCE.md#标签页增强的显示设置)。点击**恢复标签页显示默认值**只重置显示偏好，不删除保存的分组。停用标签页增强并完全重启 Zotero 后会恢复原生标签栏和工具栏，已保存的分组及标题设置仍保留。分组操作见[用标签页增强管理阅读分组](MAIN_GUIDE.md#用标签页增强管理阅读分组)；准确按键见[命令参考](COMMAND_REFERENCE.md#标签页侧栏)。


如果快捷键打不开设置，可以在 Zotero 的插件偏好页点击 **Open Neo Settings**。安装、更新和禁用 Neo 仍在 Zotero 插件管理器中操作。模块 ID 和详细状态见[设置参考](SETTINGS_REFERENCE.md#模块)。

## 使用标签命名空间

在**高级**中，**命名空间分隔符**将扁平 Zotero 标签显示为虚拟路径。默认 `/` 支持路径匹配；留空则按平面标签匹配。存储的标签名称不变。

## 查看已安装的插件

启用**扩展管理面板**后，在文献库、PDF 或笔记的普通模式下按 `<Space>pp` 打开 Plugin Manager。这里可以查看已安装扩展的状态，以及 Zotero 允许的启停、设置和项目链接。

它不能搜索、安装、更新或卸载插件。这些操作仍需使用 Zotero 自带的插件管理器。

安装 Translate for Zotero 后，Reader Select 的所选文本操作可提供翻译。Better BibTeX 为 `<Space>yy` 提供 citekey；目标无法解析或任一 citekey 缺失时，Neo 拒绝复制并保留剪贴板。

控件默认值见[设置参考](SETTINGS_REFERENCE.md)，动作上下文和完整绑定见[命令参考](COMMAND_REFERENCE.md)。
