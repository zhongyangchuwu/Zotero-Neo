# 设置与偏好

在 Zotero 的 Neo 偏好页点击 **Open Neo Settings**，或在主窗口、阅读器、笔记的普通模式下按 `<Space>ps`。普通设置通常立即保存；快捷键确认后立即保存，模块开关立即保存，但需要完全重启 Zotero 才能应用。设置面板中的**使用指南**会打开本页。

下表是新配置的默认值。升级已有配置时，鼠标选择和 Vim 笔记编辑保留原有行为，包括以前的默认值和手动选择。

## 修改一个快捷键

1. 打开 Neo 设置，进入**快捷键**，选择命令所属上下文，再按动作或按键搜索。例如，翻页属于 Reader，不属于 Main 或 Note。
2. 聚焦要修改的绑定标签并按 `Enter`，或点击标签进入录制。也可用**添加快捷键**保留原绑定并增加另一组按键。
3. 依次输入按键；`Backspace` 删除最后一键，普通 `Enter` 确认并立即保存，`Esc` 取消并保留旧绑定。保存后的非默认绑定标为**自定义**。
4. 要绑定字面的 `<Enter>`、`<Esc>` 或 `<BS>`，使用行内**编辑表达式**输入规范按键语法，再按 `Enter` 保存。

### 遇到快捷键冲突

完全重复的绑定会在当前行显示占用动作；普通 `Enter` 不会覆盖，可选择行内的**覆盖已有绑定**，或继续修改序列。Zotero 和文本编辑保留的按键不能分配。

一个序列是另一序列的前缀时，较短命令可能等待后续按键；这种组合允许保存。已有的不兼容绑定可能只允许删除，先删除旧条目再分配替代绑定。保存失败时按提示修正后重试；其他问题见[故障排查](TROUBLESHOOTING.md)。

## 找到命令和当前快捷键

输入多键命令的前缀后，**前缀提示**列出可用的后续按键。主窗口、阅读器和笔记 Normal 默认使用 `<Space>` 作为命令前缀。按 `:` 打开命令面板，搜索当前上下文可用的动作，包括支持但尚未绑定的动作。

快捷键搜索覆盖动作名称、当前与默认按键、分组和上下文，结果标明默认、自定义或未绑定。未绑定动作只可加入其支持的上下文。选择所有分组可查看只读的 Zotero 原生快捷键；修改 Neo 绑定不会改变它们。

关闭可选模块后，对应动作和用户绑定仍保存在设置中，但不参与按键匹配、前缀提示或命令面板；重新启用后不必重建绑定。完整动作和默认按键见[命令参考](COMMAND_REFERENCE.md)。

## 调整外观和语言

Neo 面板的背景、文字、边框和强调色跟随 Zotero，并随宿主明暗切换更新。**交互配色**只调整 Neo 的交互标记和状态提示，不改变面板主题或 Zotero 原生批注颜色。

| 设置 | 新配置默认值 | 可调整内容 |
| --- | --- | --- |
| 交互配色 | Zotero | 可选 Catppuccin、Tokyo Night、Gruvbox 或自定义配色。 |
| 标记宽度 | 3 px | 主窗口条目标记宽度，范围 1–4 px。 |
| 状态样式 | 中性 | 可切换为着色。 |
| 语言 | 跟随 Zotero | 在**高级**中可改为 English 或中文；影响设置界面和本地化命令标签。 |

## 调整阅读器控制

在**阅读器**中选择滚动模式；界面只显示当前模式的参数。步进按固定距离移动，恒速按住时保持速度，加速模式按住时改变速度。

| 设置 | 新配置默认值 | 作用 |
| --- | --- | --- |
| 文本选择模式 | 开 | 允许 `v` 或 Zotero 原生文本选择进入 Reader Select。 |
| 批注评论编辑 | 开 | 允许 Reader Normal 的 `i` / `Enter` 编辑选中批注的评论；关闭不影响原生评论字段或 Select 的添加评论动作。 |
| 滚动模式 | 恒速 | 可选步进、恒速或加速。 |
| 滚动步长 | 60 px | 步进模式下每次移动的距离。 |
| 滚动速度 | 2000 px/s | 恒速模式按住滚动键时的速度。 |
| 初始速度／最大速度 | 各 2000 px/s | 加速模式的起始速度与速度上限。 |
| 加速度／减速度 | 2600／4200 px/s² | 加速模式按住及松开按键时的速度变化。 |
| 松开按键时立即停止 | 关 | 开启后加速模式不再逐渐减速。 |
| 持久化标记 | 关 | 开启后可在重启 Zotero 后跳回已保存位置。 |
| 默认颜色 | 黄色 | 用于没有明确指定颜色的下划线和添加批注评论。 |

开启位置标记保存后，标记写入父条目的 Extra；独立 PDF 写入附件的 Extra。写入失败时回退到不同步的本地偏好，因此不要把它当作一定已同步的备份。

## 开关可选功能

**模块**控制 Neo 自带的可选功能。**Extras** 用于设置与 Neo 兼容的其他 Zotero 插件及其接入动作。

| 可选模块 | 新配置默认值 | 用途 |
| --- | --- | --- |
| 链接与复制提示 | 开 | 显示链接和复制目标提示。 |
| 扩展管理面板 | 开 | 查看并管理已安装的插件。 |
| 引用增强 | 开 | 查找参考文献和按需查询元数据。 |
| 标签页增强 | 关 | 调整标签栏并管理阅读分组。 |
| 条目自定义属性 | 关 | [定义和编辑文献的自定义属性](MAIN_GUIDE.md#给文献添加自定义属性)。 |
| AI 问答（实验） | 关 | 在默认折叠的**实验性与可选扩展**中启用。 |
| 翻译增强 | 关 | 在同一折叠分组中启用，处理自动译文的保存与筛选。 |

切换开关立即保存；保存值与当前运行状态不同时，模块页顶部显示一条**部分更改将在重启 Zotero 后生效**提示。切回当前状态后提示消失。完全退出 Zotero 后重新打开才能应用；只关闭设置窗口、重开 PDF 或热重载 Neo 不会生效。**恢复功能默认值**只重置本页功能开关，并立即保存。

### 实验性与可选扩展

AI 问答按明确操作把当前选区或有限章节内容发送给所选服务；开启图像发送后还可能附带相关图表裁图。端点密钥保存在本机密码管理器，与引用查询和翻译插件的凭据分开管理。

#### 准备翻译增强

**选区翻译** Extra 与**翻译增强**是独立设置。前者在**设置 → Extras → 选区翻译**中管理 Translate for Zotero 的安装、启停和更新，并控制手动选区翻译；Extra 默认关闭，开关立即生效。只为自动译文准备依赖时不必开启手动 Extra。安装或更新前核对来源和确认提示；Neo 不修改上游服务、语言、自动翻译偏好或凭据。

自动译文保存需要 Translate for Zotero 2.4.8 就绪并开启自动翻译，还需启用**翻译增强**并完全重启 Zotero。关闭任一 Neo 开关不会卸载上游插件，关闭翻译增强也不会删除已保存的译文便签。

## 调整标签页显示

在**模块**页启用**标签页增强**并完全重启 Zotero。模块启用后，**标签页显示**中的位置更改即时生效。

| 设置 | 新配置默认值 | 可调整内容 |
| --- | --- | --- |
| 侧栏位置 | 最左侧 | 可选最左侧、最右侧或顶部；顶部由 Neo 绘制横向标签栏，保留 Zotero 原生工具栏。 |
| 宽度 | 260 px | 左右侧栏展开宽度为 180–520 px，可收起或聚焦。 |
| 标题格式 | `{title}` | 可使用 `{title}`、`{citekey}`、`{author}`、`{year}` 和 `{filename}`。 |

::: v-pre

标题格式例如 `{citekey} — {title}`；用 `{{` 和 `}}` 表示字面花括号。未知占位符或不配对的花括号不能保存；所有动态字段都为空时回退到原生标签标题，分隔符仍按字面保留。格式只改变 Neo 中的显示，不修改文献元数据。

:::

**恢复标签页显示默认值**只重置显示偏好，不删除分组；停用模块并完全重启后恢复原生标签栏，已保存的分组和标题设置仍保留。分组操作见[标签页增强指南](MAIN_GUIDE.md#用标签页增强管理阅读分组)。

## 使用标签命名空间

在**高级 → 标签命名空间**设置**命名空间分隔符**，默认为 `/`。留空时按完整标签名匹配。该偏好只影响候选分组，不改写 Zotero 的标签名。例子见[标签操作](MAIN_GUIDE.md#给条目添加标签和筛选)。

## 引用增强的元数据来源与密钥

DOI 和标题查询使用 Semantic Scholar，arXiv ID 查询使用 arXiv；发送的是查询词或标识符，不是 PDF。主动搜索优先使用缓存，刷新才绕过缓存；刷新失败不会清除已有结果。参见[参考文献操作](READER_GUIDE.md#查找和核对参考文献)。

Semantic Scholar API Key 可选，匿名查询同样可用，额度受服务限制。可从 [Semantic Scholar API 页面](https://www.semanticscholar.org/product/api)申请。在**设置 → 阅读器 → Semantic Scholar**填写或修改后立即保存到 Zotero 本机密码管理器，删空即清除；打开设置和编辑密钥本身不会发送 PDF。点击**验证**会向服务发送只读检查请求。密钥与元数据缓存独立，**清除元数据缓存**不会删除凭据或文库条目。

## 导出和恢复配置

**设置快照**用于迁移设置，不替代文库备份。点击 Neo 设置右上角的**设置快照**，选择**导出**、**恢复**或**文库中的快照**；也可在主窗口命令面板搜索“设置快照”。

### 导出到自管文件

1. 勾选要导出的插件，选择一起导出或单独导出。快照通常保存已修改的偏好，不会把整套默认值固定到另一台设备。
2. 选择格式：默认**加密文件（.age）**需要密码；**明文文件（.json）**不需要密码，任何取得文件的人都能读取。
3. 需要导出受支持的密码和 API 密钥，或标签颜色、阅读器主题等文库级设置时，展开**更多导出选项**。凭据只能包含在加密文件中；文库级设置恢复时必须匹配原文库。
4. 选择保存位置，查看结果和跳过原因。妥善保管文件和密码；密码丢失后无法解密。旧版 Neo 加密配置文件仍可导入。

明文导出会排除已知的密码和密钥，但其他设置也可能含有个人信息、路径或未识别的秘密。分享或托管前先审核内容；不要仅凭格式判断文件无敏感信息。加密文件同样需要安全保管。

### 按插件托管到 Zotero 附件

在**文库中的快照**选定插件、标题、可写文库和分类，勾选**在所选文库创建一个可见的附件**，再点击**存为 Zotero 附件**。每个附件保存一个插件的配置，附件属于所选 Zotero 文库；Neo 的本机关联不随快照迁移。

- JSON 可选择**定期检查，发现变化时更新附件**，约每 5 分钟检查一次；内容未变不重写。age 每次手动创建或更新都要输入密码，不自动更新，也不在关联中保存密码。
- 自动更新只写入本机绑定的附件，不会自动应用从其他设备下载的设置。外部内容改变、附件删除、未下载或只读时会暂停，不覆盖或自动重建；存在未保存的原生编辑时也会拒绝写入。查看提示并重新预览，必要时明确创建新目标。
- 可以修改已有快照的标题、分类和 JSON 自动更新选项；更换插件、文库或格式需要新建快照。**取消本机关联（保留附件）**不会删除原附件。

跨设备传输依赖 Zotero **数据同步**传输附件条目、**文件同步**传输附件内容；Neo 不配置同步账号、服务或配额。本机保存成功不代表另一台设备已经收到。另一台设备需自行安装插件、审核模板，再刷新并选择附件来源；快照不是自动订阅或自动恢复。

### 预览并选择恢复项

1. 进入**恢复**，选择快照文件，或展开**从 Zotero 附件选择**并选定文库和附件。加密文件需输入来源密码并点击**解锁并预览**；预览不会写入设置。
2. 对照**本机当前值**和**恢复为**，勾选需要恢复的项目。秘密只显示是否设置；需要本机路径的项目须先映射，阻止项不可勾选，未知或未审核的插件会跳过。
3. 如需保留旧配置，先点击**导出当前配置…**并保存。Neo 不会自动备份旧值；该导出仍遵循普通导出范围和凭据限制。
4. 点击**恢复所选 N 项…**，核对覆盖提示并确认。来源、模板或本机原值变化时重新预览；完成后查看逐项结果和**需重启**标记。

恢复不是跨插件原子事务：停止、关闭或部分失败不会撤销已经写入的设置。修复问题后可重新预览再试；要回退时，导入事先自行导出的配置并选择还原项。需要重启的设置须完全退出并重开 Zotero。快照值等于目标默认值时可能不产生单独覆盖，此后仍会跟随默认值变化。

### 为第三方插件选择可迁移的设置

Zotero 和 Neo 可以直接导出。其他插件先在**插件模板与支持范围**中扫描，勾选要纳入快照的设置，标记密码、令牌等敏感项并**确认本机审核**。导入的模板也是草稿，必须在本机重新审核；插件版本或声明变化时也需重新审核。扫描不会读取字段值，未绑定的密钥、动作脚本或复杂配置不一定能被发现，不能把扫描结果当作完整安全审查。

快照不会安装插件或迁移独立数据库。Translate for Zotero 的服务密钥、Better BibTeX 的 `postscript`、Actions and Tags 的规则和脚本需单独迁移。位置标记、导航历史、阅读分组、托管关联及已生成的阅读成果不随设置迁移；插件安装包、文库数据库、文献附件、字体、缓存和登录会话也不包含在快照中。WebDAV 恢复后需重新验证；路径、CSL 删除或可见性等项目按预览提示手动处理。
