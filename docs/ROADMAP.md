# 路线图 {#roadmap}

本页说明 `main` 分支的当前范围与维护要求，不作为未实现功能的承诺。实际工作流和准确按键见[使用指南](USER_GUIDE.md)与[命令参考](COMMAND_REFERENCE.md)。

## 当前 {#current}

当前实现覆盖 Main 文库浏览与选择、Reader 文本选择和批注、笔记查找与 Vim 编辑、标签/分类操作、标签页与分屏，以及共享跳转历史。九个内部核心分区固定启用；只有链接与复制提示、扩展管理面板提供可选开关。

获取与当前文档对应的包，见[安装与入门](GETTING_STARTED.md#get-main-build)。构建和宿主验证按[main 验收规范](ACCEPTANCE.md)执行；每次结果绑定实际提交与 XPI，不把代码合并视为完整 GUI 验收或正式发布。

## 维护边界 {#next}

- 保持核心键盘工作流完整，不按源码目录增加用户开关。
- 维护当前支持的 Main、Reader 和 Note 上下文，保留自定义绑定、行为偏好及原生输入所有权。
- 修改功能后同步命令、设置和用户指南，并对受影响的宿主路径进行实际验证。
- 不引入动态运行时依赖、模块市场或任意脚本执行机制；宏、Ex 命令、全面 Vim 兼容及更深入的 EPUB／快照支持不属于当前实现。
