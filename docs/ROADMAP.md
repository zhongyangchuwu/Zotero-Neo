# 项目状态与方向 {#roadmap}

这里记录 Neo 已经支持哪些功能，以及目前还不支持什么。没有确定时间的功能不会写成开发承诺。实际操作见[使用指南](USER_GUIDE.md)，完整按键见[命令参考](COMMAND_REFERENCE.md)。

## 当前已有的功能 {#current}

- **文献库**：用键盘浏览和查找论文，标记一组条目，批量整理标签和分类。
- **PDF 阅读器**：滚动、翻页、缩放、分屏，跳到标题和图表，设置阅读位置标记。
- **文本选择与批注**：按词句定位文字，调整选区、复制、高亮，查找和编辑已有批注。
- **笔记**：查找并打开笔记，可选 Vim 风格编辑。
- **其他操作**：切换标签页、返回之前的位置、自定义快捷键，以及查看已安装的 Zotero 插件。

这些功能以 `main` 分支的当前代码为准。想安装对应版本，可以从[安装指南](GETTING_STARTED.md#get-main-build)获取构建包。

## 目前不支持的范围 {#next}

Neo 不是完整的 Vim 移植，目前不支持宏、Ex 命令或全部 Vim 操作。对 EPUB 和网页快照的支持也没有覆盖 PDF 中的所有功能。

项目也不提供插件市场或任意脚本执行功能。运行时不从网络动态加载第三方代码；相关构建与维护约束见[开发指南](DEVELOPMENT.md)。

发现问题或想讨论新功能，可以在 [GitHub Issues](https://github.com/zhongyangchuwu/Zotero-Neo/issues) 中提出。已完成的改动见[更新记录](../CHANGELOG.md)。
