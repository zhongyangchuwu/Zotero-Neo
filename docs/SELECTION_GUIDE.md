# 选择 PDF 文字并添加批注

Neo 可以直接用键盘找到 PDF 中的一段文字，再复制、搜索或高亮。操作前先点击 PDF 正文，让焦点回到阅读器；搜索框和评论框中的按键用于文字输入。

## 在阅读模式中操作

Reader Normal 中按 `<Space>rr` 切换 Zotero 原生 Reading Mode。重排后的正文沿用 `v` / `s` 的 Flash、`h/l` 词元移动、`j/k` 视觉行移动、`H/L` 字符微调、`o`、复制、搜索和选区批注；切换会释放旧视图的提示和选区资源。

PDF 与 Reading Mode 中的 `)` / `(` 按句子扩展，`}` / `{` 按逻辑段落扩展。首次使用时优先读取当前后端的有效布局缓存，缺失时按所选来源准备，默认在本机使用无模型规则。整个段落与原生文字唯一、完整地匹配后，Neo 会采用逻辑边界，支持跨 span、换栏和相邻页。匹配规范化空白、换行连字和兼容字形，并保留原文字符。含 OCR 替字或其他差异时，Reading Mode 沿用原生 HTML 段落，PDF 按词元移动，`H/L` 可继续微调字符。句界使用宿主 `Intl.Segmenter`，并处理常见论文缩写；有歧义的句子请对照原文调整。

Reading Mode 中的图像、公式和表格裁图使用原 PDF 图像，Flash 的文字目标来自真实文本节点。文字高亮和下划线通过 Zotero 的映射保存回 PDF 坐标。页码步进和确认定位取决于当前原生视图的能力；精确 PDF 位置的共享历史，以及依赖 PDF 文本层或链接叠加层的 hints，适用于 PDF 视图。

## 选择正文时跳过图表文字

在 Reader Normal 中按 `<Space>rb` 开启正文选择，等待结构准备完成后再按 `v`。Neo 优先复用当前后端的有效附件缓存，默认未命中时使用 PDF 原有文字和绘图几何在本机提取。Flash、词元和视觉行候选会跳过已识别的图片、表格、图注和页边文字；复制与批注几何也按同一范围过滤。Select 指示器显示 `SELECT BODY`。

开关作用于当前 Reader 会话的 PDF 和 Reading Mode，关闭阅读器或重载 Neo 后复原。要选图注或表格文字，先按 `Escape` 回到 Normal，再按 `<Space>rb` 恢复全部文字选择。准备时再次按下可取消本次启用；已经开始的宿主提取可能继续执行。更换后端、提交新缓存或保存局部纠错后，按 `<Space>rb` 重新准备布局。复制、查找和批注会再次核对来源，使用当前有效的选区。

本地规则适用于带可提取文字的 PDF，计算使用原有文字层和绘图数据。扫描页可先通过 OCR 工具准备文字层。首次准备可能处理整份 PDF，耗时取决于文件和缓存。公式及来源几何未知的文字保留可选，复杂版式请先核对过滤范围。普通鼠标拖选沿用 Zotero 的选择逻辑，退出 Select 后会释放临时样式。

## 搜索和预览图表

按 `<Space>rf` 打开图表列表，按编号、题注关键词搜索，或用 `p:6` 筛选第 6 页。↑ / ↓（或 Ctrl+N / P）切换候选，右侧从当前 PDF 渲染预览；预览期间阅读位置不变。按 Enter 或“定位到原文”跳转，Escape 取消并返回发起操作的分屏。确认跳转沿用 Zotero 原生历史；PDF 中可以用 Ctrl+O / Ctrl+I 后退和前进。

默认按整组显示子图、题注和脚注，使用解析提供的成员矩形绘制，成员之间的正文留白。遇到题注漏配或错配时，可切换“独立主体”，按类型和页码浏览已识别的图片／表格区域。这个视图按区域列出主体，适合绕开题注关联；识别遗漏仍需回到原文查看。预览支持 + / − / 0 和按钮缩放；列表超过 200 项时可缩小搜索范围。

列表优先复用当前后端的解析缓存，默认未命中时按需本地提取。PDF 与 Reading Mode 共用此入口，预览均来自原 PDF，确认定位交给当前原生视图。关闭 Reader、切换视图或更换解析后端会释放旧预览。

## 章节内查找

Reader Normal 按 `<Space>rs`，在章节下拉框确认范围并输入原文关键词。范围包含编号子章节，标题结构不足时可搜索整篇文档。界面会根据当前位置的可见文字建议章节，也可手动改选。

结果按段落显示字面匹配，最多显示 100 项。↑/↓ 选择，Enter 按布局区域定位原文段落，Escape 返回原阅读位置。定位精度为段落区域，关键词仍需对照原文查看；此查询使用字面搜索，原生 `/`、`n/N` 和 Find 查询各自保留。PDF 跳转沿用原生历史，可用 Ctrl+O / Ctrl+I 恢复位置；Reading Mode 由 Zotero 的原生映射负责定位。

## 摘录整组图表与公式

Reader Normal 按 `<Space>re`，搜索图表编号、题注或公式。默认列出已识别的整组图表与独立公式，也可按类型筛选，或切换“独立主体”查看区域。预览来自原 PDF，绘制所有已知成员，间隙中的正文留白。列表会标明仅有题注或关联不确定的对象，便于回原文核对识别范围。

- Enter／复制图文与来源：复制富文本图片、题注、论文和页码。Zotero 笔记中的图片保留原生区域定位元数据，普通文本链接可打开对应 PDF 页。
- 复制原图：复制 PNG，便于粘贴到图片工具；多页对象可使用图文或笔记保存。
- 复制结构文本：后端提供结构时，可复制公式原始 LaTeX／文本或表格 TSV／安全 HTML。HTML 保留已有单元格合并属性，TSV 按单元格文字输出；公式和数值请对照原文核对。本地规则提供文字与区域，结构化单元格和公式 LaTeX 由相应解析后端提供。
- 保存为新笔记：确认归属后创建独立的新笔记。有文献父条目时保存在该文献下，独立 PDF 对应独立笔记。图片作为嵌入附件保存，附带原生区域定位元数据和 PDF 来源关联。已有笔记与 PDF 批注保持原样。

先预览或复制，点击保存后才写入笔记。保存目标来自当前 Reader，操作前会核对 PDF 版本和目标身份。取消、换视图或关闭 Reader 会释放界面，已接纳的保存可继续完成；失败时会清理本次未完成的笔记。布局优先复用已存结果，云端上传由解析界面的明确操作发起。

已有批注与图表摘录可在 `<Space>rn` 中[按章节整理成笔记](NOTE_GUIDE.md#按章节整理批注与摘录)，先预览再保存。

## 对照原生与云端解析

按 `<Space>rd` 打开“文档解析对照”，默认选择本地规则（无模型），直接处理 Zotero 自带 PDF.js 提供的文字和绘图几何。已有 MinerU／OXR 选择保留。打开面板先读取来源与当前后端缓存；需要对照 Zotero 原生 SDT 时，点击左侧“读取原生结构（可能使用模型）”，再查看独立的原生结果。

点击“读取缓存或本地解析”优先使用缓存，缺失时在本机处理；“重新本地解析”会刷新结果。普通导航、选择和章节入口按需提取，并在当前功能中复用。需要跨会话复用时，在对照面板解析一次，成功后会保存 `.zotero-neo-analysis-*.json`。

云端可选 MinerU 官方服务或 OXR / SoMark。MinerU Token 自动保存在本机密码管理器，删空即清除，单篇与批量准备共用。“验证”用于检查凭据；上传 PDF 由云端解析按钮发起。OXR 密钥在本次对话框内使用，也可填写兼容 API 地址。普通云端解析优先读缓存，缺失时上传；“重新解析并上传 PDF”会重新上传。申请入口见[文档解析设置](SETTINGS_REFERENCE.md#文档解析对照)。

缓存根据 PDF 哈希、页面几何、后端配置和适配器版本匹配，内容是规范化区域，图表关联在读取时按当前算法计算。PDF 或配置变化后会重新准备；本地规则没有模型版本，云端服务未提供模型版本时可手动重新解析以获取新结果。API 密钥和 HTTP 请求体与缓存分开管理。缓存是附件目录内的本机文件，单独复制 PDF 时需在目标机器重新准备；跨设备同步仍须另行核对。保存失败时面板会提示，当前有效结果仍可使用。

两列展示区域、正文归属和内容，可逐项定位或整组定位。遇到密集表格、仅有题注或关联不确定的结果时，先核对原文，再选择独立主体或局部纠错。区域数量和词汇差异用于诊断；耗时记录覆盖该次处理流程，云端还包括上传、排队和下载。MinerU 使用官方异步接口，每篇上限为 200 页、200 MB。质量核验见[解析质量评测](QUALITY_EVALUATION.md)。

## 修正图表关联与正文归属

在 `<Space>rd` 的对应解析列中展开区域，先用“定位区域”核对原 PDF：

1. 图表误配题注时，在题注区域选择“同页图／表主体”。候选显示区域 ID 与 PDF 坐标；确认原文后点击“保存题注关联”。
2. 正文被误分为图表或图注时，点击“保存为正文”。它只修改归属，实际文字仍须映射到原生文本后才能复制或批注。
3. 点击“恢复原始归属”移除该区域修正；“撤销上次已保存纠错”还原本列上一次保存，每列在当前对话框内最多保留 20 步。控件可用 Tab / Shift+Tab 到达，用 Enter / Space 操作。

改为正文时，Neo 会一并移除与该区域冲突的局部题注关联。“恢复原始归属”移除当前区域的显式修正；要恢复保存前的完整状态，可在同一面板内撤销，或重新保存题注关联。

修正独立保存于附件目录的 `.zotero-neo-corrections-*.json`，PDF、原生 SDT 和解析缓存各自保留。匹配来源的修正可在重开 Reader 或重启后复用，图表导航、正文选择和对象摘录共享这些归属。保存后旧结果与过滤会退休，后续操作使用重新读取的布局。

修正绑定确切的 PDF、页面、后端配置和解析结果。来源变化后需在新结果上重新核对；修正读取失败时会暂停相关图组操作并提示。局部纠错调整已有区域的归属与关联，识别遗漏、新框和表格单元格需通过解析结果补充。修正以附件旁的本机文件复用，复制 PDF 或跨设备使用时请另行核对。维护者的核验方法见[解析质量评测](QUALITY_EVALUATION.md)。


## 批量准备论文

Main 普通模式按 `<Space>ru`，按 EffectiveSelection 固定本次 PDF：先取 Persistent Selection，其次当前多选／游标目标。普通文献条目展开其 PDF 附件，直接选中的 PDF 只处理该附件；重复附件去重，非 PDF 忽略。Reader 的同一按键取当前附件。展开“本次固定 PDF 数量”可审阅列表，本次批次始终使用这份已捕获清单。

此入口固定使用 MinerU。填写或使用已保存的 Token，点击“使用 MinerU 准备（上传未缓存 PDF）”。每批最多 200 个 PDF，每次最多申请 50 个文件地址；已缓存项直接复用。界面分别显示缺失文件、失败和成功项，按需读取文件，上传与下载各最多并发 2 个。页面几何由 Zotero 自带 PDF.js 读取，准备过程可在现有 Reader 之外运行。完成表示 MinerU 结果已保存，Reader 使用哪一份布局取决于当前后端选择。

面板会显示 Reader 当前选择的本地规则、MinerU 或 OXR。选择 MinerU 时，后续 `<Space>rf`、图表遍历和侧栏可复用该批有效缓存；本地规则和 OXR 各自使用自己的布局。需要使用这批结果时，在 `<Space>rd` 中主动切回 MinerU，准备面板保留当前 Reader 选择。

队列在关闭面板或发起任务的 Reader 后继续运行。“停止本地等待”停止本地请求和轮询，已上传的远端任务可能继续完成。“继续／重试未完成项”先查询已有回执，复用已提交和已完成的工作。明确失败的任务可重交；上传前中断、签名地址丢失或过期时，会先确认服务仍在等待文件，再重新申请地址。下载或缓存保存失败时，优先取回已有结果。

最近一批任务的身份和回执保存在 Zotero 数据目录的 `zotero-neo-document-tasks.json`，文件内容限于这些恢复信息。重启后打开面板，使用已保存的 Token 点击继续，才会查询或上传；Token、签名 URL 和原始服务错误均留在任务文件之外。新批次会替换任务记录，已有附件缓存和旧远端任务各自保留。PDF 变化时请新建批次，以当前文件重新准备。


当前后端的有效布局同时用于 `[f` / `]f`、`[t` / `]t` 和侧栏图表分组。默认缺失时按需本地提取；已选云端后端的缓存缺失时，先使用原生结构，上传由明确操作发起。标题导航沿用原生大纲与标题校正。正文选择依据布局区域过滤，复制文字和高亮坐标来自原生文本；Reading Mode 使用真实块映射，未知或部分覆盖的块保留可选。正文与排除区域冲突时优先保留正文，判断使用区域本身而非整组包围框。关闭对话框会释放界面并停止可取消的等待，远端计算和 SDK 提取可能继续执行。

## 从一段文字开始

1. 在 Zotero 中打开 PDF，点击页面文字。按 `v`，输入页面上可见的一个词或短语，再选择对应提示。按 `Enter` 会选择最近的匹配项。
2. 文字选中后，按 `z` 再按 `y`（`zy`），为它添加黄色高亮。

可以输入不完整的单词：例如页面上是 `flow matching,`，输入 `match` 会选中完整的 `matching`；输入 `ow mat` 会选中 `flow matching`。逗号等标点可以单独查找。同一个词中的重复子串只显示一个提示。

Flash 只查找当前视图中可见的文字。匹配目标超过 48 个时，继续输入以缩小范围；确认后才会改变选区。英文大小写沿用 smartcase：查询含 ASCII 大写字母时区分大小写，否则忽略大小写。

## 选中文字之后

选中文字后按 `zy`，Zotero 会添加黄色高亮。输入词句或选择匹配位置时，按 `Escape` 可退出查找并保留之前的选区。

## 调整选中的文字范围

在 PDF 普通模式下按 `v`，输入页面上能看到的原文词句，按字母提示选择匹配位置；按 `Enter` 会选择最近的一处。如果没找到，试试更短的词句。Neo 也可以接管 Zotero 已经选中的 PDF 文字。

选中文字后，用 `h` / `l` 向前或向后调整一个完整词元，`j` / `k` 移到相邻视觉行并吸附到词元边界。活动端的词元会显示轮廓提示，方便确认当前正在调整哪里。

例如选中 `flow matching,` 中的 `flow` 后，按 `l` 依次得到 `flow matching`、`flow matching,`，按 `h` 反向收缩。缩到一个词后继续移动会越过原锚词，向另一侧扩展，并保持词元完整。标点独立选择，内部空格保留，首尾空白作为边界。

按 `o` 交换锚点与活动端，随后仍按同一规则移动。按 `s` 用 Flash 定位另一端；向前或向后选择时，原锚词和目标词都会完整保留。接管原生非整词选区时，会保留其精确锚点。

需要选取半个单词、公式或文字层中的局部字符时，用大写 `H` / `L` 微调。`w` / `b` 使用浏览器词边界，`0` / `$` 移到行首或行尾，`)` / `(`、`}` / `{` 分别扩展句子或段落。已有自定义动作按原绑定执行，可在[设置](SETTINGS_GUIDE.md#修改一个快捷键)中检查当前实际绑定。

## 使用当前选区

- 按 `y` 复制选中文字；复制时会规范化 PDF 的换行和空白。按 `#` 在 PDF 中查找该文字。
- 按 `zy`、`zr`、`zg`、`zb` 或 `zp`，添加黄色、红色、绿色、蓝色或紫色高亮。
- 按 `a` 或 `Enter` 打开选区操作。选择**为选区添加下划线**（Underline）可加下划线；选择**添加批注评论**（Add note）会创建 PDF 批注并打开评论编辑器。

## 保存自动翻译的译文

按[设置指南](SETTINGS_GUIDE.md#准备翻译增强)准备并启用翻译增强，即可使用译文保存入口；Plugin Manager 可独立使用。翻译服务、目标语言和密钥由 Translate for Zotero 管理。自动结果保存适配 Translate for Zotero 2.4.8 的就绪运行时，请先确认版本和运行状态；其他版本保持现状，其公开 API 可用时仍可手动翻译。

1. 像往常一样在 PDF 或 Reading Mode 中选中文字，等待自动译文完成。
2. 如需修订，直接修改弹窗译文。点击“保存译文”，把当前显示的完整内容保存下来；这一操作复用已有翻译结果。
3. 按 `<Space>ra` 打开批注侧栏，用“全部／批注／译文”筛选列表；译文条目带有“译文”标记。PDF 上的批注标记、原生颜色筛选均保留原状。

保存会创建蓝色原生便签，在原文旁保留原文和译文，已有高亮与人工批注保持原样。同一 Reader 会话中，相同结果重复保存会复用标记；修订后保存会新建标记并保留旧内容。关闭翻译增强后，Translate for Zotero 与已保存的便签继续保留，便签仍可在 Zotero 原生侧栏查看。

译文完成且选区、视图和 PDF 来源仍有效时可以保存。外部修改 PDF 后，请重新打开阅读器并选择文字。按钮获得焦点后按 Enter 保存，按 Escape 返回 PDF。

## 查找和管理已有批注

在 Reader Normal 中按 `[a` / `]a` 选择上一个或下一个批注，或按 `<Space>ra` 打开原生侧栏。`Y` 复制当前批注的评论；Normal 模式的 [`y` 复制提示](READER_GUIDE.md#复制-doi、批注-或打开链接)可直接选择当前可见页面上的其他内容。复制摘录时，在命令面板选择“复制批注高亮文本”（`yankAnnotation`），默认通过命令面板调用。按 `Zy`、`Zr`、`Zg`、`Zb` 或 `Zp` 按颜色筛选，`Za` 清除筛选。

选中已有批注后，按 `zy`、`zr`、`zg`、`zb` 或 `zp` 可以改色。想查看某种颜色的批注，可用对应的筛选快捷键；按 `Za` 清除筛选。

**`dd` 会永久删除选中的批注，且无法撤销。** 核对目标后按 `dd` 并确认删除；在确认提示中按 `Escape` 可取消，批注会保留。

## 编辑批注评论

选中批注后，若在[阅读器设置](SETTINGS_GUIDE.md#调整阅读器控制)中启用了**批注评论编辑**，按 `i` 或 `Enter` 打开评论编辑器。普通键入和输入法输入都会写入评论；按 `Enter` 插入换行。输入法正在组合文字时，`Escape` 会先交由输入法处理。

输入后会立即保存本机草稿；停止输入两秒后自动尝试保存到 Zotero 批注。按 `Escape` 会提交最后的草稿并关闭编辑器。阅读器交互停用或输入权交给原生编辑器时，Neo 也会提交并关闭。已经接纳的保存可以在视图关闭后完成。

本机草稿可在重开视图、Reader 或重载 Neo 后恢复，存储范围是当前 Zotero 配置文件。保存失败时可点击“重试”；批注已在别处修改时，先核对内容，再选择“覆盖”或“丢弃草稿”，由你决定如何处理冲突。

出现“本机草稿保存失败”时，请保持 Zotero 开启，先重试或复制文字。编辑器会暂时保留界面；视图被强制关闭时，会弹出草稿供复制。本次运行中的草稿仍可重开找回，重启或停用前请先确认持久保存成功。

“批注评论编辑”控制 Reader Normal 中 `i` / `Enter` 的行为。文本选择模式下的“添加批注评论”独立提供，按 `za` / `i` 可创建 PDF 批注并打开评论编辑器；已有 Zotero 笔记保持原样。

## 高亮没有创建成功时

文字批注支持一页内或相邻两页中可完整定位的选区。跨度较大或有片段定位失败时，文字会保持选中；可缩小范围重试，或先按 `y` 复制文字。
