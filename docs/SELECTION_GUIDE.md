# 选择 PDF 文字并添加批注

Neo 可以直接用键盘找到 PDF 中的一段文字，再复制、搜索或高亮。操作前先点击 PDF 正文；如果光标还在搜索框或评论框里，快捷键不会按阅读器命令执行。

## 在阅读模式中操作

Reader Normal 中按 `<Space>rr` 切换 Zotero 原生 Reading Mode。重排后的正文沿用 `v` / `s` 的 Flash、`h/l` 词元移动、`j/k` 视觉行移动、`H/L` 字符微调、`o`、复制、搜索和选区批注；切换会释放旧视图的提示和选区资源。

Reading Mode 中的 `)` / `(` 按句子扩展，`}` / `{` 按结构化段落扩展。句界采用宿主 `Intl.Segmenter`，缩写等情况仍可能存在歧义。PDF 视图中这两组动作仍依赖 Gecko 的 `Selection.modify` 粒度支持，目前不能作为可靠的句段扩展方式。

重排视图中显示为原 PDF 裁图的图像、公式或表格，仍是图像区域；其中没有独立文本节点的文字不能直接 Flash。页码步进等操作取决于原生视图是否提供对应能力；精确 PDF 位置的共享历史恢复仍限 PDF 视图。链接／复制 hints 中依赖原 PDF 文本层或链接叠加层的目标也仍以 PDF 视图为准。文字高亮和下划线通过 Zotero 的映射保存回原 PDF 坐标。

## 选择正文时跳过图表文字

在 Reader Normal 中按 `<Space>rb` 开启**正文选择**，等待结构准备完成后再按 `v`。Flash、词元和视觉行候选会跳过原生结构已识别的图片、表格、图注及页眉页脚等页边文字；跨过这些区域时，复制和保存批注也会同时排除对应文本与坐标。Select 指示器显示 `SELECT BODY`。

开关作用于当前 Reader 会话的 PDF 和 Reading Mode，关闭阅读器或重载 Neo 后复原。要选图注或表格文字，先按 `Escape` 回到 Normal，再按 `<Space>rb` 恢复全部文字选择。准备过程中再次按下可取消本次启用，但不能中止 Zotero 已经开始的原生提取。

首次准备可能处理整份 PDF，耗时取决于文件与原生缓存；此功能不上传云端。效果依赖 Zotero 的结构分类，公式和没有可靠来源几何的文字仍保留可选，不能保证所有复杂版式都正确隔离。普通模式下的鼠标拖选仍使用 Zotero 原生逻辑；退出 Select 后临时选择样式随之释放。

## 对照原生与云端解析

按 `<Space>rd` 打开“文档解析对照”。原生结构沿用 Zotero 的 `.zotero-sdt-cache`；对照面板同时查找当前服务的本地解析缓存，命中后直接显示，打开面板不会发起云端请求。默认选择 MinerU 官方云端，填写官网创建的 API Token 后即可解析当前论文；也可切换到 OXR / SoMark 并修改兼容 API 地址。切换服务或确认地址后会查找对应缓存。密钥只保留在本次对话框中，切换服务会清空原密钥。

点击“读取缓存或使用云端解析”优先使用缓存，未命中时上传当前 PDF。要更新已保存结果，点击“重新解析并上传 PDF”；该操作明确重新上传。解析成功后自动保存到 Zotero 附件存储目录的 `.zotero-neo-analysis-*.json`，重开阅读器或重启 Zotero 后可复用；保存失败时，本次结果仍可用，面板会提示未保存。缓存不是 PDF 内嵌数据，单独复制 PDF 不会携带它，也不承诺随 Zotero 同步。

缓存按 PDF 文件哈希、页面几何、后端地址、请求设置及适配器版本匹配，文件变化或缓存损坏时不复用。服务未返回模型版本时，无法自动发现服务端模型升级，可手动重新解析。缓存保留规范化区域，图表关联按当前算法重新计算；API 密钥和 HTTP 请求体不写入缓存。缓存显示原解析耗时与保存时间，读取耗时不冒充重新解析耗时。

两列展示各自的区域、正文归属和内容；展开区域后可定位。MinerU 提供的表格、图片成员关系会保留为整组，展开图表组后可“定位整组”，包含它提供的主体、题注和脚注；缺少题注的表格仍会列出。分组效果取决于服务端输出；密集表格页可能出现题注错配，此时可展开单独的表格区域定位。复制对照报告可取得完整结构和词汇差异。区域数量和词汇差异仅用于诊断，不是准确率；原生缓存状态、网络与服务排队也会影响耗时。

MinerU 使用官方云端异步接口，面板显示上传、排队、解析和下载进度；当前每次处理一篇 PDF，最多 200 页、200 MB。批量选择与任务恢复界面尚未接入。

有效云端缓存也用于常规 `[f` / `]f`、`[t` / `]t` 图表导航和侧栏图表分组；无需再次打开对照面板或填写 Token。缓存缺失、损坏或与来源不匹配时，图表导航回退到原生结构。标题导航继续使用原生大纲及标题校正。云端区域不替换正文选择过滤或 Reading Mode，也不用于生成精确文字批注。关闭对话框会取消当前 HTTP 等待，并使未完成的界面结果失效；这不代表服务端计算一定停止。原生结构提取同样可能处理整份 PDF，SDK 不提供真正的中止能力。

## 从一段文字开始

1. 在 Zotero 中打开 PDF，点击页面文字。按 `v`，输入页面上可见的一个词或短语，再选择对应提示。按 `Enter` 会选择最近的匹配项。
2. 文字选中后，按 `z` 再按 `y`（`zy`），为它添加黄色高亮。

可以输入不完整的单词：例如页面上是 `flow matching,`，输入 `match` 会选中完整的 `matching`；输入 `ow mat` 会选中 `flow matching`。逗号等标点可以单独查找。同一个词中的重复子串只显示一个提示。

Flash 只查找当前视图中可见的文字。匹配目标超过 48 个时，继续输入以缩小范围；确认后才会改变选区。英文大小写沿用 smartcase：查询含 ASCII 大写字母时区分大小写，否则忽略大小写。

## 选中文字之后

选中文字后按 `zy`，Zotero 会添加一条黄色高亮批注。如果还在输入词句、选择匹配位置的阶段，按 `Escape` 可以退出查找，不会改动之前的选区。

## 调整选中的文字范围

在 PDF 普通模式下按 `v`，输入页面上能看到的原文词句，按字母提示选择匹配位置；按 `Enter` 会选择最近的一处。如果没找到，试试更短的词句。Neo 也可以接管 Zotero 已经选中的 PDF 文字。

选中文字后，用 `h` / `l` 向前或向后调整一个完整词元，`j` / `k` 移到相邻视觉行并吸附到词元边界。活动端的词元会显示轮廓提示，方便确认当前正在调整哪里。

例如选中 `flow matching,` 中的 `flow` 后，按 `l` 依次得到 `flow matching`、`flow matching,`；按 `h` 反向收缩。缩到一个词后继续移动会越过原锚词，向另一侧扩展，不会先留下空选区。标点独立选择，内部空格保留，首尾空白不作为停点。

按 `o` 交换锚点与活动端，随后仍按同一规则移动。按 `s` 用 Flash 定位另一端；向前或向后选择时，原锚词和目标词都会完整保留。接管原生非整词选区时，会保留其精确锚点。

需要选取半个单词、公式或有错误的 PDF 文本层时，用大写 `H` / `L` 按字符微调。`w` / `b` 保留浏览器原有的词边界移动；`0` / `$` 移到行首或行尾，`)` / `(`、`}` / `{` 分别移到句子或段落边界。已有自定义字符动作不会自动变成词元动作；可在[设置](SETTINGS_GUIDE.md#修改一个快捷键)中检查当前实际绑定。

## 使用当前选区

- 按 `y` 复制选中文字；复制时会规范化 PDF 的换行和空白。按 `#` 在 PDF 中查找该文字。
- 按 `zy`、`zr`、`zg`、`zb` 或 `zp`，添加黄色、红色、绿色、蓝色或紫色高亮。
- 按 `a` 或 `Enter` 打开选区操作。选择**为选区添加下划线**（Underline）可加下划线；选择**添加批注评论**（Add note）会创建 PDF 批注并打开评论编辑器。

## 查找和管理已有批注

在阅读器 Normal 模式中按 `[a` / `]a` 选中上一个或下一个批注，也可按 `<Space>ra` 打开 Zotero 原生批注侧栏并浏览其中的条目。`Y` 直接复制当前批注的评论。要复制当前可见页面上的其他内容，无需先选中批注，可使用[Normal 模式的 `y` 复制提示](READER_GUIDE.md#复制-doi、批注-或打开链接)。在命令面板搜索**复制批注高亮文本**（`yankAnnotation`）可直接复制摘录；此操作没有默认快捷键。按 `Zy`、`Zr`、`Zg`、`Zb` 或 `Zp` 按颜色筛选批注，按 `Za` 清除筛选。

选中已有批注后，按 `zy`、`zr`、`zg`、`zb` 或 `zp` 可以改色。想查看某种颜色的批注，可用对应的筛选快捷键；按 `Za` 清除筛选。

**`dd` 会永久删除选中的批注，且无法撤销。** 核对目标后按 `dd` 并确认删除；在确认提示中按 `Escape` 可取消，批注会保留。

## 编辑批注评论

选中批注后，若在[阅读器设置](SETTINGS_GUIDE.md#调整阅读器控制)中启用了**批注评论编辑**，按 `i` 或 `Enter` 打开评论编辑器。普通键入和输入法输入都会写入评论；按 `Enter` 插入换行。输入法正在组合文字时，`Escape` 会先交由输入法处理。

编辑器保持打开时，停止输入两秒后会自动保存。按 `Escape` 会保存最后的草稿并关闭编辑器。阅读器交互停用或输入权交给原生编辑器时，Neo 也会保存并关闭评论编辑器。

关闭视图或阅读器前先按 `Escape` 保存。仅关闭或销毁编辑器本身不会保存尚未提交的文字，也不会取消已经开始的 Zotero 保存。

**批注评论编辑**设置只控制 Reader Normal 模式中的 `i` / `Enter`；它不会关闭文本选择模式下独立的**添加批注评论**动作。按 `za` / `i` 可在文本选择模式中创建批注并打开评论编辑器；这不会把文字追加到已有 Zotero 笔记。

## 高亮没有创建成功时

Neo 只能给一页内或相邻两页中的完整选区添加批注。选区跨了太多页，或有一部分无法定位时，批注会失败，但文字仍保持选中。把选区缩小后再试，或者按 `y` 先复制文字。

阅读器导航和侧栏操作见[阅读和导航 PDF](READER_GUIDE.md#开始分屏阅读)。[命令参考：Reader Select](COMMAND_REFERENCE.md#reader-select-与批注操作)列出当前所有选区与批注操作。
