# 选择 PDF 文字并添加批注

Neo 可以直接用键盘找到 PDF 中的一段文字，再复制、搜索或高亮。操作前先点击 PDF 正文；如果光标还在搜索框或评论框里，快捷键不会按阅读器命令执行。

## 在阅读模式中操作

Reader Normal 中按 `<Space>rr` 切换 Zotero 原生 Reading Mode。重排后的正文沿用 `v` / `s` 的 Flash、`h/l` 词元移动、`j/k` 视觉行移动、`H/L` 字符微调、`o`、复制、搜索和选区批注；切换会释放旧视图的提示和选区资源。

PDF 与 Reading Mode 中的 `)` / `(` 按句子扩展，`}` / `{` 按逻辑段落扩展。首次按下时优先读取当前服务的布局缓存，缺失时显式请求原生结构，不上传 PDF。只有整个段落能唯一匹配真实文字时才采用逻辑边界，支持已渲染文字的跨 span、换栏及相邻页；规范化只处理空白、换行连字和兼容字形，不接受 OCR 替字。Reading Mode 无完整匹配时保留原生 HTML 段落，PDF 则使用词元退路，`H/L` 仍可按字符微调。句界采用宿主 `Intl.Segmenter` 并补充常见论文缩写，仍不保证所有自然语言歧义均正确。

重排视图中显示为原 PDF 裁图的图像、公式或表格，仍是图像区域；其中没有独立文本节点的文字不能直接 Flash。页码步进等操作取决于原生视图是否提供对应能力；精确 PDF 位置的共享历史恢复仍限 PDF 视图。链接／复制 hints 中依赖原 PDF 文本层或链接叠加层的目标也仍以 PDF 视图为准。文字高亮和下划线通过 Zotero 的映射保存回原 PDF 坐标。

## 选择正文时跳过图表文字

在 Reader Normal 中按 `<Space>rb` 开启**正文选择**，等待结构准备完成后再按 `v`。优先复用当前后端的有效附件缓存，缓存缺失时使用原生结构；此操作不上传 PDF。Flash、词元和视觉行候选会跳过已识别的图片、表格、图注及页眉页脚等页边文字；跨过这些区域时，复制和保存批注也会同时排除对应文本与坐标。Select 指示器显示 `SELECT BODY`。

开关作用于当前 Reader 会话的 PDF 和 Reading Mode，关闭阅读器或重载 Neo 后复原。要选图注或表格文字，先按 `Escape` 回到 Normal，再按 `<Space>rb` 恢复全部文字选择。准备过程中再次按下可取消本次启用，但不能中止 Zotero 已经开始的原生提取。更换后端、提交新缓存或保存局部纠错会关闭旧过滤，再次按 `<Space>rb` 准备新布局。复制、查找与批注前重查来源，文档变化或选区退休后不继续写入。

首次准备可能处理整份 PDF，耗时取决于文件与原生缓存；此功能不上传云端。效果依赖所选布局的结构分类，公式和没有可靠来源几何的文字仍保留可选，不能保证所有复杂版式都正确隔离。普通模式下的鼠标拖选仍使用 Zotero 原生逻辑；退出 Select 后临时选择样式随之释放。

## 搜索和预览图表

按 `<Space>rf` 打开图表列表，按编号、题注关键词搜索，或用 `p:6` 筛选第 6 页。↑ / ↓（或 Ctrl+N / P）切换候选，右侧从当前 PDF 渲染预览；预览期间阅读位置不变。按 Enter 或“定位到原文”跳转，Escape 取消并返回发起操作的分屏。确认跳转沿用 Zotero 原生历史；PDF 中可以用 Ctrl+O / Ctrl+I 后退和前进。

默认显示包含子图、题注和脚注的**整组**，只绘制解析所提供的真实成员矩形，间隔中的正文留白。若表格漏配题注或关联错误，可切换**独立主体**：逐一浏览解析已经识别的图片／表格区域，使用类型和页码筛选定位。主体视图没有题注编号，不能补回模型没有识别到的区域。预览区支持 + / − / 0 和按钮缩放；列表超过 200 项时请缩小搜索范围。

列表优先复用当前服务匹配的解析缓存，未命中时使用原生结构，不会主动上传 PDF。尚未得到图表结构时，可以先使用下方文档解析对照。PDF 与 Reading Mode 共用此入口，预览均来自原 PDF；确认能否定位由当前原生视图决定。关闭 Reader、切换视图或更换解析服务会释放旧预览。

## 章节内查找

Reader Normal 按 `<Space>rs`，在章节下拉框确认范围并输入原文关键词。范围包含编号子章节；没有可靠标题结构时提供整篇文档退路。默认根据当前位置可见文字建议章节，找错范围时可直接改选。

结果按段落显示字面匹配，最多显示 100 项；↑/↓ 选择、Enter 定位原文段落，Escape 取消并保持阅读位置。这里使用已存布局的区域坐标，不把命中词冒充精确字符高亮，也不调用语义模型。布局文字可能与 PDF 有差异，结果仍需对照原文。原生 `/`、`n/N` 和 Find 查询保持独立；PDF 确认跳转沿用原生历史，Ctrl+O / Ctrl+I 可以恢复位置。Reading Mode 的跳转继续由 Zotero 原生映射负责。

## 摘录整组图表与公式

Reader Normal 按 `<Space>re`，在列表中搜索图表编号、题注或公式。默认列出已识别的整组图表与独立公式；可按类型筛选，或切换“独立主体”避开错误的题注关联。预览来自原 PDF，绘制所有已知成员，间隙中的正文留白；仅题注或关联不确定时会标明，不能补回解析没有识别到的区域。

- **Enter／复制图文与来源**：复制富文本图片、题注、论文与页码。Zotero 笔记中的图片保留原生区域定位元数据；普通文本回退链接打开对应 PDF 页。
- **复制原图**：复制 PNG，便于粘贴到图片工具。多页对象使用图文或笔记保存。
- **复制结构文本**：有结构时复制公式原始 LaTeX／文本，或表格 TSV／安全 HTML。HTML 保留模型提供的单元格合并属性；TSV 不重建合并单元格，不承诺模型数值正确。
- **保存为新笔记**：确认界面中的归属后创建笔记。有文献父条目时保存到该文献下，独立 PDF 对应独立笔记。图片作为 Zotero 笔记的嵌入附件保存，可通过原生图片定位回原区域；同时记录 PDF 来源关联。不会追加或覆盖已有笔记，也不会新建 PDF 批注。

预览和复制不写入笔记。取消、换视图或关闭 Reader 会释放界面；已接纳的保存可继续完成，失败会清理自有的未完成笔记。所有操作都复查当前 PDF 版本与目标身份，不会借用 Main 选择。布局优先复用已存结果，不自动上传。

已有批注与图表摘录可在 `<Space>rn` 中[按章节整理成笔记](NOTE_GUIDE.md#按章节整理批注与摘录)，先预览再保存。

## 对照原生与云端解析

按 `<Space>rd` 打开“文档解析对照”。原生结构沿用 Zotero 的 `.zotero-sdt-cache`；对照面板同时查找当前服务的本地解析缓存，命中后直接显示，打开面板不会发起云端请求。默认选择 MinerU 官方云端；填写 Token 会自动保存，删空即清除，重开时回填到密码框，单篇与批量准备共用。只有点击“验证”才检查凭据，不会上传 PDF。申请入口与存储说明见[文档解析设置](SETTINGS_REFERENCE.md#文档解析对照)。也可切换到 OXR / SoMark 并修改兼容 API 地址；OXR 密钥仅本次使用。切换服务或确认地址后会查找对应缓存。

点击“读取缓存或使用云端解析”优先使用缓存，未命中时上传当前 PDF。要更新已保存结果，点击“重新解析并上传 PDF”；该操作明确重新上传。解析成功后自动保存到 Zotero 附件存储目录的 `.zotero-neo-analysis-*.json`，重开阅读器或重启 Zotero 后可复用；保存失败时，本次结果仍可用，面板会提示未保存。缓存不是 PDF 内嵌数据，单独复制 PDF 不会携带它，也不承诺随 Zotero 同步。

缓存按 PDF 文件哈希、页面几何、后端地址、请求设置及适配器版本匹配，文件变化或缓存损坏时不复用。服务未返回模型版本时，无法自动发现服务端模型升级，可手动重新解析。缓存保留规范化区域，图表关联按当前算法重新计算；API 密钥和 HTTP 请求体不写入缓存；保存的 MinerU Token 独立存放于本机密码管理器，不进入普通偏好导出。缓存显示上次处理记录耗时与保存时间；耗时包括上传、等待和取回，批量任务还可能包含本地暂停时间，不作为模型纯计算耗时。读取缓存不冒充重新解析。

两列展示各自的区域、正文归属和内容；展开区域后可定位。MinerU 提供的表格、图片成员关系会保留为整组，展开图表组后可“定位整组”，包含它提供的主体、题注和脚注；缺少题注的表格仍会列出。分组效果取决于服务端输出；密集表格页可能出现题注错配，此时可展开单独的表格区域定位。复制对照报告可取得完整结构和词汇差异。区域数量和词汇差异仅用于诊断，不是准确率；原生缓存状态、网络与服务排队也会影响耗时。

MinerU 使用官方云端异步接口，面板显示上传、排队、解析和下载进度。单篇对照与批量准备共用提交、查询、下载和归一化协议；插件目前限制每篇 200 页、200 MB。

## 修正图表关联与正文归属

在 `<Space>rd` 的对应解析列中展开区域，先用“定位区域”核对原 PDF：

1. 图表误配题注时，在题注区域选择“同页图／表主体”。候选显示区域 ID 与 PDF 坐标；确认原文后点击“保存题注关联”。
2. 正文被误分为图表或图注时，点击“保存为正文”。它只修改归属，实际文字仍须映射到原生文本后才能复制或批注。
3. 点击“恢复原始归属”移除该区域修正；“撤销上次已保存纠错”还原本列上一次保存，每列在当前对话框内最多保留 20 步。控件可用 Tab / Shift+Tab 到达，用 Enter / Space 操作。

改为正文会同时移除与该区域冲突的局部题注关联。“恢复原始归属”只移除当前区域的显式修正，不重建这些关联；要恢复保存前的完整状态，在同一面板内撤销，或重新保存题注关联。

修正独立保存在该附件目录的 `.zotero-neo-corrections-*.json`，不改 PDF、原生 SDT 或云端解析缓存。关闭面板、重开 Reader 或重启 Zotero 后，匹配来源的修正仍可复用；图表导航、正文选择和对象摘录共享这些归属。保存会释放旧结果与过滤，不能继续复制或保存过期摘录。

修正严格绑定 PDF、页面、解析服务／配置及确切解析结果；来源变化时停用旧修正，不猜测迁移到相似区域。读取修正失败会提示不可用，不绕回未修正的图组。修正不能补回未识别区域、画新框或生成表格单元格；单独复制 PDF 不携带修正，也不保证随 Zotero 同步。维护者的质量核验方法见[解析质量评测](QUALITY_EVALUATION.md)。


## 批量准备论文

Main 普通模式按 `<Space>ru`，按 EffectiveSelection 固定本次 PDF：优先 Persistent Selection，其次当前多选／游标目标。普通文献条目展开其 PDF 附件，直接选中的 PDF 只处理该附件；重复附件去重，非 PDF 忽略。Reader 使用同一按键，但只准备当前附件，不读取 Main 选择。展开“本次固定 PDF 数量”可审阅列表，之后改变选择不会改变已捕获的批次。

此入口固定使用 MinerU。填写或使用已保存的 MinerU Token，点击“使用 MinerU 准备（上传未缓存 PDF）”。界面每批最多 200 个 PDF；按具体上传接口的较保守限制，每次最多申请 50 个文件地址。已缓存项跳过上传；缺失文件、服务失败与成功项分别显示。上传与结果下载并发各最多 2 个，不提前把整批 PDF 读入内存。页面几何由 Zotero 自带 PDF.js 读取，不新建 Reader 标签页或运行原生 OCR。完成状态表示 MinerU 结果已保存，不表示当前 Reader 一定使用它。

面板会实时显示 Reader 当前选择 MinerU 还是 OXR。选择 MinerU 时，后续 `<Space>rf`、图表遍历和侧栏可复用匹配且有效的 MinerU 缓存；选择 OXR 时不会消费这些结果，已完成结果仍写入 MinerU 缓存。若需要使用它们，请在 `<Space>rd` 中主动切回 MinerU；准备面板不会自动更改服务。

关闭面板后任务继续；关闭发起任务的 Reader 也不会取消队列。点击“停止本地等待”只停止本地请求／轮询，已上传的远端任务仍可能完成；“继续／重试未完成项”会先查询已有回执，不重复上传已成功提交的文件，已完成项保持不变。明确失败的任务可重交，上传前中断且签名地址已丢失／过期时，只在服务确认仍等待文件后重新申请上传。下载或缓存保存失败时，优先重新取回原结果。

最近一批的任务身份和回执保存在 Zotero 数据目录的 `zotero-neo-document-tasks.json`，不含 Token、签名 URL 或原始服务错误。重启后可重新打开面板、使用已保存的 Token 继续；重启本身不会查询或上传。新建批次会显式替换这份任务记录，已保存的附件解析缓存保留，也不会取消旧远端任务。若附件 PDF 已变化，旧任务拒绝落盘，请新建批次重新准备。


有效云端缓存也用于常规 `[f` / `]f`、`[t` / `]t` 图表导航和侧栏图表分组；无需再次打开对照面板或填写 Token。缓存缺失、损坏或与来源不匹配时，图表导航回退到原生结构。标题导航继续使用原生大纲及标题校正。正文选择复用这些区域作为排除策略；实际复制内容与高亮坐标始终来自原生文字。Reading Mode 使用其真实块映射，未知或部分覆盖的正文块保留可选。图表整组包围框不用于排除文字，正文与排除区域冲突时优先保留正文。关闭对话框会取消当前 HTTP 等待，并使未完成的界面结果失效；这不代表服务端计算一定停止。原生结构提取同样可能处理整份 PDF，SDK 不提供真正的中止能力。

## 从一段文字开始

1. 在 Zotero 中打开 PDF，点击页面文字。按 `v`，输入页面上可见的一个词或短语，再选择对应提示。按 `Enter` 会选择最近的匹配项。
2. 文字选中后，按 `z` 再按 `y`（`zy`），为它添加黄色高亮。

可以输入不完整的单词：例如页面上是 `flow matching,`，输入 `match` 会选中完整的 `matching`；输入 `ow mat` 会选中 `flow matching`。逗号等标点可以单独查找。同一个词中的重复子串只显示一个提示。

Flash 只查找当前视图中可见的文字。匹配目标超过 48 个时，继续输入以缩小范围；确认后才会改变选区。英文大小写沿用 smartcase：查询含 ASCII 大写字母时区分大小写，否则忽略大小写。

## 选中文字之后

选中文字后按 `zy`，Zotero 会添加一条黄色高亮批注。如果还在输入词句、选择匹配位置的阶段，按 `Escape` 可以退出查找，不会改动之前的选区。

## 调整选中的文字范围

在 PDF 普通模式下按 `v`，输入页面上能看到的原文词句，按字母提示选择匹配位置；按 `Enter` 会选择最近的一处。如果没找到，试试更短的词句。Neo 也可以接管 Zotero 已经选中的 PDF 文字。

选中文字后，用 `h` / `l` 向前或向后调整一个完整词元，`j` / `k` 移到相邻视觉行并吸附到词元边界。活动端的词元会显示轮廓提示，方便确认当前正在调整哪里。

例如选中 `flow matching,` 中的 `flow` 后，按 `l` 依次得到 `flow matching`、`flow matching,`；按 `h` 反向收缩。缩到一个词后继续移动会越过原锚词，向另一侧扩展，不会先留下空选区。标点独立选择，内部空格保留，首尾空白不作为停点。

按 `o` 交换锚点与活动端，随后仍按同一规则移动。按 `s` 用 Flash 定位另一端；向前或向后选择时，原锚词和目标词都会完整保留。接管原生非整词选区时，会保留其精确锚点。

需要选取半个单词、公式或有错误的 PDF 文本层时，用大写 `H` / `L` 按字符微调。`w` / `b` 保留浏览器原有的词边界移动；`0` / `$` 移到行首或行尾，`)` / `(`、`}` / `{` 分别移到句子或段落边界。已有自定义字符动作不会自动变成词元动作；可在[设置](SETTINGS_GUIDE.md#修改一个快捷键)中检查当前实际绑定。

## 使用当前选区

- 按 `y` 复制选中文字；复制时会规范化 PDF 的换行和空白。按 `#` 在 PDF 中查找该文字。
- 按 `zy`、`zr`、`zg`、`zb` 或 `zp`，添加黄色、红色、绿色、蓝色或紫色高亮。
- 按 `a` 或 `Enter` 打开选区操作。选择**为选区添加下划线**（Underline）可加下划线；选择**添加批注评论**（Add note）会创建 PDF 批注并打开评论编辑器。

## 保存自动翻译的译文

先按[设置指南中的翻译增强流程](SETTINGS_GUIDE.md#准备翻译增强)准备并启用翻译增强；该入口不依赖 Plugin Manager。翻译服务、目标语言和密钥仍由 Translate for Zotero 自己管理。自动结果的保存只支持 Translate for Zotero **2.4.8** 的就绪运行时；仅显示已安装并不表示保存可用。Neo 不会静默替换或降级其他版本；上游公开翻译 API 可用时，手动“翻译”动作仍可能可用。

1. 像往常一样在 PDF 或 Reading Mode 中选中文字，等待自动译文完成。
2. 如需修订，直接修改弹窗里的译文。点击旁边的**保存译文**，保存当前显示的完整内容，不再发起翻译请求。
3. 按 `<Space>ra` 打开批注侧栏，用**全部／批注／译文**切换列表；译文条目带有**译文**标记。角色筛选只影响侧栏，不隐藏 PDF 上的标记，也不替换 Zotero 原有的颜色等筛选。

保存会创建蓝色原生便签批注，在原文旁保留原文与译文，不自动给文字加高亮，也不覆盖已有人工批注。同一阅读器会话中，未改结果重复保存不会再建标记；修订结果后再次保存会新建标记，旧内容保留。关闭翻译增强不会停用或卸载 Translate for Zotero，也不会删除已保存的原生便签；它们仍可通过 Zotero 原生批注侧栏查看。

译文未完成、选区或视图已变化、PDF 来源不再匹配时，不能继续用旧弹窗保存。外部修改 PDF 后，请重新打开阅读器再选择文字。按钮获得焦点后可按 Enter 保存，按 Escape 返回 PDF。

## 查找和管理已有批注

在阅读器 Normal 模式中按 `[a` / `]a` 选中上一个或下一个批注，也可按 `<Space>ra` 打开 Zotero 原生批注侧栏并浏览其中的条目。`Y` 直接复制当前批注的评论。要复制当前可见页面上的其他内容，无需先选中批注，可使用[Normal 模式的 `y` 复制提示](READER_GUIDE.md#复制-doi、批注-或打开链接)。在命令面板搜索**复制批注高亮文本**（`yankAnnotation`）可直接复制摘录；此操作没有默认快捷键。按 `Zy`、`Zr`、`Zg`、`Zb` 或 `Zp` 按颜色筛选批注，按 `Za` 清除筛选。

选中已有批注后，按 `zy`、`zr`、`zg`、`zb` 或 `zp` 可以改色。想查看某种颜色的批注，可用对应的筛选快捷键；按 `Za` 清除筛选。

**`dd` 会永久删除选中的批注，且无法撤销。** 核对目标后按 `dd` 并确认删除；在确认提示中按 `Escape` 可取消，批注会保留。

## 编辑批注评论

选中批注后，若在[阅读器设置](SETTINGS_GUIDE.md#调整阅读器控制)中启用了**批注评论编辑**，按 `i` 或 `Enter` 打开评论编辑器。普通键入和输入法输入都会写入评论；按 `Enter` 插入换行。输入法正在组合文字时，`Escape` 会先交由输入法处理。

输入后会立即保存本机草稿；停止输入两秒后自动尝试保存到 Zotero 批注。按 `Escape` 会提交最后的草稿并关闭编辑器。阅读器交互停用或输入权交给原生编辑器时，Neo 也会提交并关闭。已经接纳的保存可以在视图关闭后完成。

关闭视图、阅读器或重新加载 Neo 后，重新编辑同一批注可恢复未提交的本机草稿。草稿只保存在当前 Zotero 配置文件，不随批注同步。保存失败时可重开编辑器点击**重试**；若批注已在别处修改，先核对，再明确选择**覆盖**或**丢弃草稿**，不会自动覆盖外部修改。

若提示**本机草稿保存失败**，不要直接退出 Zotero：先重试或复制文字。此时 `Escape` 不会关闭编辑器；若视图被强制关闭，Neo 会弹出包含草稿文本的提示供复制。内存草稿可在本次运行中重开批注找回，但存储恢复前不能保证重启或停用后仍可恢复。

**批注评论编辑**设置只控制 Reader Normal 模式中的 `i` / `Enter`；它不会关闭文本选择模式下独立的**添加批注评论**动作。按 `za` / `i` 可在文本选择模式中创建批注并打开评论编辑器；这不会把文字追加到已有 Zotero 笔记。

## 高亮没有创建成功时

Neo 只能给一页内或相邻两页中的完整选区添加批注。选区跨了太多页，或有一部分无法定位时，批注会失败，但文字仍保持选中。把选区缩小后再试，或者按 `y` 先复制文字。

阅读器导航和侧栏操作见[阅读和导航 PDF](READER_GUIDE.md#开始分屏阅读)。[命令参考：Reader Select](COMMAND_REFERENCE.md#reader-select-与批注操作)列出当前所有选区与批注操作。
