# 常见问题与排查

## 按键没有反应

先把焦点放到要操作的地方：主窗口点条目列表或分类树，阅读器点 PDF 正文。再按 `:` 查当前能用的命令。若设置过按键，以 **Neo 设置 → 快捷键**为准；每个上下文的绑定不同。

链接提示、侧栏标签页或扩展管理不见了？检查[模块开关](SETTINGS_GUIDE.md#开关可选功能)。无法用快捷键打开设置时，在 Zotero 的 Neo 偏好页点 **Open Neo Settings**。

## 为什么输入中文时 Enter 或 Esc 没有执行命令

搜索框、Flash、笔记和批注评论都能输入中文。**先结束输入法的组字**：候选窗出现时，方向键、`Enter`、`Esc` 和 `Backspace` 先交给输入法；提交候选后，Neo 才根据文字更新查询，下一次按键才执行界面命令。

焦点还在原生文本框时，字母用于输入；在启用了 Vim 编辑的笔记中，按 `i` 从 Normal 进入 Insert。阅读器大纲的方向键、`Tab` 和 `Enter` 由 Zotero 处理。改键也不会覆盖这些保留键。

## Flash 找不到文字

Flash 只匹配活动 PDF 窗格里当前可见、可选取的文字，不做 OCR。试试较短的原文片段；要查整篇文档，用 `/`。详见[选中文字](READER_GUIDE.md#从一段文字开始)。

## 评论中 Enter 换行，Esc 却保存了内容

批注评论编辑器中的 `Esc` 保存并退出，不是丢弃。停止输入约两秒后也会尝试自动保存。离开或关闭阅读器前先用 `Esc` 保存；直接关闭阅读器不会补存最后的文字。

## 修改模块开关后为什么没有生效

如果看到「部分更改将在重启 Zotero 后生效」，设置已保存，功能仍在沿用启动时的状态。完全退出并重新打开 Zotero；只关闭设置、重开 PDF 或热重载 Neo 不算重启。

## 新快捷键为什么没有保存

重复绑定会在当前行标出占用的动作；改用其他键，或明确选择「覆盖已有绑定」。原生保留键不能保存；前缀冲突会提示，但不阻止保存。参见[录制与表达式](SETTINGS_GUIDE.md#修改一个快捷键)。

## 找不到某条笔记

如果选择器当前只看所选论文的笔记，切换到 **Browse library**（浏览文库）。同名时看预览里的所属条目和正文；操作见[笔记指南](MAIN_GUIDE.md#开始查找并编辑笔记)。

## 怎么报告问题

去 [GitHub Issues](https://github.com/zhongyangchuwu/Zotero-Neo/issues) 附上 Neo / Zotero 版本、所在界面、按键、预期结果和实际提示。需要日志时见[诊断说明](DEVELOPMENT.md#诊断)；反馈前不必重置配置。
