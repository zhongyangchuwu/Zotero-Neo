# 故障排查

先按遇到的问题查找。下面写的是默认快捷键；如果改过按键，请以 Neo 设置中的绑定为准。

## 按键没有反应

1. **先看焦点。** 点击要操作的区域：主窗口的条目列表或分类树、阅读器的 PDF 页面、笔记编辑器。搜索框、批注评论、Zotero 控件和输入法候选可能正在接收按键。刚打开的 PDF 要先等待加载，再点击页面。
2. **检查功能是否被关闭。** 如果 `y` / `f` 的字母提示或 `<Space>pp` 扩展管理面板没有出现，进入 `<Space>ps` → **设置 → 模块**检查对应开关。修改后需重启 Zotero。
3. **检查绑定与上下文。** 在**设置 → 快捷键**中选择当前上下文，搜索动作或按键，查看它是默认、自定义还是未绑定。主窗口、阅读器、文本选择和笔记中的同一个键不一定做同一件事。
4. **检查相关行为开关。** 阅读器的 `v` 还受**文本选择模式**控制；Normal `i` / `Enter` 编辑已选批注还需开启**批注评论编辑**；笔记命令需要**Vim 风格笔记编辑**。这些偏好与模块开关不是同一层设置。

若阅读器显示原生输入状态，按普通 `Escape` 退出后再使用命令。原生文本框和输入法仍保留各自的文字编辑按键，不能把正在输入的字母当作 Neo 浏览命令。焦点与模式见[基本概念](CONCEPTS.md)，录键和重绑定见[设置指南](SETTINGS_GUIDE.md)。

## 修改模块开关后没生效

可选增强的请求只在下一次完全启动 Zotero 时应用。使用 Zotero 的退出命令彻底退出应用，再重新打开；只关闭某个窗口、重新打开 PDF，或在插件管理中停用后启用 Neo，都不会应用新请求。

**部分更改将在重启 Zotero 后生效**表示保存的开关与当前运行状态不同，不表示保存失败。重启前功能继续按当前状态运行；详细信息见[模块参考](SETTINGS_REFERENCE.md#模块)。翻译依赖的独立状态和处理方法见[设置指南](SETTINGS_GUIDE.md#准备翻译增强)。

## 模块提示失败或等待主机

如果某个窗口或阅读器中的功能无法使用，可关闭重开相应阅读器；仍无法恢复时，重启 Zotero，并保留错误提示以便反馈。

反馈问题时，附上 Neo/Zotero 版本、当时所在区域、按键和可见错误。需要日志时，见[诊断说明](DEVELOPMENT.md#诊断)；不必先重置全部配置而丢掉问题发生时的状态。

## 快捷键打不开 Neo 设置

在 Zotero 的偏好设置中找到 Zotero Neo，点击 **Open Neo Settings**。然后检查快捷键绑定或可选功能的开关。

**恢复功能默认值**只重置可选功能开关，立即保存，重启后生效。要修改按键，请在**快捷键**中处理对应条目。

## 无法应用快捷键修改

完全重复的绑定会显示冲突动作；在当前行选择**覆盖已有绑定**，或继续修改。也可改用没有被 Zotero 或文字编辑保留的按键，或选择支持该动作的上下文。若一个序列是另一序列的前缀，设置会警告较短命令可能等待后续输入，但仍允许保存。

录制时按 `Backspace` 删除最后一键，普通 `Enter` 确认并立即保存，`Esc` 取消。需要绑定字面的 `<Enter>`、`<Esc>` 或 `<BS>` 时，使用行内**编辑表达式**；原生保留按键仍不能分配。

## 笔记选择器为空，或找不到某条笔记

初始范围只包含发起条目的已有笔记。选择 **Browse library**（浏览文库）查看同一文库中的其他笔记，选择 **Current item** 返回当前条目范围。标题相同时，查看预览中的所属条目和正文。


## Flash 找不到文字

使用当前 PDF 视图中看得到、能选取的短词句。Flash 只匹配活跃视图的可见文字，不是整篇全文搜索，也不提供 OCR。扫描页没有可读文字层时，改用原生 PDF 操作；要搜索整篇文档，用阅读器 `/`。

## Enter 或 Escape 没有按 Neo 命令执行

先完成或取消当前输入法组字。候选窗口存在时，确认、取消和 Backspace 交给输入法，不会提前确认 Neo 选择器或退出编辑器。组合结束后，普通按键恢复各自语义，见[文本输入与输入法](INPUT_METHODS.md)。

## 评论中 Enter 换行，Escape 却保存了内容

这是批注评论编辑器的正常行为：`Enter` 换行，普通 `Escape` 保存最终草稿并关闭。编辑器保持打开时，最后一次输入约两秒后自动保存；Escape 不是放弃草稿。输入法组字期间的 Escape 则先由输入法处理。

关闭 PDF 视图或阅读器前，先按 `Escape` 保存；销毁视图本身不会补存尚未保存的文字。已经开始的原生保存不会因界面关闭而被撤销。详见[批注评论编辑](SELECTION_GUIDE.md#编辑批注评论)。

## 翻译或 citekey 复制不可用

Reader Select 没有手动“翻译”时，检查[选区翻译 Extra 和 Translate for Zotero](SELECTION_GUIDE.md#手动翻译选区)是否已启用、上游公开 API 是否已就绪，再重新打开选区菜单。`<Space>yy` 需要 **Better BibTeX**，并且目标有可用的 citekey；任一目标或 citekey 无法解析时，Neo 拒绝复制并保留剪贴板。

Reader Select 和 citekey 是核心能力，手动翻译 Extra 与自动译文的翻译增强模块可独立关闭。缺少外部集成不会因为给动作绑定一个按键就自动补上。

自动译文的保存只支持 Translate for Zotero 2.4.8 的就绪运行时；等待弹窗译文完成后再保存，切换选区或视图后不要使用旧弹窗。若 PDF 已被外部修改，重新打开阅读器再选。关闭翻译增强不会停用插件或删除已保存的原生便签；详见[保存自动翻译的译文](SELECTION_GUIDE.md#保存自动翻译的译文)和[翻译依赖状态](SETTINGS_GUIDE.md#准备翻译增强)。

## 扩展管理面板里不能安装插件

按 `<Space>pp` 后用 `i` 或 Extras 按钮打开设置，在**选区翻译**中查看依赖状态并安装或启用 Translate for Zotero；也可直接打开 Neo 设置的 Extras 页面，不要求开启 Plugin Manager。已安装插件使用 `u` 检查其原生更新，`r` 仅重新读取列表。任意来源安装、远端插件发现和移除仍使用 Zotero 原生插件管理；Neo 不能在自己的面板中停用自身。完整操作见[插件管理](SETTINGS_GUIDE.md#查看已安装的插件)。如果 `<Space>pp` 入口不见了，检查**扩展管理面板**开关，并在更改后完全重启 Zotero。

## 第一次标题或图表导航较慢

首次请求可能需要 Zotero 在本地分析 PDF，稍后请求可复用结果。某些 PDF 没有可用的标题、图或表目标，这时改用翻页或文字搜索。Neo 不根据看起来像标题的普通文字编造结构目标；具体入口见[阅读器指南](READER_GUIDE.md#搜索正文-跳到标题和图表)。
