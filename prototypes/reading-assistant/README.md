# 精读与原文对照原型

对应 [#205](https://github.com/zhongyangchuwu/Zotero-Neo/issues/205)。这是独立运行的界面原型，用真实论文的一个章节评审拟接入 Zotero 原生 Reading Mode 的交互。

## 打开原型

在项目根目录使用 Node.js 24 运行：

```sh
npm run prototype:reader
```

浏览器打开 `http://127.0.0.1:4178/`。更换端口可用 `npm run prototype:reader -- --port 4180`。本机记录按浏览器和站点地址保存，评审时应使用同一浏览器、地址和端口。

## 体验流程

1. 默认进入单栏精读，查看章节解读与已有问答；在段落旁点“译文”查看两段预置译文。
2. 点“查看依据”或“对照原文”，在右侧查看第 6／7 页原版 PDF 页面。题注、表格、公式与页面版式保留原样，来源框只是临时叠加提示。可缩放并打开完整原 PDF。
3. 关闭对照返回阅读记录。收藏或编辑一条解读，再刷新／重开，验证结果可继续查看。
4. 切换“当前位置／本节全部／收藏”及问答／译文类型，比较跟随正文与集中查看的体验。

`J/K` 滚动正文，`C` 切换对照，`T` 显示已存译文，`Escape` 关闭对照或取消编辑。编辑时不接管普通输入；编辑内容保存前，范围切换和进入对照会暂时让位。

## 范围

- 使用 DeepSeek-OCR §3.2.2 的五段原生提取文本、一个表格和一个公式。
- 解读、两条问答及两段译文为人工预置示例；编辑、收藏和阅读偏好实际保存于当前浏览器的 `localStorage`。存储失败会提示，不显示保存成功。
- 这版用于评审交互，尚未嵌入 Zotero Reader，也不调用模型或写入 Zotero 笔记／批注。PDF 对照使用原页面的渲染图，完整 PDF 链接指向原论文。
- 原型不进入 XPI，也不作为已发布功能出现在文档站。实现采用一份文档来源、一份记录存储、精读与原页两个展示入口；后续接入原生 Reading Mode 时保留这些语义。

## 示例来源与许可

Haoran Wei、Yaofeng Sun、Yukun Li，**DeepSeek-OCR: Contexts Optical Compression**，2025，[arXiv:2510.18234v1](https://arxiv.org/abs/2510.18234v1)。论文按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 发布，原型中的正文节选、页面图像、表格与公式沿用该许可，作者不为本原型背书。

正文来自本次 Zotero 原生结构提取，按段落重排；“Figure 4”和“DeepSeek-OCR”的少量提取空格进行了校正。页面图像由原 PDF 栅格化，表格含题注，公式从原页裁出；未重排或加入 AI 内容。中文译文、摘要和问答由本项目为原型人工编写，不能作为模型效果验收。

示例 PDF 文件哈希记录在 `document.json`，来源框采用原 PDF 用户坐标。资源全部本地提供，点击论文／完整 PDF 链接时才访问外部网站。
